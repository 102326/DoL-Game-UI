- Follow Scoped Done and Risk-Proportional Validation: define the task's delivery and acceptance, reuse valid evidence, and keep untested coverage separate from unfinished work. Documentation-only rules need link/consistency checks, not new game or full build runs.

Use available `prp-technical-writing`, then `humanizer`, as needed; do not enable them for every task, install them automatically or claim an invocation that did not happen. Final text must preserve technical conclusions, commands, paths, Unknown and validation scope; experiments remain experiments.

Preserve old designs and completed experiments with source, date, result and whether to continue; reuse existing project reports. `current/archive/experiments/artifacts` describes responsibilities, not a directory migration instruction or a new memory platform.
- Release packages serve current use: retain current code, Skill/docs where applicable, necessary resources and licenses/notices; inspect the actual dependency/file list and exclude internal experiments, obsolete plans, private tests, raw audits and temporary files. Preserve valuable history in the source repository or linked archives. Do not remove needed files solely because of their directory name or change existing packaging paths for the example layout.
- Auxiliary writing, archive and delivery rules do not alter the original game's state/event/business ownership or the current UI Runtime/API. Respect the task's execution and publication scope; recording these rules does not authorize push, Release, gameplay or data changes.

- Cross-device continuation: read [HANDOFF](docs/HANDOFF.md), then verify this checkout's HEAD, branch, worktree, dependencies and actual runtime before reusing evidence. Update its Current / Decided / Next snapshot at handoff, with the tested source commit, commands, environment and CI link. Mark uncommitted/unpushed work and unavailable local artifacts explicitly. Machine paths belong only in ignored `docs/HANDOFF.local.md`; never equate macOS, Windows, Actions or Android validation.
