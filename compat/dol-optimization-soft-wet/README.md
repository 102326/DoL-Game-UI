# DolOptimizationSoftWet 1.0.0

原版优化的存档界面，保留原描述编辑、分页、槽位和保存／读取控件。

本包以 Soft & Wet 3.x — Kraft Work 为视觉基线。窗口外壳使用主 UI 的黑灰 Acrylic，内容不重复模糊，按钮与导航复用当前交互机制。关闭动画或 UI 时保留原操作，未知结构退让。资源与槽位适配不强行添加独立页面。

要求 `原版优化 >=1.1.1.2`、`DoLGameUI >=3.0.0` 和 DoL 0.5.12.13。最低声明与结构合同共同决定是否启用，不代表所有后续版本或组合均已验证。当前开发验证范围见仓库维护报告；旧发行记录保留原证据，不能充当 1.0.0 的真机证明。

按目标 Mod 选装，加载在目标 Mod 和 UI 之后。替换同技术名旧兼容包，每个身份只启用一个版本；回退时恢复原包并重启，不清空游戏数据。

构建：`python scripts/package-adapter.py compat/dol-optimization-soft-wet`。原节点、值、事件和业务逻辑由原 Mod 管理。
