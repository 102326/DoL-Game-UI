# DolOptimizationSoftWet 1.0.3

本次为本地研究候选，随当前测试组合检查 原版优化 1.1.2.1；最终真机覆盖和制品身份以本轮验证报告为准，尚未公开发布。

原版优化的存档界面，保留原描述编辑、分页、槽位和保存／读取控件。

存档附加日期采用条件修复：仅在已识别页面出现 NaN／undefined／Infinity 日期时，读取该槽位并按 SugarCube 解码后的活动历史帧生成显示。正常日期不读取、不覆盖；上游修复后会自动保留其结果，无需为了停用补丁再更新本包。只改日期文字，不写入存档、metadata 或原版业务；字段无效时保留原异常，不伪造当前时间。关闭页面、停用或销毁时恢复仍由本包持有的文字，迟到读取不得写回失效节点。

衣柜增加“叠加装备”管理区，使用当前已加载原版优化的原模板与链接：查看叠穿衣物、点击名称卸下、用 ◀▶ 调整层级，最前层前移时按原规则与主装备交换。管理区采用 Kraft Work 3.X 材质与触控尺寸；不复制装备规则，也不直接改写叠穿数组。

此前验证的作者版本 [v1.1.2](https://github.com/ANLINSTUDIO/Degrees-of-Lewdity-DolOptimization/releases/tag/v1.1.2) 默认关闭叠加服装。请在原版优化设置中自行开启；兼容包不强制开启，也不改变已有选择。未知版本、原管理模板不匹配或所需接口缺失时，不显示新增区，保留原版及扩展信息入口。

本包以 Soft & Wet 3.x — Kraft Work 为视觉基线。窗口外壳使用主 UI 的黑灰 Acrylic，内容不重复模糊，按钮与导航复用当前交互机制。关闭动画或 UI 时保留原操作，未知结构退让。资源与槽位适配不强行添加独立页面。

要求 `原版优化 >=1.1.1.2`、`DoLGameUI >=3.0.0` 和 DoL 0.5.12.13。最低声明与结构合同共同决定是否启用，不代表所有后续版本或组合均已验证。新增叠穿管理主要验证官方 v1.1.2，回归固定 1.1.1.5；Windows 真实游戏／Loader 与受控用例结果见仓库维护报告，不能当作 Android／iOS 实测。

按目标 Mod 选装，加载在目标 Mod 和 UI 之后。替换同技术名旧兼容包，每个身份只启用一个版本；回退时恢复原包并重启，不清空游戏数据。

构建：`python scripts/package-adapter.py compat/dol-optimization-soft-wet`。原节点、值、事件和业务逻辑由原 Mod 管理。
