# MapleBirchSoftWet 1.0.1

本次为本地研究候选，随当前测试组合检查 MapleBirch 5.5.4；最终真机覆盖和制品身份以本轮验证报告为准，尚未公开发布。

MapleBirch 云存档窗口外观，不读取或代管凭据，不派发云端业务。

本包以 Soft & Wet 3.x — Kraft Work 为视觉基线。窗口外壳使用主 UI 的黑灰 Acrylic，内容不重复模糊，按钮与导航复用当前交互机制。关闭动画或 UI 时保留原操作，未知结构退让。资源与槽位适配不强行添加独立页面。

要求 `maplebirch >=5.2.3`、`DoLGameUI >=3.0.0` 和 DoL 0.5.12.13。最低声明与结构合同共同决定是否启用，不代表所有后续版本或组合均已验证。当前开发验证范围见仓库维护报告；旧发行记录保留原证据，不能充当 1.0.0 的真机证明。

按目标 Mod 选装，加载在目标 Mod 和 UI 之后。替换同技术名旧兼容包，每个身份只启用一个版本；回退时恢复原包并重启，不清空游戏数据。

构建：`python scripts/package-adapter.py compat/maplebirch-soft-wet`。原节点、值、事件和业务逻辑由原 Mod 管理。
