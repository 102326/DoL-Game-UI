# ModHubSoftWet 1.0.1

ModHub 管理器外观，不改安装、排序、启停或市场业务。

1.0.1 修复手机列表和可用更新提示中的大块空白：原 ModHub 在窄屏将信息和操作上下排列，本包同步改为按内容确定信息区高度，保留桌面布局、完整更新文字与更新入口。同时补齐 1.8.0 顶栏的材质和选中文字颜色。替换旧兼容包并重启即可，主 UI 和 Host 无需因本修复更新。

覆盖已识别的模组管理、市场、说明、加载日志及帮助中心，以及更新提示、统计卡片、操作组和原生移到 body 的“更多工具”菜单；菜单仍使用原定位与事件。1.0.1 定向检查了手机上的 ModHub 1.7.6 和 1.8.0。其它自定义弹窗不据此自动接管。

本包以 Soft & Wet 3.x — Kraft Work 为视觉基线。窗口外壳使用主 UI 的黑灰 Acrylic，内容不重复模糊，按钮与导航复用当前交互机制。关闭动画或 UI 时保留原操作，未知结构退让。资源与槽位适配不强行添加独立页面。

要求 `ModHub >=1.3.0`、`DoLGameUI >=3.0.0` 和 DoL 0.5.12.13。最低声明与结构合同共同决定是否启用，不代表所有后续版本或组合均已验证。页面与输入检查不等于安装、启停、排序、市场交易或救援流程全部验收。

按目标 Mod 选装，加载在目标 Mod 和 UI 之后。替换同技术名旧兼容包，每个身份只启用一个版本；回退时恢复原包并重启，不清空游戏数据。

构建：`python scripts/package-adapter.py compat/modhub-soft-wet`。原节点、值、事件和业务逻辑由原 Mod 管理。
