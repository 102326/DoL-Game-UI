# ModHubSoftWet 1.0.4

为 ModHub 管理器、市场、说明、日志和帮助中心提供 Soft & Wet 4.x 外观。已识别的更多工具菜单、安装弹窗和时间点还原窗口也跟随主 UI 的 Acrylic、通透度及适用设置。

管理列表与帮助中心已有 ModHub 2.0.1 的 Android 检查。2.0.2 的时间点还原窗口按原结构适配，本版实际验证范围以对应记录为准。页面显示检查不等于安装、更新、排序、删除或还原业务全部通过。

需要 DoL 0.5.12.13、`ModHub >=1.3.0`、`DoLGameUI >=4.2.0` 及主 UI 所需 Host。将本包加载在 ModHub 和主 UI 之后，同一技术名只启用一个版本，重启后生效。最低版本声明不代表所有后续版本都已验证；未识别的结构保持原样。

本包保留 ModHub 的节点、输入值、事件、尺寸、滚动和业务。关闭主 UI 或移除本包可退回原外观；需要整包回退时恢复原包与顺序并重启，无需清空存档或 App 数据。
