# 旧 Lyra Goose 衣柜嘴部适配 0.1.5

适用于 **Lyra `0.5.11.9-1.0.0a-0815-goose-ucb` / DoL 0.5.11.9 / UI 2.2.2+**。0.1.5 将 UI 依赖改为最低版本，可与 UI 2.7 配套；原资源和业务代码不变。不用于 DoL 0.5.12.13，不是通用嘴部补丁。

导入 ZIP，不要解压，替换同名旧包，只启用一个版本。本包提前注入，监听 UI 的私有衣柜预览准备事件；UI 与目标 Lyra 仍需启用。重启后生效。旧 UI 2.0.3～2.2.1 用户仍可使用历史 0.1.4。

只调整新生成私有预览模型的 `mouth.srcfn`，不修改原角色模型、V/T、脸型、游戏图片或存档。指定 Lyra 不匹配或模型缺少嘴部回调时退出；没有准备事件时不做任何修改。禁用本包并重启可恢复原路径。

UI 最低版本不表示所有未来 UI 或第三方组合已验证。0.1.5 已检查 2.7 的事件准备位置、私有模型与监听合同，并通过隔离路径、未知资源、重复加载和清理测试；未在本轮重新安装旧 0.5.11.9 Lyra 做真机验证。

开发构建：`python scripts/package-adapter.py compat/lyra-wardrobe-mouth-soft-wet`。仅编译原有 TS 入口为清单中的提前注入 JS，不打包第二套 Runtime。
