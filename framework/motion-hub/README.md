# Stone Free Floating Hub Motion Lab

这是 Stone Free 3.0 第八轮的可选动态原型，不是正式 UI 更新。它保留当前 Soft & Wet 外观，通过扇形工具、空间转场和侧边停靠探索新的交互方式。

## 试用

使用研究构建输出的两个包：

1. `StoneFreeHost-0.1.2-experimental.mod.zip`
2. `StoneFreeMotionHub-0.1.3-experimental.mod.zip`

保留 ZIP，作为两个独立 Mod 导入测试环境，Host 在前。不需要安装其它研究工作台，不替换正式 `DoLGameUI`。Host 协议仍为 `0.1-experimental`；旧实验 Host 请先停用，不能同时加载多个实现。

这些是明确配对的实验包，包版本与公共协议版本分别管理。请先在独立测试安装中试用，不据此推断所有整合包或任意 Host 升级兼容。源码仓库的 `docs/STONE_FREE_3.0_DISTRIBUTION.md` 记录实际安装、更新、退出与导航证据；第八轮的临时加载记录保留其原有范围。

## 操作

- 点击右侧星形入口展开三个工具，再选择状态速览、状态对照或原版侧栏。
- 按住拖动，松手后吸附到最近一侧；拖进边缘提示区域会停靠为窄胶囊，点击胶囊恢复。
- “停靠侧边”提供无需拖动的操作方式。“恢复位置”只恢复本原型的位置。
- 点击空白、关闭详情或按 Escape 收起。键盘聚焦入口后，方向键可移动位置。
- “退出原型”释放本消费者及其自己创建的状态/侧栏适配，不卸载其它参与者或停止 Host。重载后，仍启用的 Mod 会再次出现。

位置只写入 `StoneFreeMotionHub.position.v1`。不能访问存储时仍可本次操作，但无法持久保存。减少动态效果的系统偏好会直接关闭过渡，操作路径保持可用。

## 原版与扩展边界

状态数据按需读取原游戏，没有平行游戏状态。状态速览和对照复用同一公开来源，原版侧栏工具仍通过已核对的原按钮执行。按钮被模态遮挡、身份失效或场景未就绪时退让；不会穿透遮挡或自动重试未知结果。

原型也显示其它参与者主动贡献的公开视图。超过三个视图或可用高度不足时，改用可滚动的紧凑工具列表。没有扫描或重新渲染未参与的第三方页面。

不包含穿戴、购买、战斗推进或存档操作。物理触控、真实 IME 和长期使用需要单独记录；浏览器点击、Android 受控输入及局部失效测试不能代替这些证据。
