# Stone Free Host 1.0.0-rc.1

这是 Stone Free Host 首个正式版本 1.0.0 的候选包。Loader 技术包名为 `StoneFreeHost`，现有公共协议仍为 `0.1-experimental`。Host 提供挂载、动效、主题与资源释放能力；游戏规则和存档由游戏及相应 Mod 管理。

## 配合 Soft & Wet 使用

导入本包和 `DoLGameUI-5.0.0.mod.zip`，Host 排在主 UI 前，每个技术包名只启用一份，然后重启游戏。从 4.5.2 升级时同时替换两个包。单独使用 Host 的 Mod 可以按各自的依赖说明安装。

## 回退

恢复原 Host、配套主 UI、原先使用的选装包和加载顺序，然后重启。需要旧包时可从 [Soft & Wet 4.5.2](https://github.com/102326/DoL-Game-UI/releases/tag/v4.5.2) 下载。许可见包内 `LICENSE`。
