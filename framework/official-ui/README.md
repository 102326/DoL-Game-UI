# Soft & Wet：官方 UI 融合候选

第十四轮本地研究包 `DoLGameUI-3.0.0-lab.14.mod.zip`，与 `StoneFreeHost-0.1.1-experimental.mod.zip` 配对。先启用 Host，再启用本包。不同时启用正式 DoLGameUI 或其它版本的官方 UI，不需要额外安装 Wardrobe Reference 或 Motion Hub。请使用隔离测试安装；这不是正式 3.0。

本包继承现有 Soft & Wet 界面，衣柜、服装店、战斗、社交/属性导航、存档列表和通用面板导航逐步接入公共 Host 的场景生命周期。这些区域接入公开挂载生命周期，原内容和操作仍由游戏执行。主题、侧栏及官方设置内部继续保留成熟实现，由整个消费者退出统一释放，不能据此宣称每个组件都已迁移。Host 没有内嵌进本包，公共协议未改。

本包恢复了正式 2.7 的服装店早期注入与四项 TweeReplacer 分页补丁，需要 TweeReplacer >=1.0.0。分页实验仍然默认关闭。包内保留 UI API v1 声明及原版回退；这不代表全部 2.7 页面、游戏版本和 Mod 组合已重新验收，也不能直接替代稳定版。

在衣柜中，主衣物按钮仍然单击穿戴。旁边的“参照”把 A 的显示资料收进边缘标签，之后可继续分类、搜索和浏览；点击另一件的“对照”展开相同字段的差异。返回不重建衣柜列表，A 留存至清除、离开场景或关闭衣柜。取消“空间转场”可对照普通打开路径；系统减少动态效果也保持同一功能。

比较只读取经过当前目录校验的显示值。A 标记为固定快照，B 标记本次读取；没有差异只表示展示字段相同，不代表隐藏属性或穿戴效果等价。跨部位比较不保证相互替换。没有试穿、装备恢复或另一套库存状态。

本轮按现有 Soft & Wet 的 Ocean、Acrylic 外壳和稳定轻卡片统一衣柜与商店。宽容器的衣柜对照放在自有侧栏，差异通过紧凑数值块显示；浏览列表仍可操作，窄容器使用底部面板。商店可以固定 A，再选择另一件对照原版名称、价格文字与名称行标记。顶部只保留参考标签和操作，比较内容放在商品详情中，关闭后 A 继续保留。商店对照是只读快照，不是购买结果或实时报价。

在界面设置中启用可选悬浮球，可以查看当前参与者的公共视图，并返回仍有效的衣柜参照。衣柜或商品固定参考后分别保留一份会话内显示快照，明确标记来源已离开；它不保留穿戴动作或恢复旧场景的能力，可单独清除。启用、隐藏、展开方式和重置入口继续可用；3.0 Hub 位置独立保存，旧位置保留。它不是强制入口，默认关闭。

缺少或不支持的 Host 时本包不启动；Host 退出会清理本消费者并恢复原版入口。停用包后重启与主动释放是不同路径，不承诺整包热卸载。现有官方 UI API v1 保留，实验 Host 协议仍是 `0.1-experimental`。

衣柜与商店共用取出、暂存和归位的运动规则，比较字段分步出现。商店可关闭空间转场；减少动态效果时仍使用相同原控件。对于已识别的普通衣物“购买并送到家 ×1～10”，本包只在原按钮执行后核对原金钱与衣柜变化，二者同时符合才显示已确认。无法核对时显示结果未知并阻止从本界面重复派发；请先核对原版，不要通过重开界面盲目重试。套装、未知目的地继续由原版显示结果，不额外确认。

完整验证范围、功能覆盖和限制见源码仓库 `docs/STONE_FREE_3.0_R14.md`。原版战斗演示的实际回合与随机遭遇、完整战斗结算分开记录；本轮不宣称物理手机触控、全部游戏组合或正式 3.0 验收通过。

本轮扩展普通多件送回的结果核对，数量滑块仍是原控件。没有用单件公式确认套装或其它目的地。原版导入/导出页识别补充原 export 入口，控件、值与事件不替换；显示存档面板不代表已执行存读档。设置说明见 `docs/UI_SETTINGS.md`，可选包说明见 `docs/OPTIONAL_ADAPTERS.md`。
