# Soft & Wet 4.1

黑灰 Acrylic、可调通透度、共享窗口交互与玻璃天气。4.1 保留已认可的 V1 设计、金属悬浮球和真实游戏操作，重点统一各页面设置并减少动态装饰牵动外壳重绘的开销。

## 安装

1. 保留需要的存档、原包和加载顺序。
2. 安装 Framework Host 与 DoLGameUI 两个 ZIP，无需解压，每个技术身份只启用一个版本，Host 放在 UI 前。
3. 按已安装目标 Mod 选装兼容包，放在目标与 UI 后，再重启。

当前游戏合同为 DoL 0.5.12.13，ModLoader 最低 2.100.0，TweeReplacer 最低 1.0.0。Host 使用 `>=0.1.2-experimental && <0.2.0`，本轮核对 0.1.5-experimental。最低版本与实际结构共同决定是否适配，不保证所有未来版本。玩家无需安装 Node。

## 使用

从侧栏或悬浮工具打开“界面设置”。Acrylic 通透度默认 60，在沉稳阅读与高通透之间连续调整；官方及完整兼容窗口跟随同轴。正文行距、段落与选项间距、正文宽度独立设置，默认保留原版正文。字号和按钮各自 50%–150%，不缩放原图片。

新安装默认显示 Hub、开启动画并平铺全部原战斗选项；已有明确选择保留。扇形工具悬空排列，辅助操作位于内侧，空间不足时保留可操作回退。衣柜单击仍直接穿戴，详情使用抽屉；参考快照不试穿、不恢复旧装备。商店继续使用原商品、报价和购买入口。

窗口天气来自游戏。已识别完整表面使用统一天气能力，动态前景与静态玻璃分层；设置、虚拟设备、正文和资源区域按角色保留差异。装饰不接收输入，减少动态及关闭动画仍能执行原操作。

4.1 对完整匹配的 ModHub 1.9.2 市场源复用有界依赖规则编译；不缓存推断结果，不改变作者 ZIP、安装或更新业务，未知源保持原生。该能力属于主 UI，外观适配包不接管业务。

## 数据与回退

UI 不迁移原游戏存档格式。保存、载入、文件与云端仍由原游戏或对应 Mod 处理；无法确认的数据不自动修复。衣柜、交易与第三方叠穿使用原入口，未知结构退让。

总开关可恢复原版界面，保留偏好与设置入口。整包回退请恢复备份包与顺序并重启，不清除 App 数据。其它 Mod 仍依赖 Host 时保留它；不承诺整包热卸载。

Host 公共协议仍为 0.1-experimental，UI API v1 保持；双包架构不变。ReOverfits 业务、全部战斗／交易、物理手机与 iOS、长期资源和功耗未穷举；部分第三方页面保留原外观。最新覆盖与问题状态以对应发行记录为准，不将短 rAF 采样写成 FPS 保证。

设置与适配说明见包内 `docs/UI_SETTINGS.md`、`docs/OPTIONAL_ADAPTERS.md`。原创代码、依赖、ModHub 片段与游戏衍生代码分别保留 LICENSE、THIRD-PARTY-NOTICES、MODHUB-PERFORMANCE-NOTICE 及 UPSTREAM-RENDERER 文件，不能互相替代许可。
