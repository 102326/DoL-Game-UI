# Soft & Wet：官方 UI 融合候选

第十轮本地研究包 `DoLGameUI-3.0.0-lab.10.mod.zip`，与 `StoneFreeHost-0.1.1-experimental.mod.zip` 配对。先启用 Host，再启用本包。不同时启用正式 DoLGameUI 或其它版本的官方 UI，不需要额外安装 Wardrobe Reference 或 Motion Hub。请使用隔离测试安装；这不是正式 3.0。

本包继承现有 Soft & Wet 界面，衣柜是首个通过公共 Host participant/mount/binding 管理的正式页面。其余页面仍保留原实现，不能据此宣称全部消费者化。Host 没有内嵌进本包，公共协议未改。

当前仅验证衣柜融合及代表性启动、回退路径。本研究打包不带正式包的服装店早期注入与 TweeReplacer 分页补丁，不能作为正式 2.7 全功能替代版安装。其它页面的完整制品合同留待对应迁移与最终发行整合。

在衣柜中，主衣物按钮仍然单击穿戴。旁边的“参照”把 A 的显示资料收进边缘标签，之后可继续分类、搜索和浏览；点击另一件的“对照”展开相同字段的差异。返回不重建衣柜列表，A 留存至清除、离开场景或关闭衣柜。取消“空间转场”可对照普通打开路径；系统减少动态效果也保持同一功能。

比较只读取经过当前目录校验的显示值。A 标记为固定快照，B 标记本次读取；没有差异只表示展示字段相同，不代表隐藏属性或穿戴效果等价。跨部位比较不保证相互替换。没有试穿、装备恢复或另一套库存状态。

缺少或不支持的 Host 时本包不启动；Host 退出会清理本消费者并恢复原版入口。停用包后重启与主动释放是不同路径，不承诺整包热卸载。现有官方 UI API v1 保留，实验 Host 协议仍是 `0.1-experimental`。

完整验证范围与失败收据见源码仓库 `docs/STONE_FREE_3.0_OFFICIAL_INTEGRATION.md`。物理触控、更多 Mod 组合与完整正式 3.0 验收不包含在本轮承诺内。
