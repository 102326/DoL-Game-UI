# Soft & Wet 3.0 — Kraft Work

`DoLGameUI 3.0.0` 本地 Stable 候选，等待负责人最终批准，尚未公开发布为稳定版。当前公开预发布是 3.0.0-rc.1，稳定版仍为 2.7.0。技术名仍为 DoLGameUI，原有 UI API v1 保留。

## 安装与升级

1. 备份存档，保留可回退的 Soft & Wet 2.7 安装包。
2. 在 ModLoader 中停用旧 DoLGameUI，导入并启用 Host 和本 UI 两个 ZIP，**不要解压**。Host 排在 UI 前，只启用一份同名 Host 和 UI。
3. 本 UI 支持 DoL **0.5.12.13**，需要 ModLoader **>=2.100.0**、TweeReplacer **>=1.0.0**。实际 Loader 验证版本为 2.101.1。
4. 最低 Host 为 **0.1.2-experimental**，推荐使用已公开的 **0.1.4-experimental** 原包；依赖表达式为 `>=0.1.2-experimental && <0.2.0`。
5. 按加载器提示重启，再载入进度并检查偏好。安装报告不代替实际加载检查。

NativeStatus、独立 MotionHub、WardrobeReference、Factory 和 Author Kit 均不是玩家必装项。可选外观兼容包按各自说明安装，不代表所有后续第三方版本已验证。

## 界面与操作

当前候选采用黑灰 Soft Acrylic、稳定阅读表面和可关闭的空间转场，不再提供三档质量选择。旧档位值保留供升级和回退使用，不限制官方新视觉。衣柜仍单击直接穿戴，已穿戴衣物的“衣物详情与特质”可单独打开抽屉；参考快照不试穿、不恢复旧装备，也不持有离场后的业务句柄。商店继续使用原商品、颜色、报价与购买入口，战斗继续使用原动作与结算；聚焦编辑 B 为可选实验，默认使用原版战斗布局。

Floating Hub 默认关闭。主题、字号、密度、侧栏、页面开关与存档显示偏好沿用；旧悬浮位置保留，新 Hub 使用独立位置数据。关闭动态效果后仍可执行相同业务。Widget、任意布局编辑器及全局动作底栏不属于本版交付。

R16-W01 修复保留：快穿和脱下通过当前原穿戴入口执行，避免绕过已验证第三方叠加规则；扩展叠加管理仍从原入口使用。未知结构退让，不猜测第三方私有业务。普通送回衣柜 1–10 件交易按原金额与库存确认；未知结果不自动重试，套装及其它目的地不套用该确认公式。

## 回退与数据

界面设置总开关可回到原版。回到 2.7 时，停用本 UI、恢复旧包并重启；无其它消费者依赖时可停用 Host。不要清除存档或偏好，不承诺整包热卸载。

不迁移原游戏存档格式。继续保留 `metadata.dolGameUI.gameTime` 及同命名空间中其它有效附加字段。保存、读取、导入导出及云端业务仍由原游戏或对应 Mod 执行。Windows 和 Android 的 RC 升级回退已有代表性证据；最终 Stable 包的本轮结果以外部 Gate 报告为准。

## 支持边界

Framework 公共协议仍为 **0.1-experimental**，没有长期 API 1.0 冻结承诺；官方 UI 的产品稳定性与公共协议稳定性分开。作者应核对协议、所需能力和具体 Host 版本，破坏性变化需要明确通知。Host 不依赖官方 UI，也不管理 Mod 加载、第三方状态或存档事务。

Loader 2.101.1 的预发布比较有已知限制，部分 0.2.0 预发布可能满足安装表达式，但不属于当前支持组合。消费者检查协议与能力，不能保证拦截所有错误 Host 包。Host 需要 AbortSignal.any 等环境能力，不支持时应回退。

物理手机与 IME 的完整设备覆盖、全部 Mod 与衣槽、所有交易目的地和战斗结束类型、长期性能、云端及文件选择未完整验证。部分社区 Patch、资源或 TypeError 告警仍需按具体场景判断，不能统一认定为 UI 缺陷或无害。新 Hub 位置落盘及回退读回没有本轮新增证明。

Host 0.1.4 沿用已公开的冻结字节，包内 RC 描述记录其当时状态，不因 UI 进入 Stable 候选而改写同版本包。Framework 不提供单包/双包混装或整包热替换。
