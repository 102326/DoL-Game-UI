# Soft & Wet 4.5（研发中，未发布）

黑灰 Acrylic、可调通透度、悬浮工具与玻璃天气，让 DoL 的常用窗口更清楚、更轻快。

## 安装

导入 Framework Host 与 DoLGameUI 两个 ZIP，不要解压，每个 Mod 只启用一个版本。Host 放在主 UI 前；兼容包按已安装的目标 Mod 选用，放在目标与 UI 后，再重启游戏。

适配基线为 DoL 0.5.12.13，ModLoader 需2.100.0或更新，TweeReplacer需1.0.0或更新。Host适用0.1.2-experimental至0.2.0之前，推荐使用发布页附带包。

## 使用

从侧栏或悬浮工具进入“界面设置”。Acrylic通透度默认60，可在沉稳阅读与高通透之间连续调整。正文行距、段落与选项间距、正文宽度分别控制；字号和按钮独立调整。

设置提供上下、左右布局。设置和属性窗口可拖动标题空白处，玻璃和内容带有受力与回弹反馈。普通换页直接显示，设置分类只保留20ms短淡入，衣柜直接进入。菱形玻璃悬浮球支持扇形和网格布局，扇形工具悬空排列，辅助操作放在内圈。拖动后可原地放下；持续顶边蓄力、沿边调整方向，松手弹射，飞行时可重新接住。

衣柜单击衣物直接穿戴，详情以抽屉展示。商店保留商品、配色、报价和购买入口，窄屏详情使用抽屉。窗口天气来自DoL游戏内环境，关闭动画或系统减少动态效果时仍可操作。

已有显示偏好继续保留。页面可单独切回原版，总开关保留设置入口。整包回退时恢复原包与加载顺序并重启，无需清空存档或App数据。

说明见包内 `docs/UI_SETTINGS.md`、`docs/OPTIONAL_ADAPTERS.md`、`docs/INSTALL_4.5.md` 和 `docs/RELEASE_4.5.0.md`。反馈与下载：[GitHub](https://github.com/102326/DoL-Game-UI)。
