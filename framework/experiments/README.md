# 共享 Vue 分发实验

这些 ZIP 只用于对照消费者自带 Vue 与共享 Vue 的成本和失败边界，不是默认安装方案，也不是稳定第三方 SDK。

使用同一套 Host、领域代码和 Vue 消费者源码。共享模式先启用原 `StoneFreeHost`，再启用 `StoneFreeVueResearch`，最后选择对应消费者。消费者的技术名称与自带 Vue 版本相同，不能同时启用两种版本。

运行库通过独立命名空间提供当前构建的 Vue 公共导出，每个消费者仍创建独立 App。没有共享游戏 State、Vue Store、主题或组件实例，也没有把所有 Mod 放进一个 Vue App。

本实验要求同一协议和构建所用的 Vue 版本。运行库缺失、不符或缺少所需导出时，消费者退出，不改用其它全局 Vue。此时不自动等待依赖出现；补齐加载顺序后重新加载对应消费者。这个严格检查用于固定输入对照，不是未来版本支持策略。

正常退出应先卸载消费者，再卸载运行库。运行库只撤销自己的公开入口，不接管已创建 App 的生命周期；已经捕获导出的消费者仍可能持有运行库，删除命名空间不等于内存卸载。外部命名空间不覆盖，外部替换的对象不删除。

在源码仓库根目录运行 `npm run framework:vue:build`，生成独立输出 `dist/framework-vue-comparison/`；共享版不替换默认研究 ZIP。`npm run framework:vue:test` 检查相同消费者行为、独立 App 与依赖异常。原 UI 2.7 和 API v1 不受影响。

`comparison.json` 比较一至四个已存在消费者。双方使用相同说明文本；共享方案额外运行库、依赖声明和许可证计入包体。这里只比较制品大小，不据此推断启动、内存、响应速度或所有 Mod 的升级成本。
