# P-B：Hub自由放置与边缘蓄力（隔离研究）

2026-11-05，以正式整合 `e1a47d2` 的球体、菜单、主题及Host为基础。负责人对自由放置给出正面反馈，并要求继续补齐原设计；当前新增边缘蓄力/瞄准/弹射，仍是隔离原型，未批准进入产品。未恢复已作废Study02/03，也不新增全局布局编辑器。

## 来源与变化

- 球体材质、扇形/网格、内侧按钮、展开效果、原生入口和生命周期沿用现役实现。窄屏沿用原来的网格回退，不声称每个尺寸都呈现扇形。
- 原档 `js/input.js` 的普通浏览态球体吸边，编辑态允许蓄力；`js/physics.js` 有压墙死区、180ms防误触、瞄准及有限反弹。本轮参考这些设计，独立实现单球状态机，不复制全局自由布局/碰撞世界。此前只说明浏览态吸边不够完整，不能据此删除编辑态效果。档案SHA256：`7f09cb06e86d6447da8b69960ba81446492c59ed471dcccc4621342e64686074`。
- 普通拖动原地落定、方向键24px、主动停靠/隐藏/找回保持。持续压入边缘超过4px并停留180ms才进入蓄力；34px有效短行程使屏内中心抓取可满蓄。沿墙瞄准±43°；松手300–1000 CSS px/s，最多2.2秒或4次碰撞，随后落定。不自动甩出普通拖动、不增加点击开菜单等待。
- 蓄力用现役球体的有限挤压、进度环及瞄准线表达；稳定充能后停止RAF，指针再动时唤醒。飞行中单击先接住，下一次点击开菜单；重抓从当前显示位置接管。Escape/失焦/场景失效/隐藏/旋转/减少动态可中断，不保存半次手势；正常落定或主动接住才保存。减少动态只做直接放置。
- 为隔离研究复制当前Hub组件和owner；如果采用，应将位置策略最小整合回现有组件，不保留第二套产品Hub。第三方View、场景Binding和原生操作仍走现有合同。
- 页面独立Storage facade将所有偏好写入 `Evo42.hub.preview.<variant>.` 前缀；只复制读取正式旧坐标，不修改正式键。自由位置另有版本化研究记录；未知版本保留且提示仅本次生效。此facade只用于研究页面，不是Host或产品存储方案。

## 复现

需Node26、锁定依赖和Chromium。样式依赖当前 `dist/framework/official-ui/style.css`；新设备先按仓库流程构建，不能只加载组件而遗漏生产主题。

```sh
node prototypes/evolution-hub-free/check.mts
node prototypes/evolution-hub-free/edge-physics-check.mts
node prototypes/evolution-hub-free/edge-check.mts
node prototypes/evolution-hub-free/record.mts
node scripts/preview-evo42.mts
```

打开 `/prototypes/evolution-hub-free/index.html?variant=free`（边缘候选）、`?variant=direct`（仅自由放置）或 `?variant=baseline`（现役吸边）；录像打印带 `run` 参数的 `compare.html` 路径。根页面仍是旧研究入口，使用完整路径。

direct/free两版录像执行相同普通拖放、顶边、瞄准、松手、开菜单和原生操作，1280/390 × 900、同等待、1×播放；独立录制不保证帧同步，不用于比较性能。原合同长录像只作诊断。新媒体位于忽略的 `tests/artifacts/evo42-hub-edge/`；上轮direct目录为历史证据，另一台设备需重建。

## 已验证与限制

Mac Chromium覆盖两宽度的原自由/吸边合同、菜单中心命中及44px区域、原生单次动作、存储隔离与销毁；新增短碰边拒绝、稳定蓄力停帧、沿墙瞄准、每帧有限/界内坐标、自然落定、真实指针重抓、单击接住及各类中断。另有390宽CDP触控模拟；纯状态机验证阈值、四边、非有限输入、不同dt与飞行上限。具体最终结果绑定现有报告的证据摘要，不能把中途通过代签后续修改。

初次缺生产主题、过渡中误采样与正式偏好写入问题已修正。边缘续批实际发现：取消回弹中重抓使用旧目标而非显示坐标、满蓄后无效RAF、减少动态通知晚于pointerup时误保存，以及飞行接住误开菜单；分别补接管、停帧、同步状态守卫和单击抑制。失败记录保留，不通过增加固定sleep掩盖。

不是全局布局、性能提速、所有缩放/第三方View组合或Android WebView验收。真实触摸、软键盘、安全区域、游戏侧栏遮挡及最终采用范围仍需对应环境/负责人判断。原有正式CI绑定未变产品实现；本新增原型只具有本机定向证据。
