## 复现

需Node26、锁定依赖和Chromium。样式依赖当前 `dist/framework/official-ui/style.css`；新设备先按仓库流程构建，不能只加载组件而遗漏生产主题。

```sh
node prototypes/evolution-hub-free/check.mts
node prototypes/evolution-hub-free/record.mts
node scripts/preview-evo42.mts
```

打开 `/prototypes/evolution-hub-free/index.html?variant=free` 或 `?variant=baseline`；录像脚本会打印带 `run` 参数的 `compare.html` 路径。根页面仍是旧研究入口，应使用这里的完整路径。

两版录像执行同一脚本、1280/390 × 900、同等待、1×播放；独立录制不保证帧同步，不用于比较性能。浏览器合同的长录像包含不同验证步骤，只作诊断，不冒充同操作对照。媒体位于Git忽略的 `tests/artifacts/evo42-hub-direct/`，另一台设备需重建。
