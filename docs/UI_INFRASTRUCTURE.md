# Soft & Wet 4.x — UI基础设施职责

本文件描述当前4.x职责，以实际接口和消费者为准。UI负责统一外壳、组件、视觉、浮层及自愿外观适配；Host负责公共机制；原游戏和第三方Mod保有业务状态、节点/事件及事务语义。具体[UI API](UI_RUNTIME.md)和[Host合同](HOST_4X.md)自包含，不要求读取旧版设计。

公共API与内部实现分开：DoLGameUI.ui API v1、Host protocol0.1-experimental、适配声明/SDK为外部可见合同；官方Store、组件私有状态、DOM索引、内部presentation lease不因此成为公开API。保持可选接入、能力检测、异常隔离、安全退出和原生回退。

新增整合需有多个真实消费者、最小接口与可验证收益；不要无差别集中监听/状态，不把ModHub依赖算法、第三方业务、UI具体展示搬入Host。沿[4.1公共能力调查](evolution/EVO-4.1-HOST-SHARED-SURVEY-2026-10-26.md)记录P1/P2/P3候选，未验证性能收益明确为假设。

原型不改协议与业务。正式迁移需逐消费者检查原节点/原动作、焦点/命中、几何、恢复/释放和整体一致性；不以文件数量或减少重复行数作为收益目标。
