## 发现与处理

- 发布收口时的悬浮球测试发现矮窗口菜单被新顶层战斗栏拦截。只限制可选菜单的可用区域，未让它抢占战斗层级。测试进一步确认不能把战斗栏高度用于重新映射位置，否则相同视口的球位置随栏高度漂移；保留原位置投影，只在必要时临时避让。修正后原断言和新增菜单边界断言通过。
- 手机横屏 CDP 截图采样两次超时；设备 Awake、App 前台、PID/Document 未变。拆开观察后 DOM/命中/触控正常，Android CLI 截图正常。保留失败收据；定位到截图采样路径，具体成因 Unknown。首帧图片处于进入动画中，按实际样式稳定后再次采样，未因过早画面修改 UI。
