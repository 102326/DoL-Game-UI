2026-11-18，公司 Mac 交接已由 Windows 在现有4.5分支接续。本批先处理指导修正和中性Hub工程试点。

## Current — 从哪里接手

- 研发分支 `feature/4.5-diamond-glass-hub`，目标分支 `main`，[PR #38](https://github.com/102326/DoL-Game-UI/pull/38) 为 Draft。Windows经正常fetch从交接头 `1f1df13e047c344874e392296434ab8068d9edb7` 接续，随后在 Windows 修复了静态入口恢复可见时多申请一帧的问题。
- 研发版本为 4.5.0，已发布的稳定版为 4.2.0。当前入口为蓝灰菱形玻璃，支持自由拖放和主动停靠。设置支持五种颜色和本机字体的预览、保存及恢复默认外观。架构取舍见[4.5 研发记录](RELEASE_4.5.0.md)，既有外观见[视觉基线](VISUAL_BASELINE_4X.md)。
- **公司 Mac 独有、未提交**：`scripts/build-standalone-surfaces.mjs`、`tests/standalone-surfaces.cjs` 已原样保留。它们不在远端交付中。忽略目录里的截图、原始日志及设计转交包也只在本机；跨设备验证可使用下表的 Actions 证据。
- **当前入口方向**：保留 4.5 双菱形，沿用短回摆和提亮。负责人已认可列表及单列弧线抽屉。两者现在可在「界面设置 → 入口 → 默认展开模式」选择，同一个「启用悬浮球」控制显示。
- **范围更新**：4.5不再为万能手机Mod扩大兼容开发。已有历史包及共享合同不在本批删除范围。

## Windows工程试点

`UI45_WINDOWS_RESUME_20261118_C_PILOT` 仅处理一次。保留Mac两份未同步文件的缺失状态，不生成替代文件。仓库指导已移除过时的4.2优先级约束，并区分现行实现、Claude参考与用户待定偏好。

新增回归复用 `tests/evolution-hub-integration.cts`：从真实Canvas像素检查中心与按钮中心一致，绘制层不拦截输入；覆盖自由悬浮、绘制表面尺寸变化、停靠与恢复。一次初始检查在关闭动画未完成时过早断言静止，失败现场保留；修正为等待现有关闭完成状态，不降低静止或命中要求。该检查不等同于C造型实现或视觉验收。

Windows本批使用Node 26.13.0与本机Edge 158.0.4370.26的中性页面。工具链严格类型检查与生成、Framework构建、Hub 14项检查及其中48组布局通过；新增绘制检查覆盖四种状态。Expected Lock只新增该检查并更新源码身份，原断言与反例保留。PR检查由本批推送触发，具体状态从[PR #38 Checks](https://github.com/102326/DoL-Game-UI/pull/38/checks)按提交核对，不以Mac旧成功代签。

本批没有运行真实游戏、设备或包安装，也没有视觉定稿、main合并或发布。负责人已提供完整原包，Windows 已核对源码和截图。

旧提交 `039f6a2` 的[标准 CI](https://github.com/102326/DoL-Game-UI/actions/runs/44332917545) 与[研究 CI](https://github.com/102326/DoL-Game-UI/actions/runs/44332917565) 均在恢复停靠后发现静态菱形申请金属动效帧。修复让静态绘制继续由尺寸和配置变化驱动。Windows 资源回归通过，并能拒绝恢复旧行为的反例。 修复提交 `b2714f5` 的[标准 CI](https://github.com/102326/DoL-Game-UI/actions/runs/44337509578)及[研究 CI](https://github.com/102326/DoL-Game-UI/actions/runs/44337509843)均通过。

标准 CI 在 `e516225` 的 ModHub 材质比较提前取样。[失败记录](https://github.com/102326/DoL-Game-UI/actions/runs/44354074598)使用的合成提交为 `66ef28a`。Windows 中性夹具重现了同一对数值：将关闭过的确认窗重新插入后，恢复面板已经 full，确认窗尚无适配标记，仍为透明且无模糊。下一帧重新识别确认窗后，两面同为 rgba(46,47,50,.94) 和 24px 模糊。测试现在先等确认窗自己的完整适配标记，再比较 0、100、60 三档；未修改产品材质。
