## 4.5 代码重构汇报 · 2026-11-21

本轮以公共设置和页面生命周期为范围，从已并入 main 的产品树接续。前五批的字体、13 项页面请求值、共享控件、ModHub 及衣柜改造见下文各自的提交记录。4.5.0 公开 Release 已撤下，旧标签仍指向上一棵树。
