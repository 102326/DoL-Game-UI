## 4.5 代码重构汇报 · 2026-11-21

本轮以公共设置和页面生命周期为范围，从已并入 main 的产品树接续。前五批的字体、13 项页面请求值、共享控件、ModHub 及衣柜改造见下文各自的提交记录。4.5.0 公开 Release 已撤下，旧标签仍指向上一棵树。

**同一个设置，无论从哪里进入，按同一规则解释。** 过去读取本地偏好和设置页实时修改分别判断数值类型、范围及废弃开关。现在都经 `src/theme/preference-store.ts:writePreference`，覆盖三项阅读设置、字体和按钮缩放、通透度、视觉档位及布尔偏好。视觉档位只接受 0、1、2，阅读数值取整并限制在各自范围。旧键和迁移标记继续识别，已退役的六个布尔项仍对旧读取方返回 false。是否保存、设置失败提示、字体单独刷新仍由相应调用方处理。

**启动和回退各有一个公共入口。** 整包启动时先读取偏好，再启动页面模块；主题独立启动也通过同一偏好入口绑定总开关。原先整包路径在主入口、主题控制器各绑定一次，现在每份启动快照只绑定一次。设置页切换总开关和主题启动失败时的应急恢复，现在都通过 `src/theme/page-preferences.ts:refreshPages` 按原顺序通知七个页面模块，每个模块单独隔离异常。忙态拒绝、用户请求值与实际生效值的区别仍由原模块处理。

**边界。** Host 提供 binding、claim、mount 和释放机制。UI 管理窗口尺寸和公共导航生命周期，兼容包注册目标节点及其语义。设置面板自身的导航布局与悬浮球位置分别存储；商店、衣柜仍负责归还各自移动的原生节点。此次没有移动这些职责，也没有改变 Host 协议或重画窗口。服装店商品切换等待仍单独记录在 PR #38。

**验证。** Windows 中性环境重新构建 UI 和 Framework，运行 ci:check、settings-ci、偏好持久化、材质和退役设置测试。新增同一组输入分别走公开设置 API 和本地存储启动的回归，断言读回值，包括小数、越界、非法视觉档位和退役开关。设置集成还覆盖模块缺席、衣柜忙态零写入、设置恢复、关闭和资源清理。本地首轮普通构建清空了 Framework 输出，材质和设置用例缺少正式样式；补建 Framework 后通过。独立旧 master-toggle 用例缺 tests/fixture.html，未完成；其结果不计作通过。此次没有实机测速或更新发布附件。

## 衣柜穿戴后的预览刷新 · 2026-11-21

在 `e0a09b7` 上复现了一种等待：穿戴已确认，衣柜第一次复制时侧栏 canvas 仍是旧图；同一 canvas 随后被原地重绘，衣柜要等下一次 125 ms 采样才能显示新图。本地候选 `44a474e` 仅在确认穿戴后，把首次 125 ms 拆成 48 ms 和 77 ms 两段，之后恢复原频率。一次穿戴最多多复制一次。仍沿用可见性检查和原有退出清理。

Windows Edge 159.0.4402.13，1280×1000，减少动态。沿用中性衣柜输入，点击真实衣物按钮，模拟 wear 链接只更新隔离变量，用两种纯色区别前后穿搭。固定预览区域截图核对 RGB；每版每种条件六次。下表为从点击到首次截得正确颜色的截图完成时间中位数（ms），包含采样开销。

| 侧栏输入 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 穿戴时立即画新图 | 38.0 | 38.1 |
| 延后 32 ms 在原 canvas 画新图 | 151.1 | 75.8 |

延后组侧栏新图的中位时间均为 35.4 ms，衣柜 canvas 首次观测到新像素从 140.6 降至 61.9 ms。证据限于该采样机制。真实服饰渲染、整机呈现、Mod 组合及服装店均未计入。项目既定测试路径缺少隔离游戏 HTML 和与之配套的渲染资源；玩家时延仍待对应环境复验。

### 平板实测补充

独立测试应用 0.5.12.13，Android 17、WebView 157.0.8103.52，已装 UI 4.2.0、Host 0.1.5-experimental。在同一 WebView 会话内轮换由 `e0a09b7` 和 `44a474e` 构建的衣柜控制器，其余已装 Mod、样式和游戏渲染器固定。每次恢复同一内存测试进度，用触控输入穿上同一件红色 T 恤，核对实穿物品与颜色。叠穿在首次准备时阻止主衣位改变，该次未纳入测量。

前后各五次交错采样，点击时刻以可信 click 为准。WebView 合成帧中，衣柜预览区域的红色像素增量首次达到换装前后稳定差值的 25% 时，旧版中位数 259.76 ms（208.44–274.09），新版 258.52 ms（220.22–266.91）。10% 和 50% 阈值下，新版中位数分别为 254.71 和 266.46 ms，旧版为 247.00 和 259.76 ms。此样本未显示稳定的实机提速。阈值识别及采样帧有时间分辨率限制；本轮只对照衣柜模块，整包安装与物理屏幕呈现未测。

### 本批结论

撤回 `44a474e` 的额外采样，衣柜运行代码恢复到 `e0a09b7`。同一回归在两版均通过：退出第一份镜像，第二份挂载后等 180 ms 再原地绘制，只有当前镜像更新。故意中断当前镜像的负例在最终颜色断言处失败。保留回归，未发现需要额外采样才能纠正的最终画面错误。

保留的实现用 Windows 中性衣柜测得四个节点（从点击起，ms），依次为业务选择、侧栏重绘、镜像新像素、首次取得正确颜色的区域截图。即时绘制两次为 1.2/1.2/13.1/29.4 和 1.1/1.1/10.1/27.4；控制延后 220 ms 绘制的两次为 1.2/224.3/258.4/268.4 和 1.2/221.3/262.3/277.0。业务处理为中性夹具输入，截图完成包含采样开销。完整 4.5 实机和服装店未在本批测量。
