# Soft & Wet 4.1 — 跨设备当前交接

更新：2026-10-26。当前分支 `research/perf-4.1-baseline`，关联 [Issue #31](https://github.com/102326/DoL-Game-UI/issues/31)。本批仅保存调查、规划与离线复验资料；没有性能优化候选，没有修改产品运行代码、main、Tag 或发行附件。

## Current — 当前状态

- [4.0.1 已正式发布](https://github.com/102326/DoL-Game-UI/releases/tag/v4.0.1)，运行源码基线为 `ff428b4d385b79f6c14fada9a65301157978aa6f`。本研究分支从该提交开始，后续文档提交不能冒称旧 CI 验证了新资料。
- 4.1 以性能为主线，允许研究 UI、DoL 运行逻辑及多 Mod 协同开销，前提是保留业务、存档及其它 Mod 的正常执行。当前仍处于调查和实施方案收敛阶段。
- [首轮调查](evolution/EVO-4.1-PERF-SURVEY-2026-10-26.md)有 33 次开窗、10 份 CPU profile、6 组稳态采样；[深度复核](evolution/EVO-4.1-PERF-DEEP-2026-10-26.md)另有 18 次总开关交错对照、4 份浏览器 timeline 与调用链匹配。两批保持独立，不混算。
- 当前 Android 测试环境：4.0.1、47 个报告中的 Mod、自然雷雨。作弊 UI 开启时最长 rAF 间隔约 300ms，关闭约 100–125ms；ModHub 关闭后仍约 217–233ms。它们不是呈现 FPS 或净收益预测，关闭 UI 也不等于最小 Mod 组合。
- [离线资料入口](evolution/perf-4.1-evidence-20261026/README.md)随本分支保存：合成输入、源码身份、调用链投影、复算工具、反例与上游许可。完整游戏、存档、原始 trace、设备序列号及私有备份不在 Git 中；本机原始记录继续保留。

## Decided — 已确定

1. 首批 A：共用开窗的写读批次，包括面板索引、可见性／几何、天气顶栏尺寸和焦点交接。实测每次 1 次挂载／2 次扫描，没有发现反复重挂载。
2. 首批 B：ModHub 依赖推断与更新签名成本。已有结果缓存，但 key 的计算发生在查询缓存之前；必须处理对象副本、原地修改、catalog 更新和结果隔离。
3. 第二批：保留视觉的持续天气更新优化；后续研究游戏 Renderer、宏及链接编号。不能直接跳过第三方回调、依赖校验或原生编号。
4. 保留已记录的双层悬浮扇形、撤销「紧凑状态间距」、保留「宽幅正文」及高级优化选项整理方向。具体范围见 Issue #31，尚未实施。
5. 当前授权为调查验证及保存到 GitHub，不是开始运行代码重构、合入 main 或发布 4.1。
