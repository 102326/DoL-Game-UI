# Soft & Wet 2.0.0 本地交付说明

日期：2026-10-04。沿用用户已接受的 beta.55 设计与业务代码。本次不扩大控件接管、不新增材质或依赖；公开仓库与公开发行版不变。

## 交付范围

- 一级游戏正文、战斗、衣柜和商店工作区保持 Solid；二级主菜单使用 Soft Acrylic；三级详情与已识别的小浮层按空间层级增强材质。
- 普通按钮 Neutral，选中使用局部 Ocean；内部实体轻卡片、特质轻条目、设置原控件、长文本稳定内容层。服装说明继续使用 V1 内容/行为。
- 存档默认双列；V2 才使用列表与详情布局。存档导入导出、当前 MapleBirch 5.1.1 已识别云界面仅按已有契约适配。
- 原版变量、控件值和业务回调仍为真相源；原版入口、独立功能开关、Smooth、关闭玻璃和减少动态保留。存档与已有专用页面的历史代理/移动按专项兼容边界管理，不宣称全项目没有 DOM 变更。

## 仍然明确保留的边界

- 本轮是当前平板/WebView和桌面原版/汉化代表性组合验收。当前版本手机物理设备、多背景长时间观看、GPU呈现/功耗/发热尚未完整验证，不能据短时 rAF 承诺满帧或加速。
- 初次详情静态 rAF 保留83.3/100ms尖峰；有效列表滚动采样最高25ms。没有滤掉尖峰来声称稳定120fps。
- 隔离整合环境已有资源404、remote-loader响应和skybox异常仍保留，测试通过不等于整合包零console/pageerror。
- 远程云端认证/读写、所有第三方 Mod、未来布局和平台原生 Select 弹出不在本次证明范围。未知内容优先原版/fallback。
- 公共发布、长期体验与后续缺陷修正独立于此次本地交付；不覆盖旧候选包和批准的 HTML/图片。

## 集中验收补记（2026-10-05）

此前“正式本地包”指本地安装交付，不表示所有最终验收结束。本轮继续补验，冻结 ZIP 和产品代码未改。

- 手机 25102RKBEC 已从 beta.14 留回退包并更新到 2.0.0；安装时游戏状态与模组顺序/启停保持，原生重载后在 Bedroom 建立新的只读验收基线。七个菜单各实际触摸打开/关闭两次，外壳单层 blur、正文无 blur、无横向溢出或可见错误。
- 存档详情在手机真实竖屏400×821、横屏821×352下检查100%/150%；申请200%按已有手机规则收敛到150%。关闭与操作按钮在屏幕内，详情和列表实际滑动可用。短横屏需要更多纵向滚动。检查后游戏状态、页面、偏好、存档记录、原菜单节点直接父级一致，菜单关闭，原旋转锁定恢复；未执行存档业务或游戏动作。
- 手机两分钟1/2/2/1档位观察：中位8.3ms、P95 8.4ms，最高83.1/83.2/91.6/108.3ms，184节点保持，无longtask。初次采样的列表被父区域裁剪，只作为滚动器/DOM压力观察，不作为完整可见列表的渲染成本证明。原尖峰和触摸定位安全拒绝均保留；滚动父区域后另行实际触摸通过。
