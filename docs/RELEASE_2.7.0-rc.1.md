# Soft & Wet 2.7 — Crazy Diamond

当前为 **2.7.0-rc.1 测试候选**，尚未正式发布。2.7 主要修复已有体验、整理设置和提高可靠性，没有加入自由布局系统或全局动作底栏。

## 主要变化

- 整理界面设置：阅读、材质、字体与按钮、侧栏、页面回退和兼容选项分组更清楚。诊断和进阶选项默认收起。
- 保留原有显示选择，字号与按钮仍为 50%–150%。已完成 2.6 缩放迁移的用户不会再次被重置；“恢复 100%”只恢复字号与按钮。
- 修复战斗操作栏可能随内容滚动或遮挡行动的问题，原版继续操作与回合规则保持不变。
- 修复服装店特质说明被筛选面板遮挡的问题。
- 保留可选悬浮球，新安装默认关闭。需要时在“界面设置 → 高级快捷工具”开启；可关闭、找回或单独恢复位置。
- 移除此前候选中的原版动作底栏入口；原型与 Widget 研究留待后续，不随本包启用。

## 安装与升级

适配 DoL **0.5.11.9 / 0.5.12.13**，需要 ModLoader **2.100.0+** 与 TweeReplacer **1.0.0+**。导入主包 ZIP，不要解压；升级时替换 `DoLGameUI`，不要同时启用多个版本，然后重启游戏。升级前建议备份存档。

兼容包按需选装，放在 UI 和目标 Mod 之后，见 [兼容包说明](OPTIONAL_ADAPTERS.md)。沿用原游戏状态和操作，不重新实现购买、换装、战斗或存档逻辑。

## 回退与限制

在界面设置中关闭 Soft & Wet 可回到原版，显示偏好保留。也可以独立关闭某个页面。衣柜操作处理中需等待结束；设置无法打开时，可在加载器中禁用本包并重启。

不保证所有整合包和 Mod 组合。旧浏览器不支持 Popover 时，战斗栏沿用原固定定位，仍可能受其它页面滤镜或变换影响。悬浮球不会接管未知第三方浮层。

本候选的跨设备验证结果另留在源码仓库，未验证场景不作为已通过的宣传内容。正式发布号与发布时间尚未确定。
