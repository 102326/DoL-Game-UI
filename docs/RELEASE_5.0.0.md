# Soft & Wet 5.0 — Stone Free

## 更新内容

默认的「静水暗玻」让正文和侧栏共用一套深色底。喜欢浅色时，可以在「界面设置」选择雾白玻璃或暖瓷。切换到实色后仍能看清窗口外壳、搜索框和列表的层次。也可以自选配色，导入本地 TTF 字体，先预览再保存，随时恢复默认。

设置窗口在关闭途中可以直接重新打开。雨雪天气下，此时玻璃上的天气会接着当前变化继续播放。服装店搜索在中文选词、键盘弹出和视口变矮时会保留输入焦点；宽屏在右侧看商品，窄屏从底部打开详情，关闭后可以接着挑。

悬浮球换上双菱形表冠，打开时内外两层向相反方向轻转。可以拖到顺手的位置，或半收在左、右边缘，轻点露出的部分即可恢复。列表和弧形抽屉都可以继续使用。

## 安装和升级

下载 `StoneFreeHost-1.0.0-rc.1.mod.zip` 和 `DoLGameUI-5.0.0.mod.zip`，直接导入 Loader，把 Host 排在主 UI 前，再重启游戏。从 4.5.2 升级时请同时替换这两个包，保留原包和加载顺序。ModHub、MapleBirch、原版优化、Cheat Extended、ReOverfits 及指定 Lyra 的适配包按需选装。[安装步骤与选装说明](https://github.com/102326/DoL-Game-UI/blob/research/5.0-host-prototypes/docs/INSTALL_5.0.md)

## 使用提醒与回退

适配基线为 DoL 0.5.12.13，需要 ModLoader 2.100.0+ 和 TweeReplacer 1.0.0+。同名 Mod 只启用一份。部分服装商品切换后仍需稍候。需要回退时，恢复原 Host、4.5.2 主 UI、选装包及加载顺序，再重启游戏。[下载 4.5.2 稳定版](https://github.com/102326/DoL-Game-UI/releases/tag/v4.5.2)
