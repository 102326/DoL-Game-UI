> 本文封存各轮视觉研发决定、失败和验收状态。后续开发以 [3.x 视觉基线](VISUAL_BASELINE_3X.md) 为准；下文的候选状态和早期方案不得覆盖当前决议。

2026-10-18，依据负责人《最终视觉方向重置与完整设计执行计划》。本文记录当轮官方 UI 的视觉基线。Stable Visual Gate 仍为 Blocked，须由负责人查看真实游戏并确认。

当前接续：保留成熟页面结构，统一已识别的侧栏入口和控件状态，深化人物窗口的实际分组导航；Hub 收敛为星簇主体与工具带清晰度的融合方案。设置正式支持上下、左右两种布局，共用原控件、偏好及预览。见[全局交互与设置双布局结果](KRAFT_WORK_3.0_INTERACTION_DUAL_LAYOUT.md)。下文两种 Hub 候选保留为历史对照，不再作为两套正式菜单维护。

## 已取代的规则

Ocean 不再是主体材质的默认颜色。旧蓝灰大面积表面、冷色雾、强白描边和常驻外扩辉光不作为设计依据。柔和蓝、绿、紫等局部交互色继续允许；不得把黑灰主体理解成全界面去色。R12 及此前报告保留为历史记录，其中相冲突的视觉结论已被本决议取代。

官方 UI 使用黑色和中性炭灰；阅读内容有稳定表面，临时菜单和窗口让真实游戏背景受控参与。强调来自明暗、形态、位置、局部色彩和运动。保留游戏链接、状态和商品颜色的真实语义，不统一去色。

第二轮保留已认可的设置成果，以属性页顶部、页签和导航的 Acrylic 为视觉锚点。属性正文适度增加透感；社交卡片通过底层减重、间隙、细边缘与浅阴影分层；商店标题、主体、分类、商品与 Hub 采用同一材质家族。卡片不逐个追加模糊，不改变原节点和业务所有权。

第三轮分别处理特质与成就。特质窗口采用角色信息页宽度和适度紧凑的最小高度，减少工具区重量，单张特质保留有限宽度；成就使用双列收藏陈列、明确的徽章／名称／说明／日期层级，窄屏改为单列。两页保留原节点和真实状态，仅增加展示样式。此为 Codex 的待验收实现，详见[第三轮专项结果](KRAFT_WORK_3.0_ROUND3.md)，不代表负责人已批准视觉效果。

第四轮将动效扩展至 Hub 与角色窗口、商店分类与详情、衣柜、可选战斗 B 及严格匹配的卧室原入口，使用实际选中与原操作结果驱动反馈。实现、Android 视频、业务边界和有限性能观察见[游戏主界面动效结果](KRAFT_WORK_3.0_GAME_MOTION.md)。Visual Gate 仍待负责人验收。

此前 R5-A 交付「形态展开」与「空间交接」两种 Hub→属性候选，当时仅通过评审标记比较，见 [R5-A 样板对比](KRAFT_WORK_3.0_R5_HUB_STUDIES.md)。其局部评审范围已被本轮全局整改授权接续，不再作为限制全局推广的依据。

上一轮以成就页为锚点减轻设置黑底，并让 B 真实内容较早进入，见 [R5-A 材质与交接深化](KRAFT_WORK_3.0_R5_MATERIAL_HANDOFF.md)。负责人随后明确该程度仍不足，本轮改为横向设置分类、连续控制行和紧凑预览，并重做 Hub 造型；成熟材质与反馈逐步推广到正文、侧栏、商店和衣柜。具体差异、默认体验、两种 Hub 候选及未覆盖范围见 [全局视觉统一首批整改](KRAFT_WORK_3.0_GLOBAL_VISUAL.md)。不得把单窗口或共享 CSS 的存在当作全局视觉完成，Visual Gate 仍为 Blocked。

设置导航使用单个 SVG 环绕焦点，在选项间连续迁移；柔和青绿与淡紫的轮廓缓慢流动。按钮仍保持深色，正文不持续移动。窗口关闭时停止流动，关闭动画或系统 reduced motion 时保留静态选中提示。设置内容保留完整空间转场，允许连续操作中断。详见[第二轮结果](KRAFT_WORK_3.0_ROUND2.md)。

正式设置移除流畅／均衡／华丽选择器，默认完整表现力。旧 `visualTier` 数值仍读写保留，官方入口忽略其效果限制；独立玻璃与动画开关继续生效，系统 reduced motion 优先。经典 2.7 入口保持旧合同。

## 本轮实现边界

- 设置：任务分类、当前设置及实际组件预览；整个窗口打开／关闭和分类内容参与转场。离开的设置区 inert 且 aria-hidden；重复操作取消旧动画。
- 战斗 B：可选，`combatFocused` 默认 false，关闭时使用实际原版布局。宽屏为安排列表和当前原控件，窄屏通过 Grid 在当前摘要下展示同一编辑区。动作命中位置在转场时保持稳定；原 radio、目标、Continue 和业务校验不变。
- Hub：主球、工具外壳、展开与停靠共享中性材质。已有拖动、焦点、原入口和页面离开清理继续有效。
- 衣柜、商店、侧栏与常用浮层：沿用有效结构，更新官方材质和选择提示；不重新生成原游戏业务。
- 背景层级：设置使用原生 dialog backdrop 模糊与对比变化，不对整个原游戏树施加 transform，以免改变第三方 fixed 控件坐标。

公开 UI API v1、Host 和实验协议不升级。`getVisualTier()` 在官方入口继续使用兼容值 `Fancy` 表示完整模式；这不是新的玩家档位选择。`getTheme().tokens.ocean` 保留旧键，官方 UI 对应中性 `--dgu-accent`，第三方应查询实际 capabilities，不据旧名称推断颜色或效果。

## 验收与证据

Done 是完成材料、设置、可选战斗 B、Hub 和常用页面整合，在授权 Android 测试版验证代表性功能、动画中断、清理、窄视口及关闭动画。物理手机未接入时，仅报告受控窄视口，不称手机触控验收。

测试通过仅支持功能与交互结论。视觉、负责人验收保持待确认。本轮不覆盖 Stable 2.7、不改公开 RC、不推送／合并／Tag／发布，不修改私人长期存档。
