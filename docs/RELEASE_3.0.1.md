# Soft & Wet 3.0.1 — Kraft Work

本次维护更新统一默认体验、兼容包材质，并修复战斗选择器挤压和存档窗口的视口边界。

## 更新内容

- 新偏好默认启用战斗界面与动画，原版动作控件平铺显示。战斗 B 聚焦编辑仍为默认关闭的可选实验；已有关闭偏好保留。
- Floating Hub 新偏好默认显示。已保存的关闭或隐藏选择不变，可在界面设置的“入口”中调整。
- 战斗口部动作下拉框在支持的浏览器中使用深色 Acrylic 原生选择弹层，修正文字和箭头被挤压的问题。值、选项、禁用语义及事件仍由原 Select 提供；不支持的引擎保留系统选择器。
- 修复自有存档视图在低高度窗口中被内容撑出视口、底部无法触达的问题。保存与读取业务不变。
- 六个当前配套兼容包统一为 1.0.0。四个外观包采用 3.x 共享材质，ReOverfits 继续复用主衣柜；Lyra 嘴部包是资源适配，没有需要美化的窗口。
- 加入 GitHub Actions：类型／合同、业务与动效回归、构建、ZIP 元数据／依赖／许可证和 SHA-256 检查。没有自动发布步骤。

## 安装与范围

主 UI 技术名为 `DoLGameUI`，版本 3.0.1。仍需独立 Host：`>=0.1.2-experimental && <0.2.0`，推荐已公开的 `StoneFreeHost 0.1.4-experimental` 原包。ModLoader 最低 2.100.0，TweeReplacer 最低 1.0.0；当前游戏适配基线为 DoL 0.5.12.13。最低要求不等于全部后续版本均已测试，Loader 的预发布版本比较限制仍在。

备份旧包和存档，停用旧 UI 与同身份兼容包，导入新 ZIP，确认 Host 在 UI 前、兼容包在目标 Mod 与 UI 后，再重启。不要解压 ZIP，每个技术身份只启用一个版本。回退时恢复旧 UI 和配套旧兼容包，无需清除游戏数据。

兼容包按目标 Mod 选装，具体边界见 [兼容说明](OPTIONAL_ADAPTERS.md)。CE 主要面向原作者版，另行标注独立维护 rebuild.30；二者技术名相同，只启用其一。旧 Lyra 0.5.11.9 专用包不属于本次组合。

## 验证与已知限制

维护改动已有 Windows 受控模块、构建、包检查及 Android 局部选择器证据。它们不等于全部业务、物理触控、所有 WebView 或真实 iPad 验收。候选安装与负责人视觉确认单独记录；完整范围见仓库 [维护验证记录](https://github.com/102326/DoL-Game-UI/blob/main/docs/KRAFT_WORK_3X_MAINTENANCE_20261019.md)。

当前选择器仅覆盖已检查的战斗口部动作控件，不接管未知第三方 Select。存档窗口的真实 iPad 历史反馈仍待该环境复验。`selectedWardrobe` 历史异常、部分社区告警与长期资源增长的未归因部分继续保留，不宣称本次全部解决。原始 3.0 天气、衣柜和交易验证仍限于其已有代表场景。

项目许可、上游渲染代码声明及依赖署名随包保留。反馈请前往 [GitHub Issues](https://github.com/102326/DoL-Game-UI/issues)，提供版本、环境和复现步骤；不要公开上传私人存档、账号或未获授权的第三方 Mod 包。
