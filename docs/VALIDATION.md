# 1.0.3 正式版验证说明

发布日期：2026-09-29。由 1.0.3-preview.6 收口，正式版仅调整版本与文档。

- 战斗紧凑布局、高亮同步、ResizeObserver 清理回归通过；原节点与动作选择保留。
- 衣柜五视口及宽窗口窄容器回归通过。绘图定义按需复制与全量复制的十个桌面样例结果一致。
