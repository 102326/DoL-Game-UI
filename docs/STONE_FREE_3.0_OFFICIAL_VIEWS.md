# Stone Free 3.0：官方外壳接入公开视图

2026-10-17。基于 `261372cfbaa51ee613e90522e015bda223cb929d`，限定改造可选研究包 `StoneFreeSoftWetSurface`。正式 UI 2.7、API v1、实验 Host、SDK、游戏业务和存档均不修改。

## 实现与边界

“Soft & Wet 工作台”通过 `DoLGameUI.ui` API v1 打开 Drawer，使用 `host.views()` 接收主动贡献的视图。它不再读取固定状态 schema 并手工渲染三个字段。Vue 消费者复用 `ViewOutlet.vue`，提供者仍拥有各自的挂载与数据；官方外壳不获得私有 Store、原控件或可变游戏对象。

关闭、场景绑定失效、主题关闭和包退出都会清理贡献实例、来源订阅与模态租约。单个视图失败显示局部回退；撤销声明会移除视图，同名重新声明会建立新实例。迟到的异步初始化不能复活已关闭内容。

侧边布局和官方 Drawer 可以使用同一贡献而保持实例独立。官方模态打开时浏览器负责 top layer 和焦点语义；不增加全局输入或布局仲裁器。未知、未主动贡献的 Mod 内容仍不接管。

这个可选包改为自带 Vue，ZIP 补入对应许可证。构建样本的 JS 约 66.80 kB；它替代此前约 2.47 kB 的手工快照桥，代价是更大的独立包。采用此实现是为了复用已有视图生命周期，不据此要求所有 Mod 共享 Vue 或迁移所有成熟官方页面。协议继续为 `0.1-experimental`。

## 实际验证

使用现有依赖，无新增安装：

- `npm run framework:build`：Vue/TS、Vite 与研究 ZIP 检查通过。
- `npm run framework:test`：32 组通过，其中新增官方贡献组合、撤销/重声明、局部失败、场景和主题关闭、双布局独立实例、异步迟到和 Surface 拒绝等检查。
- 浏览器运行证据：`tests/artifacts/stone-free-foundation/browser-1792170732411/result.json`。同目录 `official-390.png` 显示 390px 官方 Drawer，无主要水平溢出。夹具只加载 Surface CSS，不作为完整主题配色验收。宽屏 1280×1000 下验证侧边对照和官方对照数据独立。
- 平板运行证据：`tests/artifacts/stone-free-foundation/android-1792170701919/result.json`。M367FC、Android 17，独立 App `com.vrelnir.dol.lyra.uicompat051213`，DoL 0.5.12.13、正式 UI 2.7.0。

平板临时加载 Host、状态来源、对照及官方外壳四个自有构建。标准 Paisley Park 6.1.0 `web-click` 打开和关闭 Drawer；三项显示值与原状态一致，两个公开视图同时存在，无横向溢出。原生截图已查看，关闭后贡献挂载为零；完整退出后没有 Host、自有根或等待消费者。未持久安装 Mod、重载 App、执行游戏动作或读写存档。

这轮只补目标接入，不重跑商店、战斗、Factory 或共享 Vue 实验；这些未改变。前几轮的有效证据沿用原范围，不能替代本轮官方接入结果。

## 失败与修正

开发时两处断言先后用了错误的公开视图 ID 和错误的 Runtime 调用路径：实际为 `NativeStatus:status`、`officialRuntime.api.rescan()`。根据源码修正测试后通过，没有修改业务实现迁就断言。

双布局检查还真实遇到点击拦截：侧边工作台位于右侧，原官方研究入口也固定在右侧。390px 和 1280px 检查均被侧边面板覆盖，仅扩大窗口不足以解决。将官方研究入口移到左侧后，宽屏原点击路径通过，没有强制点击或调整第三方层级。窄屏面板仍可能覆盖外部操作，关闭面板再操作是保留的边界，不宣称所有布局能在手机并排使用。

前述初次失败保留在执行输出中；基础测试此前使用固定 `browser-tests.json`，本轮改为每次唯一目录并保存失败收据，后续不再覆盖该固定文件。此变更只涉及项目测试制品，不新增日志框架或 Tools 功能。

## 结论

本轮官方外壳接入已完成。真实 Android 结果证明当前代表性接入和清理；物理手机触控、IME、持久安装更新、真实第三方作者采用及其它版本组合未验证。实验结果不构成全部 Stone Free 3.0 的发布验收，也不改变共享 Vue 默认分发或正式 API。
