# Soft & Wet 4.5.1

服装店现在会按屏幕宽度展示衣服：平板和电脑在右侧看款式与配色，手机从底部打开详情，返回后可以接着挑。双菱形悬浮工具可以在列表和弧形抽屉之间切换。设置、特质、成就和 ModHub 切页时，窗口也能保持原来的大小。

## 安装与升级

首次安装，请下载 `StoneFreeHost-0.1.5-experimental.mod.zip` 和 `DoLGameUI-4.5.1.mod.zip`，直接导入 Loader，无需解压。把 Host 排在主 UI 前，重启游戏即可。从 4.2 升级可以保留原 Host，用新版主 UI 替换旧 UI。如果装过 ModHub、MapleBirch、原版优化、Cheat Extended 或 ReOverfits 兼容包，请一并替换对应的包，放在目标 Mod 和主 UI 之后。指定 Lyra 的嘴部资源包可以沿用。

## 使用提醒

适用于 DoL 0.5.12.13，需要 ModLoader 2.100.0+ 和 TweeReplacer 1.0.0+。每个同名 Mod 只启用一个版本。悬浮工具的布局可在侧栏「界面设置」里切换；连续挑选服装时，个别商品的预览仍可能需要稍等片刻。
