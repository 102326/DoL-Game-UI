# Soft & Wet 可选兼容包

按已经安装的目标 Mod 选装；本项目不包含第三方主 Mod。Host 放在主 UI 前，兼容包放在目标 Mod 与 UI 后，每个技术身份只启用一个版本，ZIP 无需解压。

4.x 的官方与完整兼容窗口共用 V1 黑灰 Acrylic、通透度轴及适用的字号、对齐和动效设置。正文、虚拟手机与衣槽资源保留必要区别；未识别的结构保持原生。未知页面不会因选择器相似而自动接管。

| 包 | 作用与边界 |
| --- | --- |
| ModHubSoftWet | 管理器、市场、说明、日志、帮助及已识别工具／确认／时间点还原浮层外观 |
| MapleBirchSoftWet | 云存档页面，云端操作仍由原 Mod 执行 |
| DolOptimizationSoftWet | 存档卡片、描述编辑与分页，结构匹配时接入作者叠穿管理；无效日期只在能确认时间时修正显示 |
| CheatExtendedSoftWet | 原作者 CE 与单列支持的独立 rebuild.30 外观；二者技术名相同，只启用一个 |
| ReOverfitsSoftWet | 额外衣槽接入主衣柜与商店，不另建衣柜 |
| SmartPhoneSoftWet | 原 SmartPhone Alpha 外壳、已识别普通组件及 debug 窗口；保留作者壁纸，不铺天气，不适用 Omega |
| LyraMouthCompat051213 | 指定 Lyra 嘴部资源，无独立界面，也不依赖主 UI |

具体包版本和依赖以对应发行附件、`boot.json` 为准。常规最低目标为 ModHub 1.3.0、MapleBirch 5.2.3、原版优化 1.1.1.2、CE 1.20.3、ReOverfits 4.1.1；最低声明不等于任意未来版本都通过。SmartPhone 当前明确接受 Alpha 0.3.91／0.3.91.1；嘴部资源限定 Lyra `0.5.12.13-1.0.1a-1004.1-goose-ucb` 与 MapleBirch `>=5.2.3 <6.0.0` 稳定系列。

既有完整组合检查含 ModHub 1.9.2、MapleBirch 5.6.2、原版优化 1.1.2.1、CE 1.20.3.1-rebuild.30 和 SmartPhone Alpha 0.3.91.1。设置、已识别管理窗口及存档页面展示已有代表性实机检查；未据此宣布安装、更新、作弊、云端写入或全部手机业务通过。ReOverfits 目标本轮未安装，保留合同与受控检查边界。 4.2现场已更新至ModHub 2.0.2，管理列表、帮助中心和原生时间点还原窗口已检查；还原窗口的设置联动由ModHubSoftWet 1.0.4配合UI 4.2提供，安装与还原业务仍由ModHub处理。

ModHub 依赖规则优化在主 UI 的独立早期入口实施，外观包继续只负责呈现。仅完整匹配已审 1.9.2 市场源时复用规则编译，未知版本或源码变化回到原路径，不缓存依赖结果，也不改安装或更新业务。

关闭主 UI 或移除适配包后保留原入口；整包回退请恢复原包和顺序并重启。不要清空游戏数据。
