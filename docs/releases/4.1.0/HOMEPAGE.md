**快速流畅，华丽精致，感知舒服。**

Soft & Wet 为 Degrees of Lewdity 提供黑灰 Acrylic 界面，让背景融入玻璃，同时保持正文、控件和原游戏操作清楚可用。

4.1 将材质与设置推广到更多已适配页面，提供连续通透度、阅读排布和悬浮工具布局，并减少动态天气牵动玻璃外壳重绘的开销。

[下载最新版本](https://github.com/102326/DoL-Game-UI/releases/latest) · [反馈问题](https://github.com/102326/DoL-Game-UI/issues)

> 普通玩家需要 **主 UI + Framework Host** 两个 ZIP。兼容包按已安装的目标 Mod 选用，各 `.mod.zip` 均无需解压。

## 核心体验

### 一套 Acrylic，连续调节

“Acrylic 通透度”从 0–100 连续调节，默认 60。向左更沉稳，向右更通透；保持同一套 V1 设计和清晰文字，官方与完整兼容窗口跟随同轴。

正文行距、段落与选项间距、正文宽度分别控制，默认跟随原版正文；选项可按习惯靠左或居中。字号和按钮各自调节，图片保留原尺寸。

### 窗口与玻璃天气

上下、左右设置共用真实控件、分类和自动保存。已适配窗口的材质、导航、表单与动效协调，长内容保留滚动，装饰不接收点击。

雨珠、细雨、霜羽及特殊环境来自游戏内天气。动态装饰与静态玻璃分层，保留已认可的雨量、速度与光学表现；关闭动态或系统减少动态时仍可操作。

### Floating Hub

金属球回旋带出真实工具。扇形按钮悬空排列，辅助操作位于内侧；网格继续保留，空间不足时以操作可用为先。支持拖动、停靠、快捷入口、键盘和关闭恢复。

新安装默认显示，已有关闭或隐藏选择保留，可从界面设置中找回。

### 游戏与常用界面

| 界面 | 主要体验 |
| --- | --- |
| 属性、社交、特质、成就、日志与统计 | 统一材质与导航，保留原链接、表单和语义颜色 |
| 商店与衣柜 | 商品选择、报价、单击穿戴、预览与详情抽屉，沿用原业务 |
| 战斗 | 新安装默认平铺全部原控件，聚焦编辑可选，保留既有偏好 |
| 存档、导出／载入与已适配云存档 | 协调的页头与内容承载，仍走原保存和文件路径 |
| 选项、作弊及已识别兼容窗口 | 跟随适用设置，未知结构保留原生 |

本项目不改游戏价格、穿戴规则、战斗结算或存档格式。存档异常无法确认时不自动修复，保留原版入口。

## 安装与升级

1. 保留需要的存档、原包与加载顺序。
2. 每个技术名只启用一个版本，Host 放在主 UI 前。
3. 按目标 Mod 选用兼容包，放在目标与 UI 后，再重启。
4. 更新有变化的包；未变包无需为版本统一而重复安装。具体版本和下载名见发布页。

当前游戏合同为 DoL 0.5.12.13；ModLoader 最低 2.100.0、TweeReplacer 最低 1.0.0。Host 使用 `>=0.1.2-experimental && <0.2.0`，最低版本与实际能力共同决定是否适配，不保证所有未来版本。玩家无需安装 Node。

## 回退、限制与许可

回退时恢复原包和顺序并重启，不清空存档或 App 数据；其它消费者仍依赖 Host 时保留它。部分第三方页面保留自己的风格，更多设备和全部业务未穷举；短采样改善不构成持续 FPS 或功耗保证。当前已知问题与覆盖见对应发布页。
