# 原版常用动作底栏：首批原型

2026-10-13，用户在首轮研究后明确授权尝试常见原版动作的底部入口，Mod 新增动作暂不适配。这是新增功能，不是已复现 Bug 修复。

## 本轮范围

仅支持普通 Bedroom 页的 Wardrobe、Mirror 两个原版导航目标，默认关闭。设置在“主题与阅读 → 原版常用动作底栏（实验）”。本轮手机测试实例已开启，便于直接查看。

原链接、父级、顺序、业务处理器保留；底栏按钮调用当前原节点 `.click()`，不调用 Engine.play、不写游戏变量，不复制 preMirror、时间、衣物、保存或购买逻辑。公众 UI API v1 不变。

只接受唯一活动页面、唯一直接子级 passage-content，以及其中唯一、直接、可见的原链接绑定。按页面和 data-passage 识别，不猜中文文字。隐藏、禁用、重复目标、陌生包装、未知页面和战斗结构不投影。点击时重新核对页面、节点、标签与目标；已移除或改变的绑定拒绝执行。

每个当前页面最多派发一次，未知结果不自动重试。页面没有变化时保留禁用按钮与提示，原链接仍可使用；关闭再开启不能清空这一锁。新原版页面身份出现后重新读取绑定。

底栏只拥有自己的按钮和一个尾部留白节点，退出、关闭或 destroy 时移除它们；不搬动原节点。监听范围为当前 passages，未使用全页面 Observer。原版或设置弹窗出现时隐藏，关闭后恢复。悬浮球对已知底栏避让。

**来源边界：** 这不是所有 Mod 的 provenance 判定。第三方若直接改写原版 Bedroom 的同一链接，底栏仍以当前原节点/处理器为准；不能声称已鉴别所有注入。陌生目标、重复目标及不同结构不适配，继续从原位置访问。

## 部署与未覆盖

候选 ZIP 已写入手机 ModLoader 存储并复读确认，原包有本地备份，加载顺序/隐藏列表未变。为保留当前卧室现场，本轮没有重载页面；实际体验使用当前候选 JS 与仅新增底栏 CSS 的临时预览。不能把这个证明写成完整包冷启动已验收。

不新增 API SDK，不执行 GER Goal，不清理历史 Effect/Store。所有现场 JSON、截图、临时配方和备份均在忽略目录 `tests/artifacts/stone-free-lab`，不进入用户包。

本轮尚未覆盖该底栏在真实平板/PC、手机横屏与 IME 下的完整操作，也未扩大常见动作清单。其余剧情链接、特殊镜子目标、卧室以外地点、业务消耗动作和 Mod 动作均为明确未支持，而非推断兼容。
