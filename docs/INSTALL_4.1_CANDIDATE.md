# 安装与验收 Soft & Wet 4.1

当前是负责人验收前的本地候选，尚未公开发布。正式安装前保留原包和顺序；优先在独立测试 App 试用，不清空数据。

## 安装

1. 如收到汇总 ZIP，先解压汇总包，取出其中的 `.mod.zip`。各 Mod ZIP 自身不要解压。
2. 每个技术身份只启用一个版本。Host 在主 UI 前，适配包在目标 Mod 与 UI 后。
3. 安装主 UI 4.1.0；Host 0.1.5-experimental 的成员与公开版一致，已有该版时无需重新安装。
4. 更新有变化的 ModHubSoftWet 1.0.3、ReOverfitsSoftWet 1.0.1、SmartPhoneSoftWet 1.1.2。其它四个适配包成员未变化，不必为版本统一而重装。
5. 重启，检查界面设置、页面入口与加载顺序，再使用测试进度。具体下载名与 SHA 以交付包清单为准。

当前包针对 DoL 0.5.12.13；ModLoader 最低 2.100.0、TweeReplacer 最低 1.0.0、Host 为 `>=0.1.2-experimental && <0.2.0`。本轮代表 Loader 为 2.101.1，Android 17／WebView 155。最低声明不表示所有未来版本都已测试。Node 26 仅用于开发构建，玩家无需安装。

## 本次重点看什么

- 默认 60 通透度，以及 0／100 两端；设置和 ModHub、存档三页等完整兼容窗口是否协调。
- 上下／左右设置，真实输入、长内容滚动，背景不能被穿透点击。
- 官方侧栏窗口与兼容窗口是否只播放一次进入动画，关闭后装饰与背景是否清理。
- 悬浮工具扇形／网格、内侧辅助操作、关闭与快速反向。
- 原有衣柜、商店、原生战斗与存档操作是否保持；优先使用隔离测试数据。
- 平时使用的雨效与翻页是否顺畅。有异常请附具体窗口、天气和操作，避免把所有慢帧直接归到游戏或 UI。

这里只列负责人体验重点。技术检查、实机已验与未覆盖项分别沿[候选记录](evolution/EVO-4.1-CANDIDATE-2026-11-02.md)和[消费者表](evolution/EVO-P0-COVERAGE.md#41统一交付覆盖补充2026-10-28)保存，未宣称所有设备和 Mod 已穷举。

## 偏好与回退

保留已有有效偏好。新 Acrylic 默认 60，选项默认原样／靠左；正文行距、间距与宽度默认跟随原版。新安装显示 Hub、开启动画并平铺全部战斗控件；明确保存的选择不重置。

设置总开关可回到原版界面。整包回退恢复原 UI、适配包和顺序后重启；其它消费者仍依赖 Host 时保留它。不清除存档、浏览器或整个 App 数据，不承诺整包热卸载。

ModHub 规则优化仅匹配已审 1.9.2 完整源，移除 UI 并重启即可退出；作者 ZIP 未改。未知源回到原路径不表示该 Mod 无法使用。
