# Soft & Wet 4.5 — 研发记录（未发布）

2026-11-10，负责人要求以菱形玻璃球继续研发，同步GitHub，产品版本记为4.5。本记录不表示已经发布、合并main或通过实机验收；稳定发行仍为4.2。

## 本轮范围

- 正式入口采用蓝灰半透明玻璃、双层线框菱形和四向短刻线；圆形悬浮与主动停靠的窄条保持同一识别。没有引入新的外观选择设置。
- 普通展开、关闭不启动旧金属球的充能/余辉长演出，静止不持续绘制；展开轮廓提供短反馈，并隔离通用按钮圆角与旧金属焦点规则的覆盖。既有菜单运动、原生按钮、扇形/网格与内侧辅助操作继续工作。
- 拖动松手即保存当前位置，贴边也只停在可用区域内。停靠侧边由菜单显式执行。正式入口移除蓄力、弹射、瞄准线和尾迹；保留位置偏好、拖动取消、订阅和 Host 所有权。
- 玻璃关闭和不支持模糊时使用清晰的实色回退；系统减少动态继续生效。天气、窗口材质、设置和其它业务不改成另一套设计。
- 产品版本来源为`package.json`的4.5.0，锁文件根身份同步；Host协议、Host包及七个兼容包版本不随产品号提升。核心内部2.7版本保持既有独立合同。

## 计划新增：自定义颜色主题与字体

已纳入 4.5 计划，待实现。玩家可在界面设置中自定义 UI 颜色和字体，实时预览、应用并保存偏好，也可一键恢复默认的黑灰 Acrylic 和现有字体。

- 颜色覆盖界面底色、面板、正文、次要文字和强调色。预览同时展示选中、焦点和错误等状态；验收时检查自定义颜色在不同通透度下的可读性，以及提示状态能否辨认。
- 字体可选择本机可用的字族。所选字体缺失或不包含所需字形时自动回退；验收覆盖中英文混排、长标签和窄屏，确保与现有字号、间距设置一起使用时仍可阅读和操作。
- 设置页用于预览。应用后用同一组主题与字体设置覆盖悬浮工具菜单及主 UI 自有窗口，逐项核对属性、衣柜、商店等界面。兼容包只验证已由 Soft & Wet 接管外观的区域，尊重第三方原有样式边界。
- 验收还包括重载后保留偏好、旧配置正常打开、无效配置恢复可读默认，以及恢复默认后所有受影响界面同步还原。

## 参考与取舍

本轮沿用负责人确认的“菱形玻璃”识别基础及原组件SVG比例。已准备的中性A样例是参考复刻，不宣称与历史源码逐像素一致；B烟灰细化只作为独立设计研究，未设为本轮默认。未吸收此前被否决的新球体与装饰方案，也没有将隔离样例的简化业务替换正式工具。

## 验证与接续

实际验证结果及当前分支见[HANDOFF](HANDOFF.md)。新增断言绑定真实官方Hub及放置夹具，防止测试包装层遗漏外观参数而误测金属旧路径；旧金属实验默认接口仍保持，避免改写历史实验的意义。Expected Lock只更新受影响测试身份，不移除门禁或放宽断言。

本机Chromium受控环境用于验证显示、可操作性、资源释放及拖放合同。Windows、Android/WebView与真实多Mod游戏安装未在本轮验证，保留为后续设备覆盖；不将Mac或Actions代签实机结果。发行需单独授权和最终包验收。
