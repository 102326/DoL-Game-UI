# Soft & Wet 4.5 — 研发记录（未发布）

2026-11-10，负责人要求以菱形玻璃球继续研发，同步GitHub，产品版本记为4.5。本记录不表示已经发布、合并main或通过实机验收；稳定发行仍为4.2。

## 本轮范围

- 正式入口采用蓝灰半透明玻璃、双层线框菱形和四向短刻线；圆形悬浮与主动停靠的窄条保持同一识别。没有引入新的外观选择设置。
- 普通展开、关闭不启动旧金属球的充能/余辉长演出，静止不持续绘制；展开轮廓提供短反馈。既有菜单运动、原生按钮、扇形/网格与内侧辅助操作继续工作。
- 沿用现有位置、订阅、偏好和Host所有权；自由拖放、沿边蓄力、瞄准、弹射、碰撞、接住和取消继续使用原状态机。实际飞行中的中心菱形随旋转变化，主体不变形，金色尾迹沿实际路径短时消散。
- 玻璃关闭和不支持模糊时使用清晰的实色回退；系统减少动态继续生效。天气、窗口材质、设置和其它业务不改成另一套设计。
- 产品版本来源为`package.json`的4.5.0，锁文件根身份同步；Host协议、Host包及七个兼容包版本不随产品号提升。核心内部2.7版本保持既有独立合同。

## 参考与取舍

本轮沿用负责人确认的“菱形玻璃”识别基础及原组件SVG比例。已准备的中性A样例是参考复刻，不宣称与历史源码逐像素一致；B烟灰细化只作为独立设计研究，未设为本轮默认。未吸收此前被否决的新球体与装饰方案，也没有将隔离样例的简化业务替换正式工具。

## 验证与接续

实际验证结果及当前分支见[HANDOFF](HANDOFF.md)。新增断言绑定真实官方Hub及放置夹具，防止测试包装层遗漏外观参数而误测金属旧路径；旧金属实验默认接口仍保持，避免改写历史实验的意义。Expected Lock只更新受影响测试身份，不移除门禁或放宽断言。

本机Chromium受控环境用于验证显示、可操作性、资源释放及物理合同。Windows、Android/WebView与真实多Mod游戏安装未在本轮验证，保留为后续设备覆盖；不将Mac或Actions代签实机结果。发行需单独授权和最终包验收。
