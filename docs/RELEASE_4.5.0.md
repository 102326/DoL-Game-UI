# Soft & Wet 4.5

服装店现在会按屏幕宽度显示商品：平板和电脑在右侧查看衣服与配色，手机从底部打开详情，返回后可以继续挑选。双菱形悬浮入口新增列表和弧形抽屉，设置、特质、成就与 ModHub 切换内容时也能保持窗口大小。

## 安装与升级

- **首次安装**：下载 `StoneFreeHost-0.1.5-experimental.mod.zip` 和 `DoLGameUI-4.5.0.mod.zip`，直接导入 Loader，将 Host 排在主 UI 前，再重新启动游戏。
- **从 4.2 升级**：保留原包作备份，用 4.5 主 UI 替换旧 UI。如果已有随 4.2 提供的 Host 0.1.5-experimental，可以继续使用。
- **使用 ModHub 外观包**：重新导入本页的 `ModHubSoftWet`，即使旧包也显示 1.0.4。本次更新调整了窄屏页签与工具菜单。其余兼容包按已安装的目标 Mod 选用，放在目标 Mod 与 UI 之后。每个同名 Mod 只启用一份。

从侧栏进入「界面设置」即可更换悬浮工具的布局。弧形抽屉里的工具从球的上方或下方依次展开；想收起入口时，可在设置中关闭悬浮球。

适用于 DoL 0.5.12.13，需 ModLoader 2.100.0+ 和 TweeReplacer 1.0.0+。万能手机外观包留在历史版本。切换服装商品时仍可能稍等片刻。
