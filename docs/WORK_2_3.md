# 2.3 候选工作记录

基于 M4-B 提交 6362c35，分支 `candidate/soft-wet-2.3`。正式 2.2.2 未改动。历史 M2～M4-B 证据保留。

## 当前实现

- 窄衣柜分类使用单行 Select，宽屏保留分类按钮；常用操作在窄屏默认折叠，单击直接穿戴保持。
- 衣物行减少装饰间距；商店、战斗、存档、设置与公共 Surface 添加局部窄屏规则，保留主要操作目标尺寸和安全区域。
- API v1 增加只读 `wardrobe.getSlotSupport()`，区分展示条件、未知槽位和作者声明的原业务合同。未注册的空未知槽位也进入回退提示。
- onSave 保留 gameTime，只替换自有字段并保留有效命名空间里的其它字段。非记录、冻结对象安全跳过。

- 战斗原控件连续选择、过期/隐藏/禁用拦截、原控件回退通过。

## 本轮 Paisley Park 使用事实（待最终去重）
