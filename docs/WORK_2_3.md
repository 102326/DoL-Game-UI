# 2.3 候选工作记录

基于 M4-B 提交 6362c35，分支 `candidate/soft-wet-2.3`。正式 2.2.2 未改动。历史 M2～M4-B 证据保留。

## 当前实现

- 窄衣柜分类使用单行 Select，宽屏保留分类按钮；常用操作在窄屏默认折叠，单击直接穿戴保持。
- 衣物行减少装饰间距；商店、战斗、存档、设置与公共 Surface 添加局部窄屏规则，保留主要操作目标尺寸和安全区域。
- API v1 增加只读 `wardrobe.getSlotSupport()`，区分展示条件、未知槽位和作者声明的原业务合同。未注册的空未知槽位也进入回退提示。
- onSave 保留 gameTime，只替换自有字段并保留有效命名空间里的其它字段。非记录、冻结对象安全跳过。

## 手机环境准备

APK 和 14 个用户 Mod ZIP 已从平板独立测试安装读取，保存在相邻 `soft-wet-23-phone-kit`。17 项加载顺序中 3 项随 APK 内置。14 个 ZIP 的 SHA256 与清单一致。没有复制存档、账号、凭证或 Session。

手机 ebf3ee84（25102RKBEC、Android 17）已独立安装 `com.vrelnir.dol.lyra.uicompat051213`，没有覆盖普通 Lyra。USB 安装最初被 Android 拒绝；用户允许后安装成功。先加载 2.2.2 对照，再通过原 ModLoader 更新为 2.3.0-rc.1，重启后实际版本与 17 项加载顺序核对一致。

实际手机视口 400×821：设置页无横向溢出，关闭按钮 44px；衣柜分类 Select 44px，衣物行约 60.6px，根区域 320px 且无横向溢出。正常切换上装、展开/关闭角色预览通过。只读 getSlotSupport() 能返回原衣槽和已加载 Adapter 的映射，不把这些已知映射当作新增通用槽位操作证明。截图与 CDP 记录保存在本轮 artifacts。手机建立全新测试角色，没有导入或覆盖已有存档。

手机衣柜搜索正常筛选，实际 Android 软键盘显示后输入仍在可见区；即时 CDP 测量早于键盘动画，未用该高度替代随后原生截图。键盘截图包含输入法自己的剪贴板栏，仅留本地，不用于公开对比图。原版新角色路线进入战斗教程：六组动作、根区域 308px 无横向溢出，底部操作栏 59px、可见主要按钮 44px，选择摘要展开/关闭正常且无横向溢出。没有点击继续执行战斗回合，不以这些布局证据证明战斗结算。
