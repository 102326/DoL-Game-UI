# Soft & Wet 4.0 — Evolution

Evolution 延续3.X黑灰Acrylic，更新悬浮工具、设置转场与玻璃天气。Host与UI继续分别安装，原游戏业务和存档格式保持原约定。

- Floating Hub使用金属球回旋、蓄势展开与关闭回收，保留真实工具、拖动和停靠。
- 设置共用上下／左右双布局、真实控件、偏好和连贯分类切换。普通雨珠覆盖顶部标题、布局选择及横向分类区，保留尺寸、流速与真实背景折射；雪与特殊天气保留各自表现范围。
- 设置响应血月、异世界、极热与严寒，原有雨雪继续保留；雨中血月使用普通雨。
- 优化已适配窗口雨幕的持续重绘，保留原雨量、速度、水滴与材质。
- 修复缩放后的战斗底栏偏移、关闭残留背景及一条衣柜离场刷新路径。新安装默认显示Hub、开启动画并平铺全部战斗选项，已有偏好保留。
- 兼容包保留目标Mod业务。原版优化叠穿列表显示多个已识别项目；异常附加日期仅按能够确认的存档时间修正文字，上游正常日期保留，不改存档数据。
- 存档操作区分空槽与畸形数据；无法确认时停止该次转发，保留原入口和未知扩展行，不自动修复存档。维护中的自有代码与工具完成TS First整理，玩家无需安装Node。

## 安装与回退

DoL当前适配基线为0.5.12.13，需要ModLoader >=2.100.0、TweeReplacer >=1.0.0、Framework Host >=0.1.2-experimental且<0.2.0；本轮使用Host 0.1.5-experimental。最低合同与已验证版本分开，不保证任意未来版本兼容。

备份存档并保留旧包，停用旧同名UI，Host先于UI加载。兼容包按目标Mod选装，放在目标Mod和UI之后，同名包只启用一份。无需解压ZIP。回退时恢复旧包和顺序再重启，不清空App数据或存档。
