# 在真实设备记录浏览器视口

当前没有收到真实设备参数。“允许测量”只表示授权，不能据此填写 viewport、
DPR 或系统缩放，也不能把已有模拟器结果改为实机结果。

打开 [离线测量页](../tools/device-probe.html)。它是一个完整 HTML 文件，
没有外部依赖、服务、网络请求或自动上传。可自行把该文件复制到手机或平板，
用要测量的浏览器打开；无法打开本地 HTML 时，保留该宿主为未验证，勿把别的
浏览器数值直接套用。页面内的数据只在内存中，刷新或关闭会丢失。

1. 填写设备型号、实际浏览器/应用名称与版本、实际游戏宿主名称。只填名称，
   不填网址、账号、IMEI、序列号或其他设备标识。默认 `UNKNOWN` 表示不知道。
2. 系统显示缩放和浏览器缩放需要你查看设置后人工填写；不知道时保留
   `UNKNOWN`，不能把未知值默认记成 100%。页面不会更改任何缩放设置。
3. 仅在真实硬件上操作时勾选“本次在真实设备运行”。这是你的确认，
   页面没有独立验证硬件；不勾选仍可记录浏览器观察值。
4. 竖屏时等待界面和地址栏稳定，点击“记录当前方向”。旋转横屏、等待稳定，
   再点击一次。需要时可分别记录地址栏展开/收起等条件，并说明场景。
5. 查看 JSON，点击“复制 JSON”或“导出 JSON”。文件名固定为
   `device-measurements.json`。本地文件环境可能不允许剪贴板访问；页面会选中
   JSON，供你手动复制。导出由浏览器下载处理，不会上传。
6. 分享前核对人工填写的文字，清除不想提供的内容。清空按钮删除本页采样记录；
   已手动导出的文件仍需你自行管理。

页面保留 `Redmi K90ProMax` 和 `Xiaomi pad9 pro max` 等原始请求名称。
后一个型号仍需“关于设备”中的产品型号文字确认，不能自动改名为 Pad 9 Pro，
也不需要提供序列号。iPad 系列还需明确代际和尺寸。待测目标与模拟代理映射见
[设备目录](DEVICE_PROFILES.md)。

## 如何解释这些数值

每条采样类型是 `browser-runtime-observation`，`observed:true` 只证明页面
执行时读取到了浏览器数值。`physicalDeviceConfirmed` 与
`measuredOnPhysicalDevice` 只有用户勾选后才为 `true`，同时始终标注
`physicalConfirmationSource:'user-assertion-only'`。它们不是硬件验证结果。

- `innerWidth/innerHeight`：当前布局视口 CSS 像素。
- `devicePixelRatio`：浏览器报告的 DPR。它不能单独确定屏幕物理分辨率、
  Android 显示密度、系统缩放或菜单中的浏览器缩放。
- `screenCSS`：浏览器报告的屏幕/可用空间 CSS 像素，独立于布局视口保存；
  不用它乘 DPR 推算物理分辨率。
- `screenOrientation`：浏览器报告的方向及角度，可能没有提供。
  `viewportOrientation` 根据布局视口宽高另行判断，两者不能混为一谈。
- `visualViewport`：另行保存宽高、scale 和偏移；其 scale 不能等同系统缩放，
  也不证明实际执行了浏览器菜单缩放。
- `safeArea`：此页在 `viewport-fit=cover` 条件下，通过自己的隐藏探针读取
  `env(safe-area-inset-*)`。零值只表示此页当前报告为零，不证明设备没有挖孔，
  也不证明其他宿主会给出相同的值。
- 触控点上限、coarse pointer 和 hover 条件仅为浏览器能力报告。
  自动识别的浏览器信息只保留粗略家族及主/次版本；不导出完整 UA、OS 平台或
  构建信息。

独立浏览器的观察值不能证明游戏 WebView、ModLoader、全屏模式或其他容器的
实际视口。在实际使用的同一宿主测量才具有对应关系；如果宿主无法打开此页，
须明确保留这一验证缺口。此页不会读取游戏 DOM、HTML、存档、Cookie、本地
存储、当前网址或账号，也不会连接设备、修改游戏、发布服务或自动上传。

## 自动化验证范围

`node tests/device-probe.cjs` 在受控 Chromium 环境打开本地文件，检查
390×844 / DPR 3 / 触控输入与 844×390 旋转后的观察值、UNKNOWN 默认值、
人工字段、用户确认开关、导出/复制后备/清空、存储读取禁令与无外部请求。
测试中的确认勾选是人工确认路径的模拟，不是真实硬件验证。这个 smoke 不能
替代 Redmi、小米平板、iPad、iPhone 或真实游戏宿主上的测量。
