# Soft & Wet 2.0.3 · DoL 0.5.11.9 / 0.5.12.13

2.0.3 主要整理了第三方 Mod 的兼容方式。主 UI 保留现有布局、材质、原版回退和触屏高亮修正；特定 Mod 的外观与嘴部路径改为独立可选包，方便按需安装和单独升级。

## 主要变化

- MapleBirch 云存档外观从 UI 主包移出，改由 MapleBirchSoftWet 提供。原版存档列表、详情、导入／导出与确认页仍由主 UI 处理。
- ModHubSoftWet 更新至对应 ModHub 1.3.0：外壳保持 Acrylic，主体稍微提亮并增加透光，列表、输入框和操作区保持稳定。减弱顶部统计摘要、按钮边框与默认删除色，只做 CSS 换皮，保留 ModHub 的原布局和操作。
- 特定 Lyra Goose 嘴部路径适配单独提供。0.5.12.13 主角色修复与 0.5.11.9 旧版衣柜预览修复是两个不同包，请按版本选择。
- 兼容包名称包含目标 Mod 版本和适配包版本；源码随仓库提供。cheat_extended 没有专属兼容层，通用原控件美化保持。

## 安装说明

1. 升级前建议备份存档。需要 **SugarCube 2 ModLoader 2.100.0+** 与 **TweeReplacer 1.0.0+**。
2. 在加载器中导入主 UI 和所需兼容包，**不要解压**。
3. 替换已有的同名 Mod，不要同时启用多个版本。兼容包放在主 UI 和对应目标 Mod 后加载，再重启游戏。
4. 使用 preview 候选的用户，也请替换成同名正式包；不清空原有显示偏好。

在“界面设置”关闭“启用 Soft & Wet 2.0 界面”可直接回到原版。外观包跟随总开关；不需要兼容包时，在加载器禁用并重启即可。
