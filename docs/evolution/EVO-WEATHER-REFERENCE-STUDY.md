## 对照现有A/B的判断

重新查看仓库的[A稳态](../media/evolution-weather-r2/beads-rain.png)和[B稳态](../media/evolution-weather-r2/film-rain.png)，以下是Codex的设计判断，不是参考作者的结论。

1. **A的凸起感过强。** 大水珠的固定亮斑、暗边和圆鼓体积更接近玻璃纽扣/树脂珠；真实参考的内部明暗随场景变化更明显。已有原生模糊/提亮像素检查只能证明滤镜生效，不能证明水滴折射成立。
2. **B的雾化缺少颗粒与湿润结构。** 宽幅柔化区域容易读作覆盖的烟雾；R03的凝露质感来自细密、非均匀的水珠及局部清除差异。已有噪声和三条通道并未自动形成可信材质。
3. **两者过度依赖额外观察带。** 当前视觉重点集中在研究工具条下的独立横带，真实窗口主体变化弱。该横带可以用于技术检查，不能作为“整个Acrylic表面已获得雨天材质”的证明。
4. **稀疏/随机不等于自然。** 两者仍使用相近的珠体着色和可辨的循环运动。R01/R02启发的是不同尺度和状态共存，而不是让每个水珠都按不同速度重复下落。
5. **可读性成果保留，但保护方式仍需视觉检验。** 正文像素一致是有效可靠性证据；把所有材质表现挤到一条横带则是另一回事。下一版应在实际窗口布局中同时评估材质连续性与文字、控件保护。

## 下一轮重做方向

先做小范围材质验证，再形成新的完整窗口样片；不沿A/B继续微调参数后宣布通过。

- **清透湿玻璃作为主要研究方向。** 以R01/R02/R04的附着微滴、少量不规则大滴及局部水痕为参考。先让单个静止水滴在明/暗、有纹理/低纹理背景下都成立，再研究运动。
- **光照与背景关系优先。** 降低固定球面高光和统一黑边的支配性；评估水滴内部与周围背景的关系。若验证折射，应先证明实际背景输入可得，不能给WebGL一张无关风景图就称其折射了真实UI。
- **以事件组织运动。** 下一实验应尝试“附着停留—增大/接触—局部合并—滑移—残留细滴/湿痕”，而非每滴独立循环。合并和质量变化目前尚未实现，不在本研究中报为通过。
- **凝露作为独立、克制的材质方向。** 借鉴R03的细颗粒和清除差异；不把所有雨天自动变成整面白雾，也不把手指擦拭轨迹冒充自然排水。自然排水仍需另找更直接的运动参考。
- **回到实际窗口构图。** 新样片主要验收移除人工观察带后的真实设置布局；研究条纹/观察带只做诊断辅助。材质在玻璃层上建立，正文和操作控件继续得到保护。

这些是研究后的施工建议，**不是负责人已批准的具体视觉结果**。本轮尚未选择CSS/SVG/Canvas/WebGL的新实现，也没有新依赖或正式整合。

## 下一样片的最低证据

1. 静止近景和正常窗口尺寸都看得出水而非装饰珠；提供相同布局、视口和操作的V1/A/B历史参考，旧样片不改名为通过。
2. 可观察附着与滑移，若声称合并则提供真实合并事件；不以程序状态字段代替可见行为。
3. 明暗背景、正文可读性、中途天气改变、晴雨连续性均可检查；雨转雪另行观察，不能由雨窗参考推断已完成。
4. 原速录像与目标浏览器基本性能分开报告，技术测试继续保护隐藏/中断/关闭释放；视觉质量由负责人裁决。
