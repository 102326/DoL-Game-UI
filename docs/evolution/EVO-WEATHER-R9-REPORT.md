# EVO-V1-R9 — C5.2 稀疏独立雨滴

2026-10-22，研究分支 `dev/evolution-4.0`，输入 `e2ee5dd8d0b110dd2635eef34d7e12644cf75b7f`。负责人对C5.1反馈“雨滴数量太大了而且规律性很强”，**C5.1未获视觉认可**。本轮减少数量并更换斜雨生成方式，保留四档与快节奏；负责人现已认可`6e2b2986e7ab0d2d6395923ee323fec215cc6bdf`的C5.2雨天原型，精确提交与实际CI见 [Issue #22](https://github.com/102326/DoL-Game-UI/issues/22) R9记录。

## 根因与改动

| 编号 | 发现 / 已做 | 保留边界 |
| --- | --- | --- |
| EVO-V1-R9-SCATTER | C5.1把同一SVG平铺最多三层、统一相位移动，纹理间距与重复队列可见；C5.2不再画这张循环雨幕，改为64槽固定种子的独立雨滴 | 无贴图平铺、共享循环相位或整批重生；固定种子可复现，并不等于实拍或完全无规律 |
| EVO-V1-R9-DENSITY | 斜雨候选为`10+26×intensity`，四档约19/27/36/49，实际正文保护后更少；玻璃微滴系数1.6→.65、池912→380，滑落补充系数1.4→.8 | 保留四档越大越多越快；独立分布下单帧可见数有波动，不把每帧都严格递增当自然雨的合同 |
| EVO-V1-R9-MOTION | 每颗位置、长短、宽度、速度、倾角独立；从上/左边界以错开间隔重生，退出时再采样其形态；保留C5.1玻璃滑落能量与自然湿痕/底边流出 | 不重新引入整齐队列；未模拟每颗斜雨撞击玻璃并转为附着滴 |
| EVO-V1-R9-EVIDENCE / CI-HANDOFF-01 | `scatter=1`独立启用，`scatter-review.html`提供C5.1/C5.2四档同操作原速对照；增加独立运动/有界重生检查与交接 | 旧入口及R8原始媒体保留，未合并main或发布 |

独立雨滴在原Canvas/RAF中推进，湿润和雨转雪连续消退；保守笔触边界逐颗检查实际正文/控件保护。没有增加Canvas、DOM雨幕、RAF、定时器、依赖或外部服务。滑落滴/总滴/轨迹/湿痕足迹上限仍7/90/900/32；设置V2.3、生产天气提供者、Host/API、雪晶与玩家存档不变。

`showerGeometry`记录本帧实际绘制的独立雨滴几何、速度与重生代数，支持复现。旧版`showerDensity`表示平铺层权重，新版表示独立候选预算，须结合`showerPattern`解释，不能跨版本把3与49当成同一种粒子计数；旧平铺雨幕没有被伪记为0颗。

## 验证

本机macOS / Node24.18.0 / Chromium153.0.8010.12。本轮是针对视觉反馈替换生成方式：旧平铺根因直接由实现/原速画面确认，没有把“缺少新模块”的错误包装成旧缺陷负例。

- `node --test tests/evolution-rain-model.test.cjs tests/evolution-scattered-shower.test.cjs`：原模型7项＋独立雨滴2项；固定种子复现、同一时段并非刚性平移、速度/长度差异、四档预算/速度、100秒有限/有界且错开的重生、dt0静止与resize/无效输入。
- `npx vue-tsc --noEmit -p tsconfig.evolution.json` 与 `npx vite build --config vite.evolution-weather.config.ts`：研究类型与构建。
- `node tests/evolution-weather-shower.cjs --scatter`：四档状态、实际独立几何和非一致速度、内容区斜雨开关像素变化、正文/关闭按钮严格PNG一致、暂停/减少动态相位静止、390px、隐藏停止及释放重开。
- `node tests/evolution-weather-shower.cjs --scatter --record --baseline` 与 `--scatter --record`：同1280×900/DPR1、两边斜雨均开启；约1/7/13/19秒依次四档，25秒转雪、32秒后结束。全部等待保留、1×，不宣称播放器帧级同步。普通smoke以状态推进，不冒充原速。

R9受控媒体、结果、实际几何、内容区像素对照与源码/逐文件摘要在 `docs/media/evolution-weather-r9`。独立几何/预算和像素证据不代替自然感验收；随机分布没有一个自动“画质通过”分数。新增第十一组16MiB硬上限，总176MiB仅理论上限，超限报错不截断；Artifact保留14天。
