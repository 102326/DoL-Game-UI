## 4. 顶栏雨效具体改了什么

1. 按负责人新增授权，普通雨珠、湿痕及细雨集中覆盖设置标题、布局选择和横向分类区，下缘48 CSS px渐隐；纵向导航不会把范围拉到整页。
2. 同步缩小实际Canvas backing store与CSS高度，减少整窗纹理反复清空／绘制。
3. 保留原雨模型尺寸、粒子参数、流速、碰撞及PNG normal-map／原生SVG背景折射，不使用游戏截图或虚构纹理代替背景。
4. 普通雨装饰绘制按60Hz合并不足一帧的重复更新，实时时钟不变；布局变化、动态关闭和reduced motion保留即时更新，雪与特殊天气不套用此节奏限制。
5. Host／UI双包、公开合同、原游戏业务与存档语义保持。

原四项材料合同保留，新增顶部／实际Canvas范围及绘制合并合同，合计六项。严格背景位移像素、湿痕、几何、文字保护、输入和生命周期断言均保留，没有删除反例或放宽门槛换取通过。
