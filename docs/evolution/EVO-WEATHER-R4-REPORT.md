macOS、Node24.18.0、锁定Chromium153.0.8010.12。实际命令：

- `node --test tests/evolution-rain-model.test.cjs tests/test-workflow.test.cjs`：模型4项及工作流选择/去重/非法参数检查通过。
- `npm run ci:check`：状态合同生成核对、项目/adapter/early/framework类型检查通过。
- `npx vue-tsc --noEmit -p tsconfig.evolution.json`：研究源码类型检查通过。
