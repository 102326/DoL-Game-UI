2026-10-22，分支`dev/evolution-4.0`，输入`4a99c4491a883191564ab2922d0cc25b622c5354`。负责人已授权按[实拍研究](EVO-WEATHER-REFERENCE-STUDY.md)制作下一版并展示。本报告不是画质通过或4.0完成报告；最终源码身份、推送与CI另见[#22](https://github.com/102326/DoL-Game-UI/issues/22)。

## 实际改变

| 编号 | 本轮成果 | 边界 |
| --- | --- | --- |
| EVO-V1-R3-OPTICS | 原生SVG背景位移：缓存三种近似法线图，每滴按自身边界扭曲浏览器合成背景。条纹DOM上的开/关像素对照已实际通过 | 不是WebGL读取任意HTMLElement；不是物理光学仿真。只能证明当前Chromium受控合成场景，不证明所有真实游戏背景根可用 |
| EVO-V1-R3-MOTION | 有界水滴模型：停留/增长、实际碰撞合并、面积代理转移、较大水滴滑移、短暂湿痕、干燥退出 | 模型是视觉近似，未校准接触角、体积、真实速度或质量守恒；不将每滴独立循环下落当合并 |
| EVO-V1-R3-LAYOUT | 移除人工材质观察带。按实际文字行、按钮、输入及阅读样本几何保护，允许其它玻璃留白出现水滴 | 保护区会隐藏经过的水滴，属于UI可读性处理，不是自然玻璃的物理行为。近景无此保护，单独展示 |
| EVO-V1-R3-REVIEW | 新评审页、可操作设置、独立材质近景、四段同夹具原速对照与接触前后证据 | C仍待负责人视觉评审；V1仍Reject，A/B未获认可；旧媒体全部保留 |

C没有沿用A/B的固定球面高光/厚阴影珠体。局部背景变化与薄的非对称明暗轮廓共同建立水滴；微滴停留，较大水滴由模型接触并滑移。凝露未在本轮另造一整面白雾；其颗粒、自然排水运动仍是后续独立研究。

独立技术复核找出并修复两条同源缺口：420ms布局动画结束后保护几何仍停在起点，以及暂停后布局变化无法触发保护重绘。两条实际DOM重叠红例均拒绝旧实现。修正版在工作区运动期间采用保守区域保护，完成/取消后重测文字行；暂停/减少动态也允许同一RAF做必要的几何重绘，暂停模拟时间严格不前进，稳定后停止。正式检查新增左右/上下终态、分类运动采样、暂停时间及减少动态下的真实DOM矩形验证；不再用缓存`protectedOverlap=0`自证文字安全。最终源码经只读复查，未发现新的实质问题；该复核不是视觉认可。

共享天气状态、隐藏/减少动态/暂停/关闭释放沿用既有机制；没有新增生产依赖，没有改Host公共API、业务事件、真实天气提供者或存档。A2/A3及Golden Spin V2的其它工作没有因本轮天气样片自动完成。

## 观看范围

本机入口：`http://127.0.0.1:5190/rain-review.html`；启动方式见[README](../../prototypes/evolution-weather/README.md)。设置页面可选日光、夜灯、深色背景及主动静止观察；[材质近景](../../prototypes/evolution-weather/glass-optics.html)另提供条纹验证和位移开关。

日光/夜灯是普通DOM/CSS组成的受控背景，**没有使用实拍参考素材作为运行纹理**。新四段比较都移除观察带，使用同一较通透的研究玻璃底材和日光背景；因此它们比较的是相同新夹具上的四个绘制器。不是声称旧V1/A/B历史录像的布局/底材完全未变；原第二轮媒体仍在`docs/media/evolution-weather-r2`。

原速对照：1280×900 / DPR1，相同晴天静观→晴转雨→稳定雨→材质分类→阅读分类→中途转雪计划。录像保留等待，不剪辑或加速；真实加载/分类/调度可能导致总长不同，不宣称帧级同步。录像在共同视觉阶段结束后停止；390px、隐藏、减少动态、关闭重开用独立smoke验证，不混入这些视频尾部。

近景接触证据核对真实可见的两滴水：合并前都可见；合并后被吸收水滴消失，接收滴实际DOM矩形面积增加，且有可见滑移及湿痕。近景录像后段包含主动暂停、条纹开关与背景切换，不把其当连续自然天气过程。
