## 实际技术边界与失败记录

WebGL TexImageSource并不包含任意HTMLElement。此次候选使用浏览器原生backdrop-filter处理其合成背景，未截图游戏DOM、未同步复制真实控件、未构建假游戏纹理。滤镜只能证明模糊/亮度/饱和度关系，**不是物理光学折射**。[Khronos接口规范](https://registry.khronos.org/webgl/specs/latest/1.0/) / [CSSWG背景根规范](https://drafts.csswg.org/filter-effects-2/)。

没有因为Canvas已实现而只改Canvas：保留Canvas绘制细节，新增原生背景滤镜、SVG掩模/裁切和真实DOM像素实验。`optics.html`是普通CSS条纹DOM背景，暂停同一表面，只切换背景滤镜，截图必须改变；这不等于Safari/WebView或真实游戏所有背景根均可用。

排查过程保留：最初的滤镜mask与保护区造成硬矩形，且逐水珠/全平面的滤镜成本较高；已改为实际玻璃周边/观察带的有限区域处理、柔化保护和非重复凝露。像素实验还拒绝了一次无效方案：SVG use引用组以及实验背景层顺序使滤镜看似声明但实际不生效。修正背景顺序后还发现组合裁切的矩形痕迹，最终退出组合透镜路径，使用水珠自身边界；实验同时要求未覆盖背景像素不变，重录最终版本。未通过的中间录像不作为交付候选；未靠删断言或把CSS.supports当效果证明通过。
