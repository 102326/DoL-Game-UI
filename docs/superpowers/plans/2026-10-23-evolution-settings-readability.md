# EVO-MAT-READ01 — 设置底材可读性对照

负责人已通过实际设置0.56浓度边霜并授权后续研发。先同步FROST02及新CI；CI PR24单独询问Draft原因，不因通知或绿色自动合入。本计划仅研究已登记的设置底材透字，不推广其它窗口，不修改正式默认材质或认可动效。

1. 固定当前实际设置/天气/边霜、第一方背景、桌面与窄屏输入。确认透字来自85%不透明底色叠加 `backdrop-filter:none!important`，不是新霜层或预览缩放。
2. 单平面Acrylic候选：只在独立预览服务器向实际CSS追加一条研究覆盖，启用玻璃时对固定壳背景做24px blur / .9 saturation；保留底色/边框/布局/100/80ms开关/620ms分类。玻璃关闭时不应用，不为子面板叠加blur。默认研发代码与旧预览保持原样。
3. 在同一夹具中对照旧/新，核对真实控件输入、玻璃开关、关闭后原动作、雨雪保护与释放。对背景标题显隐的实际截图测量高频差分，证明背景文字的清晰边缘受到抑制；此数值不等于可读性或画质验收。
4. 记录桌面/窄屏同操作、原速演示与截图、渲染支持及实际JS/帧观察。必要文件/媒体有摘要与体积上限，仅受控第一方页面，无游戏/存档/凭据。
5. 提供负责人对照评审，说明单层背景blur可能增加合成成本、改变折射取样背景；未验证WebView/真机/GPU。未批准前不进入实际默认设置，不写入main/Release。若候选不可行，保留失败证据并停止该方向，不通过隐藏真实背景制造画质通过。

验证复用当前真实设置与W01导出入口，新增仅手动研究检查，不扩默认CI设备矩阵。默认代码没有变化时，不重复跑整轮产品测试。
