# Motion Evolution / #22 — b507首批历史设计记录

**状态已更新：** 下文记录b507首批的设计选择，不再作为后续实施口径。[正式产品口径V1.0](../../SOFT_WET_3.1_PRODUCT_DIRECTION_V1.md)已由负责人批准；新窗口视觉重做尚未通过验收。短程、控件不移动、窗口不引入框架等是当时选择，不是未来硬约束。具体新方案未批准，当前暂停编码，见[待确认方案](../plans/2026-10-21-window-motion-proposal-v1.md)。

负责人认可 Golden Spin 球体；后续目标是全 UI 动态表现升级，不是改写游戏业务或更换 3.X 视觉基线。分批实现可操作结果，在同一 Issue 汇报，不创建大量占位任务。

共享的是取消、偏好、隐藏页和生命周期能力，各场景保留自己的动作。球体蓄势/释放表达入口动能；窗口以材质建立层次、控件保持稳定；设置分类按导航方向交接，不沿用菜单多圈轨道，不让整个界面旋转。商店/衣柜、战斗、天气以后分批处理。

本批选择复用原生 WAAPI 和已有 sourceMotion；没有为窗口引入 GSAP、全局状态管理或另一套调度平台。球体仍使用已有原型 GSAP/Canvas 路径，不改变负责人已认可的绘制。生产依赖/包体和宿主影响需在游戏整合阶段另核对。

验收分开记录：技术检查证明终态、中断、命中、键盘与清理；负责人判断视觉质量。Mac/CI、独立网页、实际游戏与设备不能互相替代。当前交付在研究分支，未授权自动合并或正式发布。
