# DoL Soft & Wet Game UI 2.5.0-rc.1 · Crazy Diamond

这是本地发布候选，尚未发布到 GitHub。正式下载仍为 2.2.2。

## 主要变化

- 衣柜支持跨已支持分类搜索，结果显示分类，同名衣物可区分；清空搜索返回当前分类。
- 点选搜索结果仍直接使用原游戏穿戴操作。整理模式只处理当前分类，不把跨分类结果自动纳入批量操作。
- 衣柜、服装店、战斗和存档继承自适应候选成果，按实际内容宽度调整布局。
- 服装店窄窗口使用详情抽屉，可以通过返回按钮或上方空白区域关闭；宽屏保留列表和详情。
- 保留原节点、原业务来源、操作前复核和原版入口。衣柜“先查看详情再穿戴”实验已删除。

## 安装与升级

导入 `DoL-SoftWet-GameUI-2.5.0-rc.1.mod.zip`，不要解压；只启用一个 UI 主包，导入后重启游戏。仍使用内部标识 `DoLGameUI`，可替换旧主包。升级前建议备份存档。

需要 ModLoader **2.100.0+**、TweeReplacer **1.0.0+**。本包声明游戏版本 **0.5.11.9 / 0.5.12.13**，不包含游戏本体、APK 或游戏图片。

既有官方可选包仍独立安装。它们使用 API v1 与最低 UI 版本要求，本轮没有新增公共 API 或改变依赖语义；目标 Mod 版本满足依赖不等于任意结构都已验证。未识别结构继续原版显示或退出适配。

## 已验证范围

Windows / Edge 隔离原游戏与夹具通过仓库发布候选检查。Android 为 M367FC 平板、Android 17、DoL 0.5.12.13 / ModLoader 2.101.1 的独立测试实例。

本批平板验证包括跨分类搜索、单击原生穿戴、陈旧绑定拒绝、关联套装、未知衣槽入口、衣柜和商店系统分屏、商品抽屉与颜色、原版回退；补充战斗动作选择及系统分屏、软键盘展开时搜索与结果点击、整理审查与取消。

大库存检查为总库存 791 件、其中 500 件合成原生衣物，默认每页 40 行。采用预先确定阈值的有界样本；这不是无限库存性能保证。

此前 Combat Demo 错误在 UI 开关两侧均可复现。原演示需要先通过 “Add human” 生成 NPC；补齐原生准备后两侧正常。本轮没有修改原游戏或第三方源码，没有执行战斗回合。

## 限制与回退

- 搜索只覆盖当前可靠来源支持的分类。陌生私有衣槽仍通过“原版及扩展信息”访问，不猜测其业务操作。
- API v1、存档格式、已有显示偏好保持；游戏内存档日期的自有 metadata 字段继续保留。
- 未逐一验证其它手机、WebView、全部 Mod 组合、战斗结算、购物与云端业务。这些属于额外覆盖，不等于现有功能未实现。
- 在界面设置关闭 Soft & Wet 或对应页面，可使用原版界面。
