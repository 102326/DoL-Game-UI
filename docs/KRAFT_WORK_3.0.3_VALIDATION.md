## 失败与修正

首次本地候选误把经典入口成员加入官方 UI 包。实际入口检查未通过，该包已保留并弃用，没有公开上传；后续使用正式入口重新构建，核对成员集合、实际加载身份和最终行为。

原存读恢复后的严格 JSON 文本比较曾因对象键顺序变化失败。完整解析后的穿戴与叠穿对象逐字段相同，原失败和语义检查分开保留，没有重放该次恢复。滚动测试在 CSS 缩放下遇到浏览器像素量化，改为核对实际 scrollTop 差值和材质位移的关系，没有放宽坐标对齐要求。

原版优化兼容包 1.0.1 的 Windows 实际 Loader 业务记录复用[此前验证](OPTIMIZATION_WARDROBE_1.0.1.md)，不重复整套业务或社区矩阵。Host 与六个兼容包沿用 v3.0.2 当前冻结附件，逐一核对摘要，不用重新构建的同版本 ZIP 替换。

物理手指、真实 iOS、全部衣物套装与扩展槽位、全部 Mod 组合、长期运行和全部游戏业务未在本轮重验。系统选择器能力、历史 `selectedWardrobe` 异常、未归因社区告警及资源变化不因本补丁宣布解决。原始截图、设备标识、第三方包与测试进度仅保留本地。
