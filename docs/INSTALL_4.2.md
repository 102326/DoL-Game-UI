# 安装、升级与回退 Soft & Wet 4.2

普通玩家需要 **Framework Host + DoLGameUI** 两个ZIP。直接导入Loader，不要解压；兼容包按自己安装的目标Mod选用。

## 安装

1. 保留需要的存档和原版本包。
2. 导入随版提供的Framework Host、主UI和所需兼容包。
3. 停用同名旧包，每个技术身份只启用一个版本。
4. Host放在主UI之前，兼容包放在目标Mod与UI之后。
5. 重启游戏，从侧栏或悬浮球进入“界面设置”。

顺序示例：**目标Mod → Framework Host → DoLGameUI → 对应兼容包**。目标Mod自己的前置和顺序照原说明处理。

DoL适配基线为0.5.12.13，ModLoader需2.100.0或更新，TweeReplacer需1.0.0或更新。Host适用0.1.2-experimental至0.2.0之前，推荐使用随版提供的0.1.5-experimental。游戏与第三方主Mod需另外安装。

## 升级与使用

已有显示偏好继续保留。首次使用的Acrylic通透度为60，正文排版跟随原版，悬浮工具默认显示，战斗选项默认全部展开。

拖动悬浮球后可原地放下；持续顶边蓄力，沿边移动调整方向，松手弹射。飞行中可重新接住。原有停靠、重置与隐藏入口保留。

设置和属性窗口从标题空白处拖动，正文仍可滚动。系统减少动态效果及关闭动画时保留相同操作入口。

使用ModHub时，同时更新ModHubSoftWet 1.0.4；该包的时间点还原窗口样式需要主UI 4.2或更新版本。其它兼容包按附件选装。

兼容包用途见[可选兼容包](OPTIONAL_ADAPTERS.md)。Cheat Extended原作者版与独立维护的rebuild.30二选一；万能手机兼容包用于Alpha，Lyra嘴部资源包按指定游戏环境安装。

## 回退

恢复保存的原UI、兼容包与加载顺序，再重启游戏。其它Mod仍需要Host时保留它。无需删除存档、清空浏览器或整个App数据。

仅想切回某个原版界面，可在“界面设置 → 页面”中关闭对应页面。总开关会保留显示偏好和设置入口。
