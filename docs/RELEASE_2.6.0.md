# DoL Soft & Wet Game UI 2.6.0 · Crazy Diamond

本版本整理了衣柜、服装店、战斗和存档的自适应布局，并修复手机窄屏浮层与战斗图组的宽度问题。2.5.0 已撤回，建议使用 2.6.0；正在使用 2.2.2 的用户也可以直接升级。

## 主要变化

- 衣柜支持跨已支持分类搜索，结果注明分类；点选衣物仍直接穿戴，整理操作保留原游戏规则。
- 服装店在宽屏显示列表与详情，窄屏使用详情抽屉；点击抽屉上方空白可以关闭。
- 战斗动作区随可用宽度排列，保留原动作控件、选择摘要与原版回退。窄屏战斗小图组可换行，主图保持比例，不再由空图槽撑宽正文。
- 存档页复用界面节点，减少打开与刷新时的闪烁；关闭响应式布局时，不再把原版存档浮层压成窄条。
- 字号与按钮缩放统一为 **50%–150%**，默认 **100%**。第一次升级到 2.6 时仅将这两个值恢复到 100%；之后重启、旋转或窗口变化会保留你的选择，其它偏好不重置。
- 关闭布局增强或主题时，保留第三方后来加入的侧栏内容与原事件。

## 安装与升级

适配 **DoL 0.5.11.9 / 0.5.12.13**，需要 ModLoader **2.100.0+** 和 TweeReplacer **1.0.0+**。

1. 升级前备份存档。导入主包 ZIP，**不要解压**，只启用一个 UI 主包。
2. 按需导入兼容包。通常让兼容包位于 UI 和目标 Mod 之后；旧 Lyra 衣柜嘴部包的提前注入顺序请按其说明设置。
3. 重启游戏。内部标识仍为 `DoLGameUI`，可替换旧主包。

模组不包含游戏本体、APK 或游戏图片。遇到界面问题，可关闭对应页面增强或在界面设置中关闭 Soft & Wet，直接使用原版；设置无法打开时，可在加载器中禁用 UI 后重启。

## 兼容与限制

- 原版游戏数据、存档格式和业务操作保持；UI Runtime API 继续使用 v1。
- 搜索覆盖有可靠来源的衣物分类。未知私有衣槽保留原版或第三方入口，不猜测穿戴规则。
- 原版优化存档的游戏内日期仍由原 Mod 异步读取，不保证瞬时出现。没有安装对应兼容包时，陌生结构可能回退到原界面。
- 不保证所有 Mod 组合、设备或 WebView 都相同显示。2.6 修复了已复现的窄屏问题，不将历史截图的所有现象归为同一原因。
