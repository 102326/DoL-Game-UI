# Stone Free：受审 UI 操作与阅读空间

2026-10-17，基于工作台提交 `bdbcefa00f187055bc3278337daa4e66e858bcdd`。本轮 Done：用一个可撤销的公开命令合同连接原版侧栏按钮，在独立消费者和工作台显示同一能力，验证原事件、结果见证、失效及清理。正式 UI 2.7、API v1、存档与原游戏业务不改；不发布。

## Delivered

- Host 新增可探测的 `commands` 能力、`provideCommand / commands / onCommands`，只接受自愿声明的无参数回调。句柄不公开原节点、Vue 实例或可变游戏对象。
- 每次调用核对本 Host 的当前绑定与声明身份。同一声明未返回时拒绝重复派发；顺序明确的新操作仍允许。提供者退出、场景失效、回调抛错或结果不合法发生在调用之后时，返回 `unknown`，不自动重试，不声称副作用没有发生。
- `StoneFreeNativeReading` 只认识 SugarCube 的 `#ui-bar / #ui-bar-toggle / UIBar.isStowed()`。按需读取原状态，复核节点身份、唯一性、class/API 一致性和实际命中点；模态、遮挡、禁用及未知结构时退让。执行者是原按钮及其原监听器。
- `StoneFreeReadingControls` 通过公开合同提供非模态操作与工作台视图。状态明确标为采样；按钮使用“切换侧栏”，不根据可能已过期的采样承诺收起或展开。结果不确定时，该实例停止再次执行，保留原版入口。
- 工作台是模态，因此其中的视图只显示状态，不越过模态调用外部原控件。关闭工作台后可在非模态工具条刷新、操作。

`returned` 只证明提供者返回了有效 JSON；侧栏是否切换以领域见证 `applied / before / after` 为准。完整返回表见 [README](../framework/README.md#受审命令实验)。这不是权限系统、业务调度器、跨故障 exactly-once 或 GER Ledger，也不恢复或结清历史 Effect。

## Not validated / Known limitations

没有购买、换装、战斗、存读档或完整玩家任务的业务结果证明。没有真实 IME、物理手机触控和原游戏跨 Passage 测试；窄浏览器视口只说明布局。没有承诺所有第三方侧栏/遮罩结构均识别，未知结构保留原版入口。

实验命令不接收任意业务参数，不跨页面缓存有效绑定，不持久记录未知结果，也不能强制取消永不返回的作者回调。后续若选取真实业务，需要单独定义领域前置条件、输入、结果和恢复，不能将此 UI 操作的通过推广为任意游戏动作可用。
