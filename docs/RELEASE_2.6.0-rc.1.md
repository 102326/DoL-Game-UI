# Soft & Wet 2.6.0-rc.1 本地候选

本包仅供后续隔离实机验货；不是正式发布，不表示 2.5 手机事故已经解决。保留 API v1、Mod 标识 DoLGameUI、原版业务和原存储键。

这次只修复已证明的问题：

- 窄窗口不再永久压低字号和按钮偏好：保存 50%–200%，手机尺寸临时显示最多 150%，宽屏恢复保存值。
- 关闭响应式布局或销毁侧栏增强时保留后来插入的第三方节点及事件；锚点丢失时保留仍连接内容，不复活已经被游戏删除的内容。
- 改进现有测试的异步等待与资源路径，更新一个 source-map-js 安全补丁。

本轮使用 macOS / Chrome / Playwright、固定原版 0.5.11.9 和现有 SugarCube 夹具。已执行构建、类型、单元、核心页面和原版恢复检查；失败和补测范围见 [调查记录](AUDIT_2.6.md)。旧 Android 记录属于历史证据，本候选尚未安装到 Android，0.5.12.13 多 Mod 组合也尚未重验。

沿用的安装要求：ModLoader 2.100.0+、TweeReplacer 1.0.0+、DoL 0.5.11.9 / 0.5.12.13。先备份，在独立测试安装中替换旧版同名 UI，ZIP 不解压；按现有说明保留目标 Mod 和兼容包，不同时启用两版。旧 Lyra 衣柜嘴部包明确列举 UI 版本，不应直接用于 2.6；本轮没有放宽它的声明。

真机应先覆盖手机事故场景，再检查竖横屏、键盘、分屏/小窗、偏好恢复、核心操作和关闭增强后的原版功能。详情见调查记录的待验证清单。

3.0 可基于此分支开展隔离原型，参考 [Stone Free 工程边界](STONE_FREE_3.0_BASELINE.md)；新功能并未编入 2.6。
