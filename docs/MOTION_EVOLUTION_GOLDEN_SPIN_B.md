## 这次实现了什么

球体使用 Canvas 2D 绘制金属明暗、球面投影刻纹和嵌点。刻纹随连续角度旋转；球体定位与光照保持空间稳定，区别于将图标整体旋转。蓄势时角速度上升，伴随轻微压缩和球面弧形残影。

默认一次约 4.73 秒：1.47 秒蓄势、0.96 秒释放、2.3 秒减速。三条方向一致的对数螺旋从球心向外扩展，增长率采用黄金比例，前景轨迹与球面使用关联角速度；余韵逐步消失。途中可以收束或重新蓄势，保留当前角度与状态，不硬切回起点。

页面提供时间倍率、能量强度研究控件。当前没有工具菜单、第二份游戏状态或业务事件代理。系统减少动态效果时显示静态能量形态；闲置不持续绘制，隐藏页暂停，卸载清理时间线、帧回调、尺寸和媒体监听。

## 技术选择

复用已引入的 **GSAP 3.15.0** 编排多段状态与中断，Canvas 2D 负责球面与能量绘制，没有增加新的图形库。GSAP 的收益是直接编排多字段蓄势、释放、收束，减少手写时间管理；原生 RAF / WAAPI 同样能够实现，尚无证据说明必须进入生产依赖。

当前独立网页构建 JS 约 137 KB（gzip 约 54 KB），包含 Vue、GSAP 和研究界面；精确值看构建日志。不是正式 UI 的净增包体。Canvas 使用主线程并限制 DPR≤2；尚未获得真实设备帧率或长期功耗结论，不能据此宣布性能通过。

GSAP 是专有 [Standard No Charge License](https://gsap.com/standard-license/)，不是项目 MIT。构建保留版权横幅、项目 LICENSE 与[第三方声明](../prototypes/golden-spin-b/THIRD_PARTY_NOTICES.md)。球体与轨迹为原创绘制，没有复制动画作品素材。

## 验证与边界

当前 Edge 受控页面检查覆盖：加速→释放→余韵、快速重启与收束的角度连续性、390px 窄屏模拟触控、尺寸变化、键盘、减少动态效果，以及卸载后回调停止。类型检查、现有 UI / Framework 合同检查和独立构建通过。CI 状态以实际 GitHub Run 为准。

首轮录屏回看发现绘制可能停在首帧：初次 RAF 早于 GSAP 首次 tick，误用 `isActive()` 使绘制循环提前退出，而阶段文字仍继续变化。已改为由时间线存续决定绘制循环，新增实际绘制次数与角度变化检查；失效录像保留本地，不作为当前交付。最终视频重新取景。

首个 GitHub Run 在减少动态效果检查失败一次：测试未等待异步 `matchMedia` 变更事件送达，就开始比较静态绘制次数。测试现等待对应状态完成后再测，不放宽“静态状态不持续绘制”的断言；首次失败 Run 保留，最终结果看修正后的 Run。

本地补验还出现一次等待媒体状态超时，未取得当次内部状态，原因仍为 Unknown；已增加失败时状态与页面可见性采集。随后一次目标检查通过，不据此认定这个超时已彻底解决。该项保留为原型测试时序限制，不把球体样片升级为发布级可靠性结论。

旧菜单研究的 Android 临时接入结果不属于新球体样片的设备验证。新阶段尚未接入真实 Hub，也未进行 Android / iOS 物理触控、长期资源或低端设备性能验收。此前通用工程保留在隔离分支，正式入口不启用实验 hook。
