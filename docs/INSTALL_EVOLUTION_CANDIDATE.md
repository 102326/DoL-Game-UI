# Evolution 候选：安装、升级与回退

> 当前候选存在[Android暴雨设置性能阻塞](evolution/EVO-ANDROID-GLASS-PERF-F1-2026-10-25.md)，尚未满足发布封包条件。

本指南用于 Soft & Wet 4.0 — Evolution 内部候选 `4.0.0-rc.2`，尚未正式发布。当前包来自完成TS First、存档P2独立复核及本轮冗余写入修复的源码`35a5bb5`，Host沿用0.1.5-experimental；相同rc.2版本标签不代表包字节相同，请核对[最新冻结清单](evolution/EVO-FINAL-REVIEW-PACKAGES-2026-10-25.json)。整体体验和发布裁决见[关卡报告](evolution/EVO-RELEASE-GATE-2026-10-24.md)。

## 安装

1. 备份需要保留的存档，并保存原 UI、Host、兼容包及加载顺序。
2. 停用旧的同名 UI，导入本轮核对的 Host 与主 UI ZIP，无需解压。
3. Host 放在 UI 前。按已有目标 Mod 选装兼容包，放在目标 Mod 与 UI 后；每个技术名只启用一个版本。
4. 重启后确认设置入口、Hub 和所需页面可用，再读取测试进度。验收阶段优先使用独立测试 App。

| 环境 | 要求与当前验收范围 |
| --- | --- |
| DoL | 当前包合同与测试基线为 0.5.12.13 |
| ModLoader / TweeReplacer | 最低声明 >=2.100.0 / >=1.0.0；本轮代表环境为 2.101.1 / 1.7.0 |
| Framework Host | >=0.1.2-experimental 且 <0.2.0；本轮使用 0.1.5-experimental |
| 平台 | Android 平板 WebView 与 Windows Edge 代表界面；完整边界见验证报告 |

最低版本和结构合同共同决定是否适配，不保证任意未来版本或预发布版本都兼容。不需要为安装 UI 更新所有无关 Mod。

具体候选版本和依赖见[最新九包清单](evolution/EVO-FINAL-REVIEW-PACKAGES-2026-10-25.json)及ZIP的boot.json。早期RC2、TS迁移前及局部修复前的清单只作历史；当前UI ZIP SHA-256为`08d0bf77903099638aef501cd80bbd9e35480b910707b79ed53441fd73069986`。本轮候选集合只含九个Mod ZIP和对应SHA256SUMS，不含内部检查报告。除嘴部资源包外，通常还需要 UI；SmartPhone 要求 UI >=3.0.2，其它外观包沿用已有最低合同。没有目标 Mod 就不安装对应包；主 Mod 与 PhotoPack 另行获取，本候选不打包第三方主 Mod。

原版优化叠穿是否开启由其原设置决定，兼容包不强制开启。已识别的叠穿项目、顺序和卸下操作使用作者原逻辑。

当前日期修复只在原版优化附加日期出现已识别无效值时尝试显示存档对应的有效时间。正常日期完全保留，上游修复后自然让位；无法确定时间时保留原显示，不用当前时间填充。该修复不修改存档数据或调用保存、载入。

## 偏好与回退

显示偏好保存在浏览器或 App 内，已有选择保留；新偏好默认显示 Hub、开启动画、战斗全部平铺，聚焦编辑仍可选。游戏存档格式不由 UI 迁移。最新候选加强存档按钮操作前的异常数据检查；无法确认时停止该次转发并保留原版入口，不尝试自动修复或写入存档。带额外摘要的未知行可能继续显示原生控件。

Node26仅为开发/构建工具要求，玩家浏览器或Android App无需安装Node。TS First没有改变玩家端依赖或存档格式。

回退时停用候选 UI 与相应兼容包，恢复原来保存的包和加载顺序，再重启。其它 Mod 仍依赖 Host 时保留它。不要清空存档或整个 App 数据。

候选使用4.0.0-rc.2独立版本标记，避免与公开3.0.4混淆。ModHub 的“一键更新全部”可能把研究 UI 换回公开包；本轮只更新已确认的四个目标，不用公开 UI 覆盖候选。

正式发布版本与下载链接仍由最终验收决定；候选准备不代表已发布。技术报告、源码身份、原始测试资料不混入玩家 Assets；截图与视频放页面展示区。
