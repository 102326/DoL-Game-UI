# Soft & Wet 3.0.0-rc.1 — Stone Free

这是首个公开RC的本地待审批制品，尚未发布。建议普通玩家继续保留稳定版2.7和存档备份。

## 主要变化

- 官方UI和Stone Free Framework Host分为两个独立Mod。玩家只需这两包及原有游戏前置，不必安装开发样例或作者工具。
- 衣柜保留单击直接穿戴，新增可随浏览保留的参照与对照。商店支持商品显示信息比较，购买仍使用原控件与报价。
- 可选Floating Hub提供公共视图和只读参考入口，默认关闭。保留Ocean、Acrylic、视觉档位和可关闭的空间转场。
- 衣柜、商店、战斗、存档和常用面板接入场景生命周期，旧业务绑定失效时退让，原版入口继续可用。
- 保留2.7设置和存档显示偏好；不迁移游戏存档格式，不恢复衣柜浏览后确认穿戴模式。

## 安装

官方UI：`DoLGameUI-3.0.0-rc.1.mod.zip`。推荐Host：`StoneFreeHost-0.1.4-experimental.mod.zip`。

前置：ModLoader >=2.100.0、TweeReplacer >=1.0.0；本次官方UI主要支持DoL 0.5.12.13。当前实际Loader验证版本为2.101.1。Host自身不绑定UI的游戏版本白名单。

备份存档并保留2.7包。先停用旧DoLGameUI，再安装Host和本UI，Host在前，按加载器提示重启。不要解压Mod ZIP，不要同时启用多个同名Host/UI。载入进度后检查偏好；发现问题可停用新UI、恢复2.7并重启。无其他消费者依赖时也可停用Host。不要清空偏好或存档来回退。

## Host版本

最低Host为0.1.2-experimental。依赖声明为 `>=0.1.2-experimental && <0.2.0`；推荐当前0.1.4。0.1.3仅包身份和说明不同，不是必要的API升级。0.1.2包含本UI所需的场景桥接修正，因此不支持降至0.1.1。

公共协议仍为0.1-experimental，原DoLGameUI UI API仍为v1。安装范围和已验证组合分开；范围不是所有未来版本的认证。Loader2.101.1可能允许0.2.0预发布，不能据此视为受支持。未来破坏性合同换协议代际；仅UI内部更新不要求无关消费者一起更新Host。SDK源码包版本也不决定每个作者的最低Host版本。

## 限制与反馈

本RC的验收范围是既有Windows/Android隔离测试环境中的最终安装、2.7升级和回退。实际结果与摘要随候选的外部验收记录提供，不能仅凭此版本说明判断安装已通过。0.5.11.9只有历史有限研究，不列入本RC默认支持。

物理手机触控、IME、所有Mod组合、长期运行、云端和文件选择没有完整覆盖。原版优化、ModHub等组合仍可能报告共同Patch、资源或配置告警，不代表本UI能自动修复全部第三方功能。旧外观兼容包可按各自说明选择安装，云端扩展不声明完全兼容。

新Hub位置回退后不主动删除，但本轮未额外验证拖动落盘与回退读回。版本/能力检查不能保证拦住所有错误Host包，不支持时请按说明回退。不要依赖热卸载。

反馈：https://github.com/102326/DoL-Game-UI/issues 。附游戏、UI、Host、相关Mod版本和复现步骤即可；避免上传私人存档、账号、完整日志。
