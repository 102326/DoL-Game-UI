2026-10-17。本轮完成一个真实衣柜场景的官方 UI 消费者接入及“取出、暂存、比较、归位”交互。Framework 公共协议和 R9 制品没有改动，没有重复依赖升级矩阵。未推送、合并或发布。

R9 原工作区核对后显式暂存 34 条源码/文档路径，固定为本地提交 `1990a125df886ffb2a6aee82b2e41db226ddf9a9`。其父提交为 `41fba02570252cd5a26d311834961e4f73b7d856`。没有混入 APK、截图、测试收据或 dist；原五个研究 ZIP 另存于本地 `tests/artifacts/stone-free-r10/baseline-r9-1990a12/`。R10 在同一分支继续，源码提交可从本文件对应 Git 历史追溯。

新增官方入口 `framework/official-ui/main.ts` 和本地研究包 `DoLGameUI-3.0.0-lab.10.mod.zip`，配对独立 `StoneFreeHost-0.1.1-experimental.mod.zip`。玩家候选路径只需这两个包；T 是验收用独立消费者，R9 Reference、Hub、Factory、Author Kit 均不是该衣柜路径的安装前置。

衣柜新增 `ReferenceDock.vue`、`reference.ts` 和 `reference.css`，直接使用现有衣物行、分类、搜索和 Source：

- 主衣物按钮继续单击穿戴，旁边轻量“参照”只固定 A 的显示资料。
- A 收进边缘标签，玩家继续在同一个衣柜列表浏览，不再打开另一份辅助目录。
- 另一件的“对照”直接展开 B。关闭“空间转场”使用普通路径，比较数据和字段算法相同。
- 相同、不同、不可比较分别标识；全部可比较字段相同也会明确提示，不推断隐藏属性相同。
- A 标为固定快照，B 标为本次目录读取。跨部位不保证可替换，不显示“更好”这种未经业务证明的排名。
- 返回关闭比较，但保留 A。原分类、查询、分页和滚动列表没有被销毁，焦点回到有效来源按钮。
- 固定时有来源卡片向边缘的运动，比较从 B 所在衣物行展开，返回有短暂来源联系。交互状态立即改变，不等待动画。
- 来源失效、页面离开、整理模式或释放时清理相应临时状态。目录失效时静态收束，不向仍 connected 的旧行播放虚假归位。

减少动态效果、现有 `visualMotion` 和 `visualGlass` 继续生效；低档位和不支持 blur 的浏览器有稳定实底。没有新增 UI 偏好键、参照持久化、试穿、装备恢复或业务状态同步。

## Architecture Findings

`src/main.ts` 提取原启动函数 `startGameUI()`。普通 Vite 构建保持 2.7 默认启动；官方候选构建关闭自启动，由公开 `connectConsumer()` 验证 Host 后启动。技术名仍是 DoLGameUI，候选运行版本为 `3.0.0-lab.10`；根 package.json 和经典构建版本仍为 2.7.0，不能把研究版本当作稳定版发布。

官方入口通过公开 `register / claim` 取得自己的 participant。衣柜通过公开 `mount({lifetime:'passage'}) / binding()` 挂载现有 Vue 页面，失效时取消预览、释放参考并恢复原节点；销毁整个官方消费者仍保留 T 的来源、挂载及可用性。官方 `DoLGameUI.destroy()` 继续是自身退出入口，现在还会取消该消费者的等待接入订阅。

Host 没有新方法、私有注册表接口或官方优先权；官方 ZIP 不包含 Host 实现。衣柜业务适配仍由消费者内部现有 Source 和原宏负责，原操作前额外复核 Host 场景绑定。参照只复制显示字段，不把原衣物对象、库存或动作句柄传入组件。

这是首个正式页面的较深接合，其余旧页面仍由原模块管理生命周期。候选并未迁移所有衣柜、商店、战斗能力。本研究打包没有携带正式包的商店早期注入和 TweeReplacer 分页补丁；它不具备替换正式 2.7 的发行合同，也不对其它页面的完整功能作验收声明。

## Experience Findings

与 R9 的“打开独立参考工具 → 固定 A → 另选 B → 点比较”相比，R10 直接从正式衣物行固定 A，再点 B 的对照。不需要在两份目录之间切换，也不用重新定位原衣柜。返回不清除 A，允许继续比较其它衣物。

普通与空间模式的比较操作数、展示字段相同。空间模式提供来源运动和归位联系，没有证明比普通模式更快或更受玩家喜欢。未开展多人偏好研究、计时或重复查阅次数测量；当前仅证明任务连续性和上下文保留成立。

真实小库存没有足够滚动溢出，不能把它算成大库存滚动证明；该部分由明确标记的 40 条目组件夹具补充。面板移到右侧、避开标题/原返回入口，窄屏改为底部布局；比较期间仍会占用一部分预览/正文区域，暂不宣称零遮挡。

- `desktop-1792181882335`、`desktop-1792181935650`：测试误以为默认分类有衣物，实际是空的头饰分类。第二次补充的诊断确认页面和 Host 挂载正常，随后通过原分类按钮选上装。
- `desktop-1792182023576`、`desktop-1792182111094`：窄屏侧栏遮挡；遮罩中心又位于侧栏本体下方。改为原收起按钮，未修改遮罩业务或 force-click。
- `desktop-1792182174630`：比较面板确实覆盖了衣柜原退出入口。修正自有面板位置，随视口/滚动避开标题区，并让测试只对不在视野的目标作必要滚动。
- `panel-1792182344461`：测试把排序后的第 13 项误当作 key 12，改为保存实际点击 key。
- `panel-1792182389205`：目录失效后 DOM 尚 connected，仍有归位飞行。返回现复核当前来源，失效时静态关闭；定向夹具通过。
- 桌面源只提供编译 HTML，未提供完整图片资源；预览有图片加载超时。它不证明实际 Android 的图片缺陷，本轮不对整套渲染重新验收。
- 桌面初始泛化 `Event` 的原因仍 Unknown。参考与退出阶段无新增 pageerror，不能推广为全游戏无错误。
