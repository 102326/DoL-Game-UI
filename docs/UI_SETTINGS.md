# Soft & Wet 界面设置基线（2.0.2）

常用显示选项直接展开；按页面回退、实验和开发工具默认收起。控件仍使用原有偏好接口和原生 checkbox / select / range，不新增游戏状态源。

| 分组 | 保留的选项 | 说明 |
| --- | --- | --- |
| 界面与阅读 | Soft & Wet 2.0 总开关、舒适阅读间距、宽幅正文 | 阅读行距与按钮密度分开调整 |
| 材质与动效 | 流畅 / 均衡 / 华丽、玻璃模糊、动画、高光 | 三档共享结构；系统减少动态效果优先 |
| 字体与按钮 | 字体大小、按钮大小、恢复 100%、手机紧凑按钮间距 | 紧凑选项默认关闭；手机尺寸横竖屏生效，大屏保持原样 |
| 侧栏与布局 | 响应式布局、紧凑状态间距 | 原生侧栏展开/折叠操作保留 |
| 存档与衣柜 | 存档 V2、衣柜界面、衣柜分页 | 关闭对应新版页面时隐藏无效的附属选项，保留已存偏好 |
| 页面与兼容 | 存档、服装店、日志、特质、统计、态度、设置、作弊、成就、社交、属性、战斗 | 默认收起，独立回退功能保留 |
| 进阶实验与外观细节 | 标题纹样、衣柜隐藏列表、商店离屏绘制、商店分页、启动缓存 | 默认收起；实验默认关闭，已保存选择不重置；不可用的商店分页接口不显示 |
| 兼容回退 | 回退原版、启用新版 | 与总开关相同语义，保留页面与显示选择 |
| 开发检查 | 状态接口预览 | 默认收起、默认关闭，仅排查时使用 |

不再常驻显示开发预览、长串页面开关和可选装饰。不删除仍有兼容用途的功能，也不默认开启实验。历史 `showCompact` / `collapsedStats` 已停用并保持关闭，不再提供入口；保留旧偏好解析兼容。

手机紧凑选项减少战斗指令、操作工具条、存档操作、衣柜与商店按钮、界面设置行的留白；不缩小字体、不压缩内容卡片、不移动原节点。操作区域保持至少 44px，模组管理界面和侧栏不在该按钮样式范围内。可随时关闭恢复默认间距。

手机判定复用现有缩放上限逻辑（视窗宽度或屏幕短边 ≤600 CSS px），因此桌面窄窗口也会按手机尺寸处理。这不是按设备型号识别。

## 2.0 总开关

“启用 Soft & Wet 2.0 界面”同时控制主题、布局和新版页面接管。关闭后使用原版游戏界面，保留“界面设置”入口；不进入旧 1.x 样式。1.x 只在独立 LTS 分支维护，不作为 2.0 的第二套界面。

页面开关、字号、存档 V2 与实验偏好仍保存用户选择；总关闭时这些显示功能实际停用，重新开启按保留值恢复。关闭期间修改页面选择只保存意图，不挂载新版页面。getPreferences / 各模块 getEnabled 返回保存的选择，实际接管还取决于总开关。

衣柜忙碌时拒绝总切换，避免部分关闭。总切换不执行购买、换装、保存或读取，也不重新应用商店进店默认筛选。已完成的启动缓存优化无法追溯撤销；启动实验按总开关在下一次重启时决定是否安装。
