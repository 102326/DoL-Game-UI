# Soft & Wet 4.1 界面设置

从侧栏“界面设置”或悬浮工具进入。阅读、材质、入口、页面、高级共用一份偏好；修改立即生效并自动保存。设置只调整界面，不改游戏数值、存档内容或其它 Mod 的配置。

## 阅读

| 控件 | 作用与默认值 |
| --- | --- |
| 正文行距 | 100%–160%；默认 100%，跟随原版 |
| 段落与选项间距 | 在原段落、已识别选项和自有表单之间增加 0–24px 留白；默认 0 |
| 正文宽度 | 从原宽度逐渐放宽到可用空间；默认 0，窄屏或原本铺满时变化较小 |
| 选项文字对齐 | 默认原样／靠左，可改为居中；不重排正文 |
| 字体／按钮 | 各自 50%–150%，默认 100%；图片保留原尺寸 |
| 手机紧凑按钮间距 | 可减少控件留白，仍保留至少 44px 点击区域；不等于已撤销的侧栏紧凑状态间距 |

“恢复原版排版”只恢复前三项。“恢复 100%”只改字号和按钮比例。新版使用统一紧凑排布，侧栏的“紧凑状态间距”不再提供；旧舒适阅读、宽幅正文开关已由三项连续控件替代。

## Acrylic 与动效

**Acrylic 通透度**为 0–100，默认 **60**。向左更沉稳，向右更通透，在同一套 V1 黑灰 Acrylic 内连续变化。它同时调整表面遮蔽、模糊与边缘层次，不是整窗 opacity，也不改变文字和按钮的透明度。

已适配官方窗口与完整兼容窗口跟随该轴；正文承载、虚拟手机、参考视图等按自身角色保留必要差异。未知第三方窗口不会被全局强行接管。关闭“玻璃模糊”后保留数值，重新打开恢复；“恢复默认通透度”回到 60。

“交互与进入动画”“交互层次反馈”“标题边缘纹样”独立控制。系统减少动态效果优先；关闭动态仍可完成相同操作。旧质量档位不限制当前官方视觉能力。

## 布局、页面与悬浮工具

设置布局提供“上下”和“左右”，默认上下。切换保留当前分类与控件；空间不足时可暂以上下方式显示，已保存的左右选择不变。布局保存在 `DoLGameUI.settingsLayout.v1`，存储不可用时仍可本次切换并提示保存失败。

页面开关可单独退回原版。新安装战斗默认平铺全部原选项，聚焦编辑仍可选择；已有明确偏好保留。衣柜按页渲染默认开启，每页 40 件，搜索、排序和全选仍按对应分类的完整数据执行。

Floating Hub 新安装默认显示，支持扇形与网格；扇形工具悬空排列，辅助操作置于内侧。空间不足时回退可操作布局。找回入口会开启并取消隐藏；重置位置不改模式与工具选择。

## 兼容与回退

高级中保留衣柜隐藏列表延迟、商店离屏绘制延后和按页生成等明确的实验回退，默认关闭，已有有效选择保留。遇到对应第三方异常时可单独关闭；商店按页生成需要重新进入页面。不要把关闭这些实验当成清除存档的方法。

总开关恢复原版界面并保留设置入口，重新开启恢复显示偏好。衣柜业务忙碌时不能强制切换。若设置无法打开，在 Loader 中停用 UI 并重启；无需清空存档或整个 App 数据。

旧 `statusPreview`、`startupCacheLazy`、`storyActions` 不启动。4.1 的 ModHub 依赖规则优化与这些旧实验无关：仅对已核对的 1.9.2 完整源码生效，未知版本保持上游实现；移除 UI 并重启可完全退出，不修改目标 ZIP、依赖结果或更新状态。

设置与已保存偏好沿用。Node 26 仅为开发工具要求，玩家无需安装 Node。
