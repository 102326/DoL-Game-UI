# Soft & Wet 界面设置

Kraft Work 3.x 采用阅读、材质、入口、页面、高级五个任务分类，每次显示当前任务。本文以当前 3.x 设置为准；早期设计仅作历史参考。官方入口取消三档质量选择。玻璃、动态和交互层次反馈独立设置，系统减少动态偏好优先。

“设置布局”提供上下、左右两种方式。上下将分类放在内容上方，是新安装的默认布局；左右将分类放在左侧。切换立即生效并保存，保留当前分类、控件值和材质预览状态，不需要重新加载游戏。

窄窗口或较大字号下，左右布局可以暂时以上下方式显示；已保存的左右选择不变，空间恢复后自动恢复左右布局。两种方式使用同一份控件和材质，没有第三种“自动”选项。关闭主题、动画或减少动态效果都不删除布局选择。

此选择是官方设置窗口的私有显示偏好，独立保存在 `DoLGameUI.settingsLayout.v1`，不加入公共 UI API v1，也不改写原有偏好对象。存储不可用时仍可本次切换，并提示无法保存。

旧 `visualTier` 值保留，官方入口使用完整视觉能力，不由旧值抑制玻璃或动画。关闭独立效果仍然有效；回到经典入口后原档位可继续使用。详见[当前视觉方向](STONE_FREE_3.0_VISUAL_DIRECTION.md)。

新安装默认显示战斗平铺界面并启用现有动效，原动作与 Continue 保留。战斗聚焦编辑 B 默认关闭，启用后聚焦单组原控件，关闭聚焦则恢复平铺；关闭新版战斗可恢复原版节点。已保存的新版战斗关闭选择继续保留。

常用选项展开，页面开关、工具与位置、兼容实验和问题诊断按需展开。设置只保存 UI 偏好，不改变游戏变量或第三方设置。

| 分组 | 内容 |
| --- | --- |
| 主题与阅读 | 总开关、舒适阅读间距、宽幅正文 |
| 材质与动效 | 玻璃模糊、动画、交互层次反馈 |
| 字体与按钮 | 字体和按钮 50%–150%、恢复 100%、手机紧凑间距 |
| 侧栏与布局 | 响应式布局、紧凑状态间距 |
| 存档与衣柜 | 存档 V2、原版/新版衣柜、衣柜按页渲染 |
| 各页面与兼容开关 | 按页面关闭，回到原版 |
| 高级快捷工具 | 默认显示的悬浮球、展开方式、工具选择、找回、重置位置 |
| 性能与兼容选项 | 标题纹样、衣柜隐藏列表、商店离屏绘制、商店按页生成 |
| 兼容回退 | 回退原版、启用新版 |
| 问题诊断 | 只读 Runtime Inspector |

## 偏好与恢复

关闭总开关后使用原版 UI，保留界面设置入口。重新开启恢复已保存的页面与显示选择，原版回退不切换为历史主题。

“恢复 100%”只改字体与按钮大小；“重置悬浮球位置”只改位置，保留开关、模式和工具选择；“找回悬浮球”会开启并取消隐藏。升级保留明确保存的悬浮球选择，新安装默认显示，明确保存的关闭或隐藏选择不会被重置。

第一次执行 2.6 缩放迁移时将字体和按钮归为 100%，迁移标记与值一起保存。之后重启、旋转、分屏或升级不再重置，范围始终为 50%–150%。其它偏好不随这项迁移改变。

旧 `statusPreview`、`startupCacheLazy` 和 `storyActions` 偏好保持 false，不再启动内部预览、加载器缓存 Hook 或原版动作底栏。它们不是当前可启用功能。

衣柜操作忙碌时不能强行切换原版或总开关。回退不执行换装、购买、保存、读取，也不修改 Mod 加载顺序。若设置无法打开，在加载器中禁用本包并重启。

## 阅读与手机密度

舒适阅读间距、正文宽度与手机紧凑间距独立控制。紧凑模式减少控件留白，保留至少 44px 命中区域，不缩小正文，不移动原节点。侧栏和模组管理页面不跟随主界面按钮缩放。

手机尺寸按视窗宽度或屏幕短边 ≤600 CSS px 判断；桌面窄窗口也可进入紧凑规则。这不是设备型号识别。

## 性能选项与实验

衣柜新安装默认按页渲染，每页 40 件。普通浏览可跨已支持分类搜索；整理模式的搜索、排序和全选覆盖当前分类完整数据，批量操作不跨分类。未知业务槽位通过原版或扩展入口访问。

进阶实验默认关闭，已有有效选择保留：

| 选项 | 作用 | 关闭方式 |
| --- | --- | --- |
| 衣柜延迟原版隐藏列表 | 换装时暂缓刷新隐藏列表，原规则和历史更新保留 | 关闭实验或回到原版衣柜时补齐 |
| 商店离屏绘制延后 | 浏览器支持时减少离屏绘制 | 单独关闭 |
| 商店按页生成 | 生成当前页，随主包提供，下次进入或重建列表生效 | 关闭后重新进入商店 |

不支持的能力不强行启用。减少 DOM 工作不等于已证明购买、换装或启动整体速度提高。
