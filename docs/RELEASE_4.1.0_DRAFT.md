# Soft & Wet 4.1

> 发布准备稿：候选尚待负责人验收，未公开发布。验收后再将正文用于 Release，不据此宣布正式可用。

**快速流畅，华丽精致，感知舒服。**

4.1 延续 V1 黑灰 Acrylic，让官方窗口、已适配的第三方界面与用户设置更加协调。这次重点放在通透度、阅读排布、悬浮工具和动态绘制开销，保留购买、穿戴、战斗与存档原有行为。

## 本次更新

### 自己决定玻璃的通透度

新的 **Acrylic 通透度**滑杆在 0–100 之间连续调节，默认 60。向左更沉稳，向右更通透；在同一套设计内改变材质，不切换成三套皮肤，也不让文字跟着透明。

已适配的官方窗口和完整兼容窗口使用同一套材质设置。虚拟手机、正文承载、资源与参考视图保留各自需要的层次。

### 阅读与窗口排布

- 正文行距、段落与选项间距、正文宽度分别调整，默认保留原版正文。
- 选项文字默认原样／靠左，可按习惯居中；正文保持原样。
- 设置继续提供上下、左右布局，保留当前分类、真实控件和自动保存。
- 删除三维翻页转场，换页直接显示；只有 UI 设置分类保留 20ms 淡入，衣柜直接进入。
- 修复服装店内容区宽度临界时详情错铺全屏的问题，窄屏抽屉和宽屏右栏按同一宽度切换。
- 官方界面统一紧凑排布；撤销侧栏“紧凑状态间距”，手机按钮间距仍可独立选择。
- 页签、表单、存档三页与适用兼容浮层跟随同一设置，未知第三方结构保留原生。

### 悬浮工具与天气

扇形工具悬空排列，辅助操作放在内侧；网格继续保留，空间不足时优先保证操作可用。金属球回旋、菜单时序和已认可的天气表现延续。

对已识别的窗口，将动态天气、光学装饰与导航轮廓从静态玻璃外壳分离，减少动画带动外壳反复重绘。保留雨滴大小、雨量、速度和材质参数；装饰不接收输入，关闭动态后操作仍正常。

### ModHub 与兼容包

ModHub、ReOverfits 和万能手机适配包同步当前样式，并递增各自版本；其它未变化的包继续沿用。目标 Mod 需要另行安装，兼容包不接管其业务。

主 UI 对已核对的 ModHub 1.9.2 市场脚本复用有界依赖规则，减少重复编译。描述与目录变化仍实时重新推断，不缓存依赖结果、更新状态或请求代次。未知版本或源码变化时保留原路径，不修改作者安装包。

## 安装与升级

普通玩家需要 **DoLGameUI + Framework Host** 两个 ZIP；兼容包按已安装目标选择，均无需解压。

1. 保留需要的存档、原包和加载顺序。
2. 替换同技术名的主 UI，Host 放在 UI 前，每个身份只启用一个版本。
3. 同步有变化的适配包：ModHubSoftWet 1.0.3、ReOverfitsSoftWet 1.0.1、SmartPhoneSoftWet 1.1.2。
4. 重启后检查设置与所需页面，再继续游戏。已有有效偏好保留，游戏存档格式不迁移。

| 环境 | 要求 |
| --- | --- |
| DoL | 当前声明与测试基线 0.5.12.13 |
| ModLoader／TweeReplacer | 最低 2.100.0／1.0.0；按实际能力与结构适配 |
| Framework Host | >=0.1.2-experimental 且 <0.2.0；本轮核对 0.1.5-experimental |
| 玩家端 | 代表性验证覆盖 Windows Edge 与 Android WebView；不要求安装 Node |

最低版本不保证所有未来版本。CE 原作者与独立 rebuild.30 只能启用一个；手机适配包用于已核对的 Alpha，不适用 Omega。具体说明见 [安装与回退](INSTALL_4.1_CANDIDATE.md)、[可选兼容包](OPTIONAL_ADAPTERS.md)。

## 已知限制

- 部分第三方页面会保留自己的界面，未知结构不强行接管。
- 短采样显示动态窗口与依赖计算有改善，不是全部设备、持续 FPS 或功耗保证；复杂组合仍可能出现慢帧。
- ModHub 全部安装／更新、云端写入、所有交易和战斗场景未穷举，不能据页面检查宣称全部业务通过。
- Ray 衣柜预览与祭坛溢出反馈仍待可复现场景确认，未宣称修复。ReOverfits 本轮没有目标 Mod 的新增实机业务证据。

回退时恢复原包和加载顺序并重启，不清空存档或 App 数据。详细源码、当前制品与覆盖边界见 [候选记录](evolution/EVO-4.1-CANDIDATE-2026-11-02.md)。
