# DoL Soft & Wet Game UI 2.5.0-rc.2 · Crazy Diamond

这是 2.5 的本地发布候选，尚未公开发布。正式下载仍为 2.2.2。

## 主要变化

- 衣柜支持跨已支持分类搜索，结果显示所属分类；清空搜索返回当前分类。点选衣物仍直接穿戴，整理仍限当前分类。
- 手机和平板竖屏优先显示衣柜分类、搜索、已穿戴摘要和衣物列表，次要操作保留在后方。整理模式收起不适用的穿脱区。
- 手机服装店将搜索与清零／每页数量分成两行，减少工具栏占位。窄容器使用商品详情抽屉，点击上方空白可关闭；宽屏保留列表与详情。
- 存档窄屏页头更紧凑，原版入口和关闭按钮留出独立点击空间；宽屏同样保留关闭区。
- 修复存档打开及内容刷新时外壳、按钮闪烁。界面节点复用，操作前仍重新核对原槽位与绑定。
- 独立原版优化兼容包为手动槽位的游戏内时间预留位置，异步读取时显示提示，补齐日期不再挤动按钮。读取仍由原 Mod 执行，自动槽不显示永久等待提示。
- 保留自适应战斗动作区、原控件和连续动作选择；不改变战斗判定。

## 安装与升级

导入 `DoL-SoftWet-GameUI-2.5.0-rc.2.mod.zip`，不要解压。只启用一个 UI 主包，导入后重启游戏。内部标识仍为 `DoLGameUI`，可替换旧主包；升级前建议备份存档。

需要 ModLoader **2.100.0+**、TweeReplacer **1.0.0+**。声明支持 DoL **0.5.11.9 / 0.5.12.13**，不包含游戏本体、APK 或游戏图片。

官方兼容包仍为可选独立包。使用原版优化时，本轮配套包为 `DolOptimizationSoftWet-原版优化-1.1.1.2-plus-v0.1.6-rc.2.mod.zip`；目标最低版本要求不代表所有未来结构均已验证。

关闭界面设置中的 Soft & Wet 或单页开关可使用原版；回退到 2.2.2 时替换主包并重启，不同时启用两版。

## 兼容与限制

- 存档格式与 API v1 保持；已有显示偏好继续保留。
- 搜索覆盖可靠来源支持的衣物分类。未知私有衣槽保留原版或第三方入口，不猜测其操作。
- 窄屏衣柜用 CSS 调整视觉顺序，键盘焦点顺序仍随原 DOM；次要操作可能需要向下滚动。
- 原版优化的紫色日期仍需异步读取；本轮消除刷新闪烁与布局跳动，不保证瞬时显示。
- 未验证任意第三方组合、所有设备及 WebView，不作全面兼容保证。
