# Stone Free 3.0 · NO.1 自由悬浮球原型

## Windows 接续状态

本地接续分支已继承正式2.6.0的50%–150%迁移和两项窄屏修复，并完成平板独立测试版的悬浮球触控、设置入口与Modal暂停／恢复检查。当前仍为内部原型，不是3.0正式发布。下面是首轮Mac原型的历史说明；旧合同、未验证范围与远程状态以[最新接续记录](STONE_FREE_WINDOWS_AB.md)和当前源码为准。

版本3.0.0-stone-free.1，仅供独立测试安装，不是正式稳定版。源码从本地可核验的2.6 RC1提交7e9a687dc52015ce5934cee709de4377b6cf625e派生；这些2.6提交尚未在远程仓库，不能从远程main直接重建此原型。

玩家现在可以：单击球体打开扇形快捷菜单；选择“全部工具”进入网格；打开真实的界面设置或只读开发检查；使用“移动悬浮球”的滑块，或长按450ms再自由拖动。位置不吸边，拖动结束不展开菜单。球体在窗口收缩时临时保持可见，保存的位置意图不被覆写。

界面设置新增一个独立“Stone Free自由悬浮球”小节，可选默认展开模式、扇形工具、关闭球体、找回隐藏球体和重置位置。不是整个设置中心重整。第一轮工具仅含自有设置、开发检查、移动；不代理原剧情动作。设置仅保存稳定工具ID、布尔项、模式和位置数值，没有任意脚本或DOM。

入口是普通Vue宿主，非模态，没有showModal、全屏点击遮罩或全局拖动监听。只有菜单展开时临时监听外部pointerdown，用来收起菜单，不拦截外部点击。球体本身的touch-action:none只用于手势区域。原生dialog或已识别游戏浮层出现时临时撤下宿主；对未知浮层不保证自动识别，不争夺第三方节点。

桌面macOS/Chrome155、Playwright与仓库已有SugarCube夹具完成真实交互回归，详见STONE_FREE_NO1.md。真实Android、WebView软键盘、触控长按/系统手势、安全区、多点触摸和实际整合Mod组合均为Not Validated。本包不能作为T0正式发布通过证明。

重要：2.6正在另行收口统一50%–150%及一次重置合同。本原型不实现、不重复、不冒充该迁移；此基线仍是RC1旧合同。后续需先接入正式2.6更新再进行集成验收。其它3.0功能、PC命令面板和Paisley Park5.0均未开发。
