# Soft & Wet 2.1.0 · DoL 0.5.11.9 / 0.5.12.13

2.1.0 主要加强界面的兼容性和异常恢复，保留现有 Soft & Wet 材质、布局和原版操作。目标是遇到陌生结构时少接管，出错时仍能继续使用原版。

## 主要变化

- 增加一层轻量 UI 适配护栏：兼容包先检查目标页面和结构，再应用外观；识别不完整时减少适配，未知内容继续显示。只读主题、档位和能力查询见 [UI Runtime 接入说明](UI_RUNTIME.md)。
- 增加可选 Modal / Drawer 请求 API，统一浮层外壳、关闭路径与焦点恢复；只接收调用方新建内容，关闭主题或能力不足时返回不可用，保留调用方自己的回退路径。
- 在“界面设置 → 开发检查”增加 Runtime Inspector，可查看能力、当前浮层、Adapter 指纹、fallback 和降级原因，并复制或导出诊断。默认收起，不读取游戏变量、存档或输入正文。
- 各界面分别启动、更新和回退；单个模块异常不再阻断其它界面。
- 社交、属性、商店、衣柜和存档补充呈现异常保护。失败时暂停对应接管，不清空已有显示偏好；明确重新启用或重载后可重试。
- 附加内容无法完整识别的存档行保留原版显示，不再被新版代理隐藏。重复或不一致的关键结构优先降级。
- 恢复锚点被其它 Mod 删除时，尽量把仍在使用的原控件保留在原页面；正常情况仍恢复原位置。游戏已删除的节点不会重新插回。
- 不支持 backdrop blur 时关闭玻璃效果；缺少 ResizeObserver 时使用现有窗口尺寸更新。不支持原生 dialog 时存档保持原版，界面设置仍可打开和关闭。
- 设置自身出错时提供简单的原版恢复入口；主题启动失败时也保留关闭整个 UI 的入口。

## 独立兼容包

MapleBirchSoftWet、ModHubSoftWet 更新为 **0.2.1**，使用本轮 2.1.0 的结构识别、角色样式、API 能力检查和撤销护栏；原窗口、控件与业务保持。旧 Lyra 衣柜嘴部包为 **0.1.1**；0.5.12.13 的独立主角色嘴部修复继续使用 **0.1.0**。

兼容包按目标版本选装，文件名仍包含目标 Mod 版本及包自身版本。详见 [兼容包说明](OPTIONAL_ADAPTERS.md)。

## API 文档与示例

第三方作者可按需使用只读主题 / 能力查询、Style Adapter 和新建 Modal / Drawer。API 不要求其它 Mod 接入，也不重建第三方已有界面。

- [API 接入文档](UI_RUNTIME.md)
- [基础设施边界](UI_INFRASTRUCTURE.md)
- 仓库 `examples/ui-surfaces/` 提供独立接入示例；Release 附示例 ZIP，默认不打开浮层。

主包、两份样式兼容包、API 文档和示例作为独立附件提供。示例包用于开发验证，普通玩家无需安装。

## 安装与回退

适配 DoL **0.5.11.9 / 0.5.12.13**，需要 ModLoader **2.100.0+**、TweeReplacer **1.0.0+**。导入 ZIP，不要解压；替换已有同名 Mod，不同时启用多个版本，之后重载游戏。升级前建议备份存档。

关闭“启用 Soft & Wet 2.0 界面”直接使用原版，各单页偏好继续保留。遇到页面异常可以关闭对应功能；设置无法打开时使用恢复入口，或在加载器中禁用 UI 后重启。

本版不修改存档格式，不重写游戏设置、战斗判定、购买或换装规则。异常保护包围 UI 呈现，不重试原版业务操作，也不引入平行业务状态。第一阶段 Runtime 仅管理 UI 样式识别与撤销，不管理加载器或第三方生命周期。

普通面板保留原节点和事件；存档、商店、战斗、衣柜延续既有专项适配边界。未知存档行回到原生显示，第三方页面继续以独立轻量样式包为主。衣柜仍属于已有深接管页面，不承诺自动渲染任意第三方私有功能，可关闭新版衣柜使用原版。

故障注入专项覆盖启动/更新/Vue 交互失败、原节点和事件保留、未知动态存档行、恢复锚点丢失、能力缺失及恢复入口。最终构建、隔离回归与设备结果见 [验收记录](VALIDATION.md)。陌生 Mod 组合、长期设备性能和云端业务不属于本轮验收范围。
