# Kraft Work 3.0 展示素材

本目录用于仓库首页和 3.0 发布页展示，不属于玩家需要安装的 Mod 包。

五张截图与约 12 秒录像来自正式发行 ZIP 在 Android 独立测试版中的运行结果，使用隔离测试进度。天气录像通过游戏原 Weather 接口准备雷雨，原生录制并保留原时间尺度；不是物理触控或 FPS 性能测量。

- `KraftWork-3.0-settings-horizontal.png`：上下设置布局。
- `KraftWork-3.0-settings-vertical.png`：左右设置布局。
- `KraftWork-3.0-character.png`：角色信息窗口。
- `KraftWork-3.0-floating-hub.png`：Floating Hub。
- `KraftWork-3.0-weather.png`：天气响应窗口。
- `KraftWork-3.0-weather-android.mp4`：Android 原速天气录像。
