# Soft & Wet 3.x 视觉基线

Kraft Work 3.x 是所有现行 UI 设计的唯一基线：黑灰 Acrylic、清楚的内容层次、局部彩色交互、按语义使用的波纹与波浪，以及响应游戏状态的天气。保留已认可效果，只修实际缺陷。

负责人于 2026-10-20 确认：此前所有 1.x／2.x 设计均封存，不再用于新设计、运行主题或默认兼容外观。历史报告、截图和源码可用于追溯，不构成当前设计依据。后续新增页面与兼容维护继续以 3.x 为准，除非负责人明确指定例外。

官方页面、专用外观兼容包和共享原生窗口的默认展示都使用这套基线。Mod 提供的页签可继承外壳和普通控件外观；未知内容的业务、节点、布局所有权和事件仍由原作者管理。没有专用适配不再意味着恢复旧蓝灰主题，也不意味着接管所有第三方组件。

旧外观入口和旧调色板断言已[封存](archive/visual-2x/README.md)，不进入构建或运行 ZIP。现有配置身份、迁移、布局、滚动、触控和原控件恢复规则保留；它们不代表旧主题仍可选。材质质量档位只改变效果强度，不切换设计代际。

新安装默认显示 Floating Hub；战斗默认启用现有界面和动画，全部动作平铺展开。聚焦编辑为可选模式，选择“全部展开”会保存该偏好。已有关闭或隐藏选择不被强制覆盖。

六个配套兼容包以 1.0.0 建立统一基线，后续修复各自递增版本，以当前发布页为准。四个外观包使用当前材质；ReOverfits 复用主衣柜；嘴部包是资源适配，无自有窗口，不因统一外观增加 UI 依赖。
