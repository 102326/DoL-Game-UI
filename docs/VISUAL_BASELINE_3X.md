# Soft & Wet 3.x 视觉基线

当前设计基线为 Kraft Work 3.x：黑灰 Acrylic、清楚的内容层次、局部彩色交互、波纹与波浪按交互语义使用、天气来自游戏状态。沿用已认可效果，只修实际缺陷。

后续官方页面与外观兼容包默认沿用这套材质、按钮、导航和动效。特殊页面有明确要求时可例外；第三方业务、未知节点和事件不因视觉统一而被接管。

1.x／2.x 的设计说明、Eyes HTML 演示、旧视觉方案与旧质量档位均为封存参考，不再作为新设计依据。历史验证与发布身份记录继续保留。经典构建、配置迁移和原版兼容回退仍可能依赖旧模块，未经行为验证不批量删除这些运行代码，也不把“恢复原版”改成“恢复旧主题”。

后续维护的默认值：新安装显示 Floating Hub；战斗平铺展示原控件并启用现有动效，聚焦编辑 B 仍需选择开启。已保存的关闭或隐藏选择保留，默认值变更不强制重置偏好。关闭新版战斗仍可恢复原版节点。

当前六个配套兼容包使用 1.0.0 技术版本。四个外观包同步 3.x 材质；ReOverfits 沿用主衣柜的显示与操作；嘴部资源包没有自有界面，不为统一外观增加 UI 依赖。旧 Lyra 0.5.11.9 专用包封存，不进入当前构建或安装组合。

以上为本地维护目标。它不改写 v3.0.0 的公开附件和历史验收，不代表本轮已获新的发布授权。
