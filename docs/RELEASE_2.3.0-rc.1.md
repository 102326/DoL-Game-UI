# DoL Soft & Wet Game UI 2.3 候选

本地候选，尚未公开发布。基于 M2～M4-B 成果整合；正式版仍为 2.2.2。

- 衣柜保留单击直接穿戴、角色预览、原版信息和整理操作；窄屏分类使用单行选择，常用操作可展开。
- 商店按容器宽度排列列表与详情；窄屏使用详情 Drawer。
- 战斗继续使用原控件和事件，增加动作密度布局和动态失效保护。
- 存档增加操作前的槽位与详情复核，保留搜索、选择与原版回退。
- 减少窄屏重复边距与装饰区域，保留主要动作的合理触控尺寸。
- API 仍为 v1，增加只读槽位支持查询；未知业务保留原入口。
- 保留游戏内存档日期，写入 gameTime 时保留同命名空间其它有效字段。

当前候选声明的游戏版本仍为 0.5.11.9 / 0.5.12.13，不扩大第三方版本兼容声明。使用 ModLoader 导入 ZIP，不解压，不同时启用多个主 UI 版本。官方兼容包仍可选。

构建和衣柜、商店、战斗、存档定向隔离测试通过。手机独立测试环境已安装，实际 UI 验收进行中；浏览器窄视口结果不代替物理手机验证。完整状态见开发工作记录。
