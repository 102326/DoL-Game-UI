# Stone Free：视图贡献与信息工作台

2026-10-16，继续基于首轮提交 `d666095647fe31c684eb80e471633efa0500ae6f`。本轮范围是一个可选布局提供者、两个贡献者、一个仅用于争用反例的替代布局及其清理验证。不增加游戏动作调度，不改正式 UI 2.7，不发布。

## Delivered

公共实验合同增加 `getCapabilities().views / provideView / views / onViews`。布局接收作者主动提供的装载回调，不解析、移动或重建原版/未知 Mod 的内容。撤销声明同步释放其全部实例；初始化期间自我撤销、过期异步结果和局部失败有定向反例。

两个独立研究包提供状态速览与状态对照视图。它们只共用公开状态 schema 和 Vue SDK，不通过私有 Store 合作。同一视图可进入信息工作台或替代布局；首轮独立模态入口和官方 Drawer 消费者仍可使用。

工作台默认可用，允许在编辑时隐藏、排序和调整密度。普通查看时隐藏排序控件。布局偏好只存于自己的 UI namespace，临时缺失的提供者不会清除已有偏好；隐藏或关闭会卸载对应实例。局部对照只在本次打开期间存在，未持久保存游戏值。

区域、组件内快捷键和模态由参与者显式申请。替代布局遇到占用时退让，可在原提供者释放后接续，不能抢占。快捷键不绑定 document，跳过输入框、IME 标记和其它贡献者拥有的子视图。

## 本轮发现并处理的问题

首轮临时部署只退出 Host 与面板，没有调用消费者的取消连接函数。同一文档里，消费者仍会等待 Host 重启；这符合已安装包的行为，却不足以证明临时包卸载。各入口现导出 `dispose()`，脚本保存并核对自己的入口对象后逐个释放，再建立空 Host 确认没有复活消费者。命名冲突时不删除外部对象，并继续清理其它自有资源。

实际检查时，平板已换过文档。比较旧收据与当前 frame/loader 后确认原订阅已消失，因此没有执行原本考虑的再次重载。旧收据的“宿主为 0 / Host 不存在”仍是当时 DOM 结果，不能据此追认完整包卸载。

另两项局部修正：Vue 深 readonly 类型遇到递归 JSON 时过度展开，改为只读 ref，底层投影仍由 Host 复制冻结；工作台不再把外部视图长 ID 拼入实例名，避免合法声明却无法显示。它们属于本项目实现问题，不是 Paisley Park 缺陷。

## 当前结论与剩余边界

A 的独立使用证据保留。B 的只读视图组合及两个受控参与者的资源交接有代表性真机证据，但两个布局与贡献者仍来自同一工程，不能称社区生态采用。

完整原游戏跨 Passage/存读档、物理手机触控/IME、受审业务命令和完整玩家行动流程未验收。本轮只实现有限信息工作台，不是 Widget 编辑器或最终默认 3.0 产品。Factory 对照收益、共享 Vue 分发与稳定 API 仍未定型。

没有未处理的本轮阻塞；后续应优先选择一个有可靠原操作身份、失效和结果见证的真实动作实验，再决定是否扩大公共命令合同。
