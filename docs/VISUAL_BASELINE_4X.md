# Soft & Wet 4.x 视觉与交互合同

本文件自包含地描述4.x当前基线，依据已发布4.1实际界面、[设置说明](UI_SETTINGS.md)、[4.1验收](evolution/EVO-4.1-CANDIDATE-2026-11-02.md)和负责人当前裁决。它取代旧代规范作为当前指导；不要求读取旧仓库才能开发。

## 当前接受的体验

快速流畅、华丽精致、感知舒服协同实现。黑灰Acrylic、清楚的内容层次、局部交互反馈和天气材质是4.1现役表现。默认通透度60、文字/选项靠左，居中模式按成熟排版独立平衡控件；不只text-align:center。默认正文行距100%、附加段落/选项间距0、正文宽度0；通过现有滑杆增加空间。保留44px主要触控区域、语义颜色及原生控件操作。

普通换页与衣柜入口直接响应；设置分类保留20ms淡入，系统减少动态优先。Floating Hub保留已接受金属球、自旋/回旋、独立悬浮扇形工具、网格及内圈工具。球体与菜单命中、停靠/取消/隐藏/恢复保持一致。

天气沿4.1现役雨珠/斜雨、四档雨量、霜羽/浅霜及特殊天空合同；正文/标题/交互区要可读、可操作。不得因共享token或设置通过就宣称所有窗口完成。

## 跨角色验收

设置、属性/社交/通用面板、存档、衣柜/参考/抽屉、商店、战斗及维护中的适配界面分别核对：外壳、导航、控件状态、文字/间距、动效/天气、偏好、原生动作、失败回退与释放。不同代码可以保留，最终展示应同一视觉语言；正文、虚拟手机和资源适配可有必要角色差异。沿[消费者覆盖表](evolution/EVO-P0-COVERAGE.md)记录实际证据，不以两角色代替全局验收。
