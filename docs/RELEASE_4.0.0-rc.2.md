# Soft & Wet 4.0 — Evolution 候选

4.0.0-rc.2用于发行前验收，尚未正式发布。保留3.X黑灰Acrylic、Host与UI双包及原游戏业务。

- Floating Hub加入金属球回旋、蓄势展开和关闭回收，保留原工具。
- 设置支持双布局、连贯分类切换、新玻璃雨珠与雪天霜羽。
- 优化已适配窗口的雨幕移动方式，减少持续重绘；雨量、速度、水滴及材质保留。
- 设置增加血月、异世界、极热与严寒环境；原有雨雪保留，雨中血月使用普通雨。
- 修复缩放后的战斗底栏偏移、关闭残留背景和一条衣柜离场刷新路径。
- 兼容包维护保持原业务；原版优化异常日期仅作条件显示修复，不改存档。

需要Framework Host >=0.1.2-experimental且<0.2.0，候选使用0.1.5-experimental；DoL当前适配基线0.5.12.13，ModLoader >=2.100.0，TweeReplacer >=1.0.0。Host先于UI，同名包仅启用一份，无需解压。升级前保留原包与存档备份，回退时恢复原包和顺序并重启，不清空App数据。

新天气模型仅用于设置，其它已适配窗口保留现有表现。未知第三方结构退让。未覆盖全部设备和Mod组合，没有完整FPS或长期无泄漏结论。完整安装与验证范围见仓库候选文档。
