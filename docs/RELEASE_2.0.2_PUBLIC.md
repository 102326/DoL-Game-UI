# Soft & Wet 2.0.2 · DoL 0.5.11.9 / 0.5.12.13

2026-10-05 更新：同名 2.0.2 附件增加 0.5.12.13 兼容声明，JS / Twee 与原发布包一致，CSS 补充触屏高亮修正，校验值已更新。已下载旧附件的用户请重新下载并替换。

Soft & Wet 2.0.2 主要完成了 2.0 界面的第一轮统一，包括存档、社交、衣柜、商店、战斗和部分常用菜单。

这一版使用柔雾 Acrylic、轻卡片和更清楚的内容层级，同时尽量保留原版游戏的状态、事件和存档行为。相比 1.x，主要调整了界面结构、材质和交互表现，没有重写游戏本体逻辑。

## 主要变化

### 存档

- 调整存档管理、详情面板和导入／导出界面的样式，保留搜索与最近保存标记。
- 宽屏默认保留双列存档布局；开启“存档 V2”后，可使用左侧列表、右侧详情的布局。
- 原版保存、读取、删除逻辑及存档格式保持不变。

### 社交

- 使用轻卡片组织角色关系与状态信息，减少重复边框和过重容器。
- 保留原版数据来源和页面行为。

### 衣柜与商店

- 统一分类、搜索、穿搭展示、详情区域和操作控件的样式。
- 服装说明保留 V1 的内容与行为，只调整外观。
- 购买价格、穿戴条件和游戏规则保持不变。

### 战斗

- 调整动作按钮的视觉层级，降低普通动作的外壳存在感，以文字和局部颜色表达选中状态。
- 调整选择摘要和战斗工具浮层的样式。
- 不改变原版战斗判定和结算逻辑。

### 常用菜单

- 统一特质、统计、成就、日志和设置等已接管区域的样式。
- 设置和特质优先美化原控件与内容节点，减少完整边框和重复容器。

## 界面调整

2.0 的材质分工为：

- 主内容：稳定实底。
- 二级菜单：Soft Acrylic，允许轻微背景参与。
- 三级详情和小浮层：更明显的玻璃层级，正文仍以可读性为主。
- 内部内容：轻卡片、弱边界、内容优先。

均衡档与华丽档共享布局，主要区别在材质强度。可在界面设置中关闭玻璃或减少动态。

## 移动端调整

修正触屏蓝色点击蒙层和小贴士 Hover 残留，保留真实选中状态和键盘焦点。

增加可选的**手机紧凑按钮间距**，默认关闭，不影响大屏布局。字号、按钮大小与显示偏好仍可在“界面设置”中调整。

## 原版界面与回退

在“界面设置”中关闭 **“启用 Soft & Wet 2.0 界面”** 后，直接使用原版界面。部分页面也保留独立回退入口；重新启用后，界面显示偏好会继续保留。

1.x 风格保留在独立维护的 **1.x LTS（1.1.0）** 中。

## 兼容性说明

- **兼容 DoL 0.5.11.9 和 0.5.12.13**。0.5.11.9 复用原版与 Lyra 验证结果；0.5.12.13 主要验证 Lyra Goose `1004.1` / MapleBirch 5.2.3 / ModHub 1.2.3，不保证所有整合包和 Mod 组合。
- Goose 嘴部修复与 ModHub 外观为独立可选包，不包含在本 UI 包中。deadwood-reblooms 未出现在本轮实际加载清单，尚未验证。
- 需要 **SugarCube 2 ModLoader 2.100.0+** 和 **TweeReplacer 1.0.0+**。
- MapleBirch 已识别的云存档界面仅做外观适配，云端功能仍由原 Mod 执行；不保证所有版本和模组组合兼容。

## 安装说明

1. 升级前建议备份存档。
2. 下载本页附件 **`DoLGameUI-2.0.2.mod.zip`**，直接在模组加载器中导入，**不要解压**。
3. 升级时替换已有的 `DoLGameUI`，不要同时启用多个版本。曾安装独立旧包 `DoLMidnightTheme`、`DoLCombatUI` 或 `DoLShopPageExperiment`，请先禁用。
4. 重启游戏，从侧栏 **“界面设置”** 调整。

本包仅包含 UI 模组，不包含游戏本体或 APK。

遇到异常可先关闭对应页面的新界面；如果设置也打不开，可在加载器中禁用本模组并重启。反馈时请附游戏版本、模组版本、设备、截图和触发步骤。
