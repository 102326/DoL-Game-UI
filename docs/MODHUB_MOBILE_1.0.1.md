# ModHubSoftWet 1.0.1 手机布局修复

对应 [Issue #20](https://github.com/102326/DoL-Game-UI/issues/20)。负责人于 2026-10-21 授权公开更新兼容包，主 UI 保持 3.0.4。

当前状态（2026-10-21）：布局修复已验证；新增原生进度圆环替代，已在真实 Android 代表性市场安装、更新和完成弹窗中复验。该轮未再观察到持续闪烁，但安装核验仍有约 0.6–0.7 秒的单次停顿。按最新授权进入发布，Issue #20 保持打开跟踪剩余问题。

## 修复范围

ModHub 在手机上将 Mod 条目和更新提示改为纵向 flex。外观包原先为横向排列设置的 `18rem` 和 `16rem` 基准尺寸随主轴变成高度，分别撑出了信息区和更新提示中的空白。

1.0.1 在原生断点内改为按内容确定高度：列表使用 640px 断点，更新提示使用 600px 断点。桌面尺寸、完整文字、更新入口和原生操作保留。另补齐 ModHub 1.8.0 顶栏强制灰底、边界和金色页签文字对 3.X 材质的覆盖。

未改安装、启停、排序、市场更新或存档规则。兼容包继续要求 ModHub >=1.3.0、UI >=3.0.0，未提高前置版本；最低声明不代表所有版本均已实测。

## 2026-10-21 进度动画整改

ModHub 1.8.0 的 `modhub-progress-font-ready` 会启用 SVG 中的 120 个字体图案，通过 `translateX(-3840px)` 切换图案。当前 WebView 的短时对照中，该画法每 3 秒约触发 199–202 次布局；兼容外观启用时，任务耗时也较高。只隐藏字体条并恢复 ModHub 原有圆环后，同类采样布局次数为 0–1。取消窗口模糊未消除字体条的持续布局，不能只回退玻璃材质作为修复。

兼容包仅改展示：已识别的主窗口和原生 body 弹窗使用原有 circle 节点和原 keyframes，确定进度值、ARIA、提示文字及业务事件保留。关闭动画／reduced motion 静态显示；未知弹窗结构退回原生。新增测试覆盖圆环显示、确定进度、两种动画关闭方式、原取消事件、结构变化和释放。

真实市场回归使用设备上已有的 Dynamicest：3.3 → 3.2.1 → 3.3。ModHub 原生禁止相同版本重装，因此没有绕过禁用状态；通过其原版本选择和安装确认完成上述流程。临时旧版只写入包体，期间不重启执行；最终包 SHA-256 为 `339c99c6f671509a95e72c12391d8a1c7bd5bedd6832b4d01f160f688f630e9a`，与开始时及作者 v3.3 附件一致。Mod 启停列表和 UI 偏好不变；完成后取消原重载提示，合成触控滚动至 450px，内容无横向溢出。

实际安装／更新各约 9 秒的观察窗口测到 15 次布局，不再是字体条引发的连续重算。分别有 600.2ms／682.3ms 的最大回调间隔，集中在安装核验阶段；不是持续运行已完全流畅的证明，也不是 FPS 测量。操作与录屏是自动化代表性验证，不称作物理触控验收。

当前候选 ZIP 的 SHA-256：`c92f0f8bf2957617d10d98cb439fd4a4c2c3268f3fe77a3bdb6d4f2d1714142c`。真实市场回归先使用 `1975ae203ff71b2eabf36aa589694788b7804f48a16c764c2677b1618ec09598`，最终候选仅补充原生弹窗 section 角色以使诊断正确显示 Style Only，并更新 README；加载图标 CSS 字节未变。最终候选另外核对实际 Loader 成员与原生弹窗匹配，不重复整个市场下载流程。

新增未知结构退让测试首次把 SVG text 的 computed display 预期写成 inline，实际浏览器返回 block。已改为与同一浏览器在适配前的原生显示值及动画名比较；没有删除退让断言。既有浏览器适配测试、类型、ZIP 成员／依赖／许可证检查通过。本分支没有运行新的 GitHub Actions。
