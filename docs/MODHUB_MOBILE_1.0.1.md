# ModHubSoftWet 1.0.1 手机布局修复

对应 [Issue #20](https://github.com/102326/DoL-Game-UI/issues/20)。本轮交付兼容包与本地安装验证，不包含公开发行。

## 修复范围

ModHub 在手机上将 Mod 条目和更新提示改为纵向 flex。外观包原先为横向排列设置的 `18rem` 和 `16rem` 基准尺寸随主轴变成高度，分别撑出了信息区和更新提示中的空白。

1.0.1 在原生断点内改为按内容确定高度：列表使用 640px 断点，更新提示使用 600px 断点。桌面尺寸、完整文字、更新入口和原生操作保留。另补齐 ModHub 1.8.0 顶栏强制灰底、边界和金色页签文字对 3.X 材质的覆盖。

未改安装、启停、排序、市场更新或存档规则。兼容包继续要求 ModHub >=1.3.0、UI >=3.0.0，未提高前置版本；最低声明不代表所有版本均已实测。

## 实际验证

| 环境／检查 | 结果与边界 |

| 更新提示 | 列表修正后另发现更新提示仍高 336px、文字区高 256px；补充独立回归先失败，再修正更新提示的主轴尺寸 |
| 负责人升级后的 ModHub 1.8.0 | 最终候选检查模组管理、市场、说明、日志、帮助五个页签及 body 中的更多工具菜单；适配合同完整，窗口与内容未出现横向溢出。19 个条目约 98.47–129.67px 高，更新提示 154px 高。顶栏背景透明、选中文字恢复当前材质文字色。智能排序和刷新入口仍存在，未执行排序或更新操作 |

| 类型与安装包 | `tsconfig.adapters.json` 类型检查、原打包流程及 `check_adapter` 合同检查通过，包含依赖、入口、成员与来源字节、ZIP 元数据和许可证 |

候选通过原 ModLoader 接口替换同技术名兼容包，备份旧 ZIP，原生重启后核对持久 ZIP 和实际加载成员摘要。未清空 App 数据，原 Mod 列表顺序与停用状态保留。安装时停在标题页，没有覆盖存档槽位。

最终候选为 `ModHubSoftWet-ModHub-1.3.0-plus-v1.0.1.mod.zip`，SHA-256：`61252a089301e493fc1faba63e740bfecaf9719eaf39d36cea969e374017cda8`。本地构建、实际安装和最后一轮页面检查使用同一候选；之前只修列表及随后加入更新提示的中间包不作为交付身份。

负责人明确跳过按钮大小问题，本轮不调整已保存的按钮比例或共享按钮尺寸。
