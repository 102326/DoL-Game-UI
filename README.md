# DoL Game UI

[![Release](https://img.shields.io/github/v/release/102326/DoL-Game-UI)](https://github.com/102326/DoL-Game-UI/releases)
![Game](https://img.shields.io/badge/DoL-0.5.11.9-blue)
![Vue](https://img.shields.io/badge/Vue-3-42b883)
![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6)

为 **Degrees of Lewdity** 提供统一的深色界面，兼顾手机、平板和 PC。以圆角控件、清晰分组和更方便的操作布局，改善战斗、衣柜、服装店及常用面板的使用体验。

**[下载安装包](https://github.com/102326/DoL-Game-UI/releases/latest) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/102326/DoL-Game-UI/issues)**

## 功能

| 界面 | 内容 |
| --- | --- |
| 全局主题 | 统一深色样式、圆角按钮、阅读宽度与间距设置，支持减少动态效果 |
| 战斗 | 行动分组、选择摘要、底部操作区，保留原生动作和结算 |
| 衣柜 | 完整角色穿搭展示、点选换装、服装图标、已穿戴标记、搜索排序、容量提示、保暖信息 |
| 衣柜整理 | 多选丢弃审查、剪开套装，以及满足条件时的修理、衣柜转移等操作 |
| 服装店 | 宽屏商品与详情分栏，手机详情抽屉；分类、搜索、配色和常驻购买区；可保存进店默认服装类型 |
| 常用面板 | 属性、社交、日志、特质、统计和成就的分组与导航 |
| 界面设置 | 独立功能开关、原版界面回退、默认关闭的实验优化 |

衣柜整理确认后按原版规则逐件处理；中途出错会停止并报告进度，已完成的操作不自动撤销。游戏规则、购买价格、穿戴限制与存档格式仍由游戏处理。

## 安装

1. 使用 **DoL 0.5.11.9** 和 **SugarCube 2 ModLoader 2.100.0 或以上**。
2. 从 Releases 下载 `DoLGameUI-1.0.0.mod.zip`，在模组加载器中导入，不要解压。
3. 建议放在内容模组之后加载，重启游戏，从侧栏 **界面设置** 调整功能。

升级时替换已有 `DoLGameUI` 包，避免同时启用多个版本。曾安装独立 `DoLMidnightTheme` 或 `DoLCombatUI` 的用户应先禁用这两个旧包，避免重复主题与控件。其他全局界面模组也可能覆盖相同样式。

本包是 UI 模组，不包含游戏本体、图片素材或 APK。

## 设置与回退

- 在 **界面设置** 中分别启用主题、布局和各专用界面。
- 关闭某个专用界面可返回对应原版界面；也可使用全局 **回退原版界面**。
- 衣柜操作执行期间不能中途切换界面，等待操作结束后再回退。
- 显示偏好保存在当前浏览器或应用中，不写入游戏存档。
- 若界面无法打开，可在加载器中禁用本模组并重启。

## 实验优化

两项实验均默认关闭，可以独立开启：

- **衣柜按页渲染**：每页挂载40件衣物；搜索、排序和全选仍作用于当前分类的完整数据。
- **商店离屏绘制延后**：使用浏览器支持的 `content-visibility` 减少离屏绘制工作；不改变原版商品生成与购买流程。

实验功能不代表整体提速承诺。已有 Android 测试确认衣柜列表节点减少；商店滚动测试尚未显示稳定收益。更深入的按需生成与系统重构属于后续计划。

## 兼容范围

开发验证以原版 0.5.11.9 和 Lyra 0.5.11.9 环境为主，覆盖手机、3:2 平板和桌面视口。Android 已完成部分实机使用与性能采样，详见 [验证说明](docs/VALIDATION.md)。

第三方自定义商店、动作、角色图层或完全替换页面结构的模组可能需要专门适配。未声明兼容全部模组或全部 maplebirch 版本；遇到异常可先关闭对应专用界面，并提交复现信息。

## 开发

需要 Node.js **22.12+**、npm 和 Python **3.10+**。

```sh
npm ci
npm run build
npm test
npm run package
```

打包结果位于 `dist/DoLGameUI-1.0.0.mod.zip`。普通构建和打包不需要游戏本体；可通过环境变量 `DOL_RELEASE_DIR` 额外指定发布包输出目录。

技术栈：Vue 3、TypeScript、Vite、Tailwind CSS。游戏集成测试需自行准备对应游戏文件，不随仓库分发。具体准备与命令见 [开发与测试](docs/DEVELOPMENT.md)。
