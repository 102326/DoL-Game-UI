**Soft & Wet UI** 为 **Degrees of Lewdity** 提供统一的深色界面，兼顾手机、平板和 PC。以圆角控件、清晰分组和更方便的操作布局，改善战斗、衣柜、服装店及常用面板的使用体验。

**[下载安装包](https://github.com/102326/DoL-Game-UI/releases/latest) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/102326/DoL-Game-UI/issues)**

Mod 作者可查看 [UI Runtime API 文档](docs/UI_RUNTIME.md)、[接入示例](examples/ui-surfaces/README.md) 和 [设计与兼容边界](docs/UI_INFRASTRUCTURE.md)。这些能力均为可选；玩家可在“界面设置 → 开发检查”查看 Runtime Inspector。

## 功能

| 界面 | 内容 |
| --- | --- |
| 全局主题 | 统一深色样式、圆角按钮、阅读宽度与间距设置，支持减少动态效果 |
| 战斗 | 行动分组、选择摘要、底部操作区，保留原生动作和结算 |
| 衣柜 | 完整角色穿搭展示、点选换装、服装图标、已穿戴标记、搜索排序、容量提示、保暖信息 |
| 衣柜整理 | 多选丢弃审查、剪开套装，以及满足条件时的修理、衣柜转移等操作 |
| 服装店 | 宽屏商品与详情分栏，手机详情抽屉；分类、搜索、配色和常驻购买区；可保存进店默认服装类型 |
| 存档管理 | 宽屏双列、手机单列，空槽混排、最近保存标记和详情抽屉；统一分页、导入导出与设置，保留原版操作及回退 |
| 常用面板 | 属性、社交、日志、特质、统计和成就的分组与导航 |
| 作弊、态度与游戏设置 | 轻分组、原生控件换皮与响应式布局，沿用原控件和生效规则 |
| 界面设置 | 独立功能开关、原版界面回退、衣柜分页与可选性能实验 |

衣柜整理确认后按原版规则逐件处理；中途出错会停止并报告进度，已完成的操作不自动撤销。游戏规则、购买价格、穿戴限制与存档格式仍由游戏处理。

## 稳定性与后续维护

**1.x（1.1.0）保留为独立 LTS。** 后续以兼容修复、缺陷修复和 DoL 更新适配为主。2.0 只维护 Soft & Wet 新版呈现；总关闭直接使用原版，不携带旧 1.x UI 作为第二套主题。

当前维护重点为兼容性、稳定性和已有功能回归。正式版经过针对性测试，但尚未覆盖所有整合包及模组组合；遇到异常可在界面设置关闭对应功能，反馈时请附版本、截图和复现步骤。厨房布局随全局主题开关回退。

## 安装

1. 使用 **DoL 0.5.11.9 或 0.5.12.13**、**SugarCube 2 ModLoader 2.100.0 或以上**及其 **TweeReplacer 1.0.0 或以上**。
2. 从 Releases 下载最新版模组 ZIP，在模组加载器中导入，不要解压。
3. 建议放在内容模组之后加载，重启游戏，从侧栏 **界面设置** 调整功能。

对外展示名为 **DoL Soft & Wet Game UI**，短称 **Soft & Wet UI**（或 **Soft & Wet**）。内部加载器标识与 API 保留 `DoLGameUI`，用于旧包升级及兼容包依赖；这是同一个 Mod。

升级时替换已有 `DoLGameUI` 包，避免同时启用多个版本。曾安装独立 `DoLShopPageExperiment` 的用户须先禁用该包，再启用新版 UI 并重启；两者会修改同一段服装店原文，不能同时加载。曾安装独立 `DoLMidnightTheme` 或 `DoLCombatUI` 的用户应先禁用这两个旧包，避免重复主题与控件。其他全局界面模组也可能覆盖相同样式。

本包是 UI 模组，不包含游戏本体、图片素材或 APK。

## 设置与回退

- 在 **界面设置** 中分别启用主题、布局和各专用界面。
- 关闭某个专用界面可返回对应原版界面；也可使用全局 **回退原版界面**。
- 衣柜操作执行期间不能中途切换界面，等待操作结束后再回退。
- 显示偏好保存在当前浏览器或应用中，不写入游戏存档。
- 若界面无法打开，可在加载器中禁用本模组并重启。

## 性能与实验

衣柜按页显示在新安装时默认开启，每页挂载 40 件衣物；搜索、排序和全选仍作用于当前分类的完整数据。已有用户的设置保持原值，可在界面设置中单独关闭，恢复一次显示完整列表。

进阶实验首次默认折叠，展开后仍可分别调整；已有偏好保留，不会因折叠自动启用或关闭。以下实验新安装默认关闭，可以独立开启：

- **衣柜延迟原版隐藏列表**：新版衣柜换装时暂缓刷新看不见的原版列表；关闭实验或切回原版衣柜时补齐。原版穿戴规则与历史更新照常执行。
- **启动缓存按需重建**：仅在模组加载的早期合并阶段，延迟重建被反复失效的 Passage 缓存；设置后重启游戏生效。后续仍调用加载器原本的缓存构建方法。
- **商店离屏绘制延后**：使用浏览器支持的 `content-visibility` 减少离屏绘制工作；不改变原版商品生成与购买流程。

**商店按页生成**已包含在本 UI 包内，不需要额外 ZIP。它默认关闭；开启后只生成当前商品页，切换后在下次进入或重建商店列表时生效。遇到列表异常可从设置中关闭并重新进入商店。关闭实验时保留原版后台生成路径；若连设置页也无法打开，可在加载器中禁用整个 UI 包并重启。

衣柜分页与商店适配层的局部刷新减少了需要处理的界面节点或扫描工作，但不代表换装、购买或启动整体速度已有稳定提升。商店按需生成减少后台 DOM 工作，尚未证明首屏点击变快。更深入的系统重构属于后续计划。

## 开发

需要 Node.js **22.12+**、npm 和 Python **3.10+**。

```sh
npm ci
npm run build
npm test
npm run package
```

打包结果位于 `dist/DoL-SoftWet-GameUI-<版本>.mod.zip`。普通构建和打包不需要游戏本体；可通过环境变量 `DOL_RELEASE_DIR` 额外指定发布包输出目录。

技术栈：Vue 3、TypeScript、Vite、Tailwind CSS。游戏集成测试需自行准备对应游戏文件，不随仓库分发。具体准备与命令见 [开发与测试](docs/DEVELOPMENT.md)。
